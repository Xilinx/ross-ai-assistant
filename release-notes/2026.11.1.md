# AMD Ross™ Agentic AI Assistant 2026.11.1

## What's New

This release adds 30 skills, all in beta, bringing the total to 80.

* **Vivado design flows (5):** `vivado-ced-configurator`, `vivado-convert-flat-to-dfx`, `vivado-ipi-assembler`, `vivado-netlist-debug-insert` and `vivado-spec-generator`.
* **Hardware debug (5):** DDR memory controller, serial transceiver (IBERT), NoC debug and performance monitoring, and PCIe link bring-up: `hw-ddrmc-debug`, `hw-ibert-gt-debug`, `hw-noc-debug`, `hw-noc-perfmon` and `hw-pcie-link-debug`.
* **Vitis, including AI Engine development (13):** AI Engine graphs and kernels, simulation, hardware emulation and profiling, platform and system composition, and migration from Vitis Classic: `vitis-aie`, `vitis-aie-int8-mac`, `vitis-aie-profile`, `vitis-aie-simulation`, `vitis-classic-migration`, `vitis-create-aie-kernel`, `vitis-functional-sim`, `vitis-hardware-emulation`, `vitis-host-profile`, `vitis-pl-profile`, `vitis-platform`, `vitis-system` and `vitis-vss-simulation`.
* **Embedded Linux with EDF and Yocto (7):** machine configuration, System Device Tree generation, Yocto source setup and builds, JTAG boot, flash programming and QEMU: `esw-gen-machine-conf`, `esw-jtag-boot`, `esw-program-flash`, `esw-runqemu`, `esw-xsa-to-sdt`, `esw-yocto-build` and `esw-yocto-source-setup`.
