# Custom Op example: negate

The examples in this directory computes the negation of its inputs, e.g., like the [onnx negate op](https://onnx.ai/onnx/operators/onnx__Neg.html). It includes both a simpler "emulated" 1x1, and a more complex 4x4 tiling example. You can use these examples as an initial reference when building your custom op.
