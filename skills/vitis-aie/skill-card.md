# Vitis AI Engine Component (vitis-aie)

Create and build a Vitis AI Engine (AIE) component/graph from a
shipped example or custom sources on an AIE-capable Versal part. In-IDE via the Vitis Python
API (`runVitisPython`) or headless via `vitis -s`; create-only by default, build (x86sim / hw)
on request.
