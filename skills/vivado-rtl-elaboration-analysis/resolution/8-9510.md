# 8-9510: Genvar Not in Scope

**Message:** `[Synth 8-9510] genvar should be declared within design element where it is used`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A genvar is declared in a different scope from where it's used.

---

## Common Patterns

### P1: genvar declared in wrong scope

**Problematic Code:**
```diff
// genvar i declared in another module
generate for(i=0;...)  // ERROR: not in this scope
```

**Recommended Fix:**
```diff
genvar i;  // declare in same module
generate for(i=0;...)
```

---

## Fix Strategy

1. Declare the `genvar` in the **same** module/design element (and scope) where the generate loop uses it.
2. Do not share a genvar across modules; each module that needs one declares its own.
3. Place the `genvar` declaration ahead of the `generate` block that references it.
4. Check for a genvar accidentally declared in a package/other unit and move it local.
