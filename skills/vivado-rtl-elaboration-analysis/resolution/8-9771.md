# 8-9771: Multiple Parameter Overrides

**Message:** `[Synth 8-9771] multiple overrides for parameter`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A parameter is overridden more than once in the same instantiation.

---

## Common Patterns

### P1: Parameter overridden more than once

**Problematic Code:**
```diff
mod #(.size_in(8), .size_in(16)) inst(...);  // ERROR: size_in twice
```

**Recommended Fix:**
```diff
mod #(.size_in(8)) inst(...);  // single override
```

---

## Fix Strategy

1. Specify each parameter override only once in the `#(...)` list — remove the duplicate.
2. Use named overrides (`#(.SIZE_IN(8))`) so an accidental repeat is obvious.
3. Check for copy-paste that repeated a parameter with a different value.
4. Verify the intended value is the one that remains after removing the duplicate.
