# 8-9404: Entity Not Yet Compiled

**Message:** `[Synth 8-9404] entity is not yet compiled`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL entity is referenced but hasn't been compiled yet.

---

## Common Patterns

### P1: Entity referenced before compilation

**Problematic Code:**
```diff
U1: entity work.ent port map(...);  -- ERROR: ent not compiled
```

**Recommended Fix:**
```diff
-- Compile ent.vhd before this file
-- read_vhdl ent.vhd  (put before this file in TCL)
```

---

## Fix Strategy

1. Compile the referenced entity's source before the file that instantiates it (correct file/analysis order).
2. Ensure the entity is analyzed into the expected library (usually `work`) and the name matches.
3. In a project flow, add the entity's file to the fileset so it is elaborated first.
4. Fix typos in the entity/library name in the instantiation.
