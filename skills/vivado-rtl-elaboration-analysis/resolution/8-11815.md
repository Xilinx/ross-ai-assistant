# 8-11815: Non-Integral Index Expression

**Message:** `[Synth 8-11815] illegal index expression; expected integral type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An array index expression is not of integral type (e.g., using `real` or `string` as index).

---

## Common Patterns

### P1: Non-integral array index

**Problematic Code:**
```diff
// Before: non-integral index
real idx;
arr[idx]  // ERROR: real is not integral
```

**Recommended Fix:**
```diff
// After: use integral type
int idx;
arr[idx]  // OK: int is integral
```

---

## Fix Strategy

1. Use an integral index type (`int`, `integer`, `logic`, `bit`, `unsigned`) — `real`/`string` cannot index arrays.
2. Convert a non-integral value to an integer index (`to_integer(unsigned(...))`) before indexing.
3. For fixed-point, scale to an integer index; do not index with `real`.
4. Verify the index expression fits the array's address range.
