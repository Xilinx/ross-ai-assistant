# 8-90: Empty Module

**Message:** `[Synth 8-90] Empty module`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A module contains no logic. Either the RTL body is genuinely empty, the intended
top module was not selected, or all internal logic was optimized away because its
outputs are unconnected or driven by constants.

---

## Common Patterns

### P1: Wrong top module selected

**Fix — set the intended top explicitly:**
```tcl
# Vivado: select the real top, not a wrapper/stub
synth_design -top my_real_top -part <part>
```

### P2: Intentional stub / blackbox

**Problematic Code:**
```systemverilog
module ip_stub(input clk, input [7:0] d, output [7:0] q);
  // empty — real IP provided elsewhere
endmodule
```

**Fix — mark it as a black box so it is not flagged as accidentally empty:**
```systemverilog
(* black_box *)
module ip_stub(input clk, input [7:0] d, output [7:0] q);
endmodule
```

### P3: Logic optimized away (dangling outputs)

**Fix — ensure outputs are actually driven and connected:**
```systemverilog
module accum(input clk, input [7:0] d, output reg [7:0] q);
  always @(posedge clk) q <= q + d;   // real logic driving q
endmodule
```

---

## Fix Strategy

1. Confirm the correct top module is selected (`synth_design -top ...`); an empty top is often the wrong module.
2. If the module is an intentional placeholder, mark it `(* black_box *)` (Verilog) or provide a proper stub so it is not treated as accidentally empty.
3. If logic was optimized away, check for unconnected/dangling outputs, all-constant assignments, or missing driver connections — connect the outputs so the logic is retained.
4. If the module is genuinely unused, remove the instantiation and the file rather than leaving dead RTL.
