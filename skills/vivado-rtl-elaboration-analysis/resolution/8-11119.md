# 8-11119: Real Port in Verilog

**Message:** `[Synth 8-11119] real type port is not allowed in this mode of Verilog`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-11119] real type port is not allowed in this mode of Verilog [/path/to/file:NN]
```

---

## Root Cause

Verilog-2001 does not support `real` type ports. This requires SystemVerilog mode.

---

## Common Patterns

### P1: real port in Verilog mode

**Problematic Code:**
```diff
// Before: real port in Verilog mode
module top(input wire [7:0] i, output real o);  // ERROR in Verilog mode
```

**Recommended Fix:**
```diff
// After: use integer/logic or enable SystemVerilog
module top(input wire [7:0] i, output wire [31:0] o);  // use fixed-point
// Or compile with -sv:
// read_verilog -sv file.v
```

---

## Fix Strategy

1. Real-typed ports require SystemVerilog mode — compile with `read_verilog -sv`, or change the port to a fixed-width type.
2. `real` is not synthesizable; for hardware, use a fixed-point (scaled integer) representation on the port.
3. Keep genuine real interfaces in simulation-only modeling.
4. Verify connected signals match the (fixed-width) port type after the change.
