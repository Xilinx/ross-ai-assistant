# 8-9400: empty statement in !%1!

**Message:** `[Synth 8-9400] empty statement in !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An empty statement (stray `;`) appears where it is flagged.

---

## Common Patterns

### P1: Empty statement

**Problematic Code:**
```systemverilog
always @* ; a=b;   // stray ';'
```

**Recommended Fix:**
```systemverilog
always @* a=b;
```

---

## Fix Strategy

1. Remove the stray semicolon / empty statement.
2. Check for a misplaced `;` after a block or condition.
3. Empty statements are allowed in SystemVerilog but often indicate a bug.
