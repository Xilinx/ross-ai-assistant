# 8-10531: String Assigned to Packed Type

**Message:** `[Synth 8-10531] cannot assign a string to an object of a packed type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10531] cannot assign a string to an object of a packed type [/path/to/file:NN]
```

---

## Root Cause

A SystemVerilog packed struct contains a `string` field, which is a dynamic (unpacked) type incompatible with packed structs.

---

## Common Patterns

### P1: string field in a packed struct

**Problematic Code:**
```diff
// Before: string in packed struct
typedef struct packed {string a; byte b;} str_t1;  // ERROR: string not packed
```

**Recommended Fix:**
```diff
// After: use a packed type for the field
typedef struct packed {byte a; byte b;} str_t1;    // all fields are packed
// Or use unpacked struct if string is needed:
typedef struct {string a; byte b;} str_t1;         // remove 'packed'
```

---

## Fix Strategy

1. Remove `string` (and other dynamic/unpacked types) from packed structs — use fixed-width `logic`/`bit`/`byte` fields.
2. If you need textual data, represent it as a fixed-length packed byte array (`logic [N*8-1:0]`).
3. Keep dynamic strings in simulation-only code, out of synthesizable packed types.
4. Verify all packed-struct members are same-family packed types.
