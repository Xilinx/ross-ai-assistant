# 8-9921: port '!%1!' should exactly match its corresponding port in extern !%2!

**Message:** `[Synth 8-9921] port '!%1!' should exactly match its corresponding port in extern !%2!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A port in the definition does not exactly match its counterpart in the `extern` declaration.

---

## Common Patterns

### P1: Port should match extern prototype

**Problematic Code:**
```systemverilog
extern module m(input [3:0] a);
module m(input [7:0] a); ...  // width differs
```

**Recommended Fix:**
```systemverilog
extern module m(input [3:0] a);
module m(input [3:0] a); ...
```

---

## Fix Strategy

1. Make each port (name, direction, width, type) match the `extern` prototype.
2. Keep extern and definition port lists identical.
3. Fix the mismatched attribute.
