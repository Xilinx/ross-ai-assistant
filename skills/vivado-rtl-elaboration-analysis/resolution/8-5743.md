# 8-5743: Unsupported RAM Pattern

**Message:** `[Synth 8-5743] Unable to infer RAMs due to unsupported pattern.`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

RAM inference fails due to unsupported coding pattern.

---

## Common Patterns

### P1: Non-template RAM access pattern

**Problematic Code:**
```diff
// Before: unsupported RAM access pattern
```

**Recommended Fix:**
```diff
// After: follow UG901 RAM templates
// - Synchronous read and write
// - Single clock domain per port
// - No mixed async/sync access
// See UG901 'RAM HDL Coding Techniques'
```

---

## Fix Strategy

1. Restructure the RAM to a supported UG901 template: a clocked process with synchronous write and synchronous (registered) read on the memory array.
2. Keep all accesses in a single clock domain per port and avoid mixing asynchronous and synchronous reads/writes.
3. Use a proper memory type (`array (0 to DEPTH-1) of vector`) indexed by an address.
4. If inference still fails, use the Block Memory Generator IP or set `ram_style` to force the intended implementation.
