## Fix Strategy

1. This is a **cascading** error — it follows a more specific error earlier in the log; find and fix that root cause first.
2. Work top-down: resolve the first reported error, then re-run — this generic error usually disappears.
3. Do not attempt to "fix" this message directly; it has no standalone cause.
4. If no earlier error is visible, check for a failed file read/parse that aborted elaboration upstream.
