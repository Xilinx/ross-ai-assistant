# 8-685: Variable in Output Port Connection

**Message:** `[Synth 8-685] variable '!%1!' should not be used in output port connection`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `reg`/variable type is used directly in an output port connection, which is not allowed for certain net types.

---

## Common Patterns

### P1: reg/variable used as output net

**Problematic Code:**
```diff
// Before: reg used in output port
reg illegaluseofreg;
my_mod inst(.out(illegaluseofreg));  // ERROR in some contexts
```

**Recommended Fix:**
```diff
// After: use wire for output connections
wire proper_net;
my_mod inst(.out(proper_net));
```

---

## Fix Strategy

1. Connect module output ports to `wire`/`net` types, not procedural `reg`/`logic` variables driven elsewhere.
2. If you need the value in procedural code, declare a `wire` for the port connection and, if required, drive a separate `reg` from it via an `assign`/always block.
3. In SystemVerilog, `logic` may be used for single-driver output connections — but ensure the signal is not also assigned procedurally, which creates a multi-driver conflict.
4. Verify the net is driven by exactly one source (the instance) to avoid contention.
