# 8-9721: Uninstantiated Package Member Referenced Outside

**Message:** `[Synth 8-9721] member of uninstantiated package is referenced outside the scope`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A member of a generic (uninstantiated) package is accessed before instantiation.

---

## Common Patterns

### P1: Uninstantiated package member reference

**Problematic Code:**
```diff
result = pack.func(args);  // ERROR: pack is uninstantiated
```

**Recommended Fix:**
```diff
package pack_inst is new pack generic map(...);
result = pack_inst.func(args);
```

---

## Fix Strategy

1. Instantiate the generic package first (`package inst is new gen_pkg generic map(...);`), then reference members through the instance (`inst.func(...)`).
2. Do not reference members of an uninstantiated (generic) package directly.
3. Ensure the instantiation is compiled/visible before the reference.
4. Confirm the flow supports VHDL-2008 generic packages; otherwise use a concrete package.
