# 8-5796: RAM (scaler_component:/vertical_scaler_/i_1) ha...

**Message:** `[Synth 8-5796] RAM (scaler_component:/vertical_scaler_/i_1) has conflicting writes using multiple ports with same address`
**Severity:** CRITICAL WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A RAM has two (or more) write ports that can write the **same address in the
same clock cycle**. The value ultimately stored is indeterminate because the
colliding writes conflict.

---

## Common Patterns

### P1: RAM conflicting writes on same address

**Problematic Code:**
```diff
-- RAM (scaler_component:/vertical_scaler_/i_1) has conflicting writes using multiple ports with same address
```

**Recommended Fix:**
```vhdl
-- Ensure only one write port targets a given address per cycle,
-- or arbitrate/priority-encode the writes before the RAM.
if we_a = '1' then ram(addr) <= din_a;
elsif we_b = '1' then ram(addr) <= din_b;   -- explicit priority, no collision
end if;
```

---

## Fix Strategy

1. Ensure a given RAM address is written by only **one** port per clock cycle — priority-encode or arbitrate the write ports so they never target the same address simultaneously.
2. If two write ports are required (true dual-port), guarantee by design that their addresses cannot collide, or define the collision behavior explicitly.
3. Review the write-enable logic — overlapping enables to the same address are the usual root cause.
4. Treat this CRITICAL WARNING as a functional risk: verify post-synthesis that the stored data is deterministic.
