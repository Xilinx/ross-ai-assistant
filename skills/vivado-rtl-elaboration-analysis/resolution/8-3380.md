# 8-3380: Loop Does Not Converge

**Message:** `[Synth 8-3380] loop condition does not converge after !%1! iterations`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL loop runs more than 2000 iterations without terminating — likely an infinite or very long loop.

---

## Common Patterns

### P1: Unbounded / non-terminating loop

**Problematic Code:**
```diff
-- Before: infinite loop
while condition loop  -- condition never becomes false
  ...
end loop;
```

**Recommended Fix:**
```diff
-- After: add proper termination
for i in 0 to 99 loop  -- bounded loop
  exit when done_flag;  -- explicit exit
end loop;
```

---

## Fix Strategy

1. Give the loop a statically bounded iteration count — synthesis must be able to fully unroll it, so `while` loops that depend on runtime data are not allowed.
2. Replace an unbounded `while` with a `for` loop over a constant range, adding `exit when <cond>;` for early termination.
3. Verify the termination condition actually becomes false/true within the bound; an off-by-one or never-updated condition causes non-convergence.
4. For iterative algorithms, move the iteration into clocked state (one step per cycle) instead of an unrollable loop.
