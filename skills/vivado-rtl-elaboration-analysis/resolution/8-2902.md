# 8-2902: Enum Value Doesn't Fit

**Message:** `[Synth 8-2902] value '!%1!' for enum '!%2!' does not fit in enum type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An enum member's explicit value doesn't fit in the declared enum base type width.

---

## Common Patterns

### P1: Enum value wider than the base type

**Problematic Code:**
```diff
// Before: value too wide for enum type
typedef enum bit [3:0] {
  l10 = 32'sb0...01011  // ERROR: 32-bit doesn't fit in 4-bit
} my_enum;
```

**Recommended Fix:**
```diff
// After: use value that fits
typedef enum bit [3:0] {
  l10 = 4'b1011  // fits in 4 bits
} my_enum;
```

---

## Fix Strategy

1. Ensure each enum member's explicit value fits within the declared base-type width (e.g., a 4-bit base holds only `4'b0000`..`4'b1111`).
2. Either reduce the literal to fit (`4'b1011`) or widen the base type (`enum bit [7:0] {...}`) to hold the intended values.
3. Use base-matched literals (`4'bxxxx` for a 4-bit enum) rather than 32-bit constants to avoid accidental overflow.
4. Keep all members consistent with the chosen width so the encoding is unambiguous.
