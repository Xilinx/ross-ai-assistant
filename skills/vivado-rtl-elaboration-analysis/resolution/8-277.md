# 8-277: Exponentiation Not Supported

**Message:** `[Synth 8-277] exponentiation is not supported`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-277] exponentiation is not supported [/path/to/file.v:42]
```

---

## Root Cause

The `**` (power) operator is used in a context where synthesis cannot implement it. While Verilog/VHDL support exponentiation in constant expressions, runtime exponentiation is generally not synthesizable.

---

## Where Exponentiation Works

| Context | Supported |
|---------|-----------|
| Constant expression | Yes |
| Parameter calculation | Yes |
| Runtime operation | No |
| Variable exponent | No |

---

## Common Patterns

### P1: Runtime Exponentiation

```verilog
// Before - runtime power operation
input [7:0] base;
input [3:0] exp;
output [31:0] result;
assign result = base ** exp;  // ERROR: not synthesizable

// After - use lookup table or iterative multiply
// For small ranges, use case statement
always @(*) begin
  case (exp)
    0: result = 1;
    1: result = base;
    2: result = base * base;
    3: result = base * base * base;
    default: result = 0;
  endcase
end
```

### P2: Power of 2 (Special Case)

```verilog
// Before - 2^n calculation
input [3:0] n;
output [15:0] pow2;
assign pow2 = 2 ** n;  // ERROR

// After - use shift for power of 2
assign pow2 = 1 << n;  // Equivalent to 2^n
```

### P3: Constant Exponentiation (This Works)

```verilog
// These are OK - constant expressions
parameter BASE = 2;
parameter EXP = 8;
localparam RESULT = BASE ** EXP;  // OK: 256

// Also OK
localparam SIZE = 2 ** 10;  // OK: 1024
```

### P4: VHDL Power Operation

```vhdl
-- Before - runtime power
signal base : integer;
signal exp : integer;
signal result : integer;
result <= base ** exp;  -- ERROR

-- After - use function for small exponents
function power_of_2(n : integer) return integer is
begin
  return 2 ** n;  -- OK if n is constant
end function;

-- Or use shift
result <= to_integer(shift_left(to_unsigned(1, 32), exp));
```

---

## Fix Strategy

1. For power of 2: use left shift (`<<` or `shift_left`)
2. For small fixed ranges: use case/lookup table
3. For constant values: keep as-is (works)
4. For general power: implement iterative multiplier
