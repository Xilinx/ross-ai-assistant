# 8-1875: Duplicate Default Case

**Message:** `[Synth 8-1875] default case should appear only once`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A case statement has more than one `default` branch.

---

## Common Patterns

### P1: More than one default branch

**Problematic Code:**
```diff
// Before: two default cases
case(sel)
  2'b00: out = a;
  default: out = b;
  default: out = c;  // ERROR: duplicate default
endcase
```

**Recommended Fix:**
```diff
// After: keep only one default
case(sel)
  2'b00: out = a;
  default: out = b;  // single default
endcase
```

---

## Fix Strategy

1. Keep exactly one `default` (Verilog/SystemVerilog) or one `when others` (VHDL) per case statement — remove the duplicate.
2. Merge the behavior of the removed default into the single remaining one if both were meant to handle unmatched values.
3. Check for copy-paste errors or a misplaced `endcase`/`end case` that accidentally left two defaults in the same case.
4. Ensure the single default is the last choice and covers all remaining selector values.
