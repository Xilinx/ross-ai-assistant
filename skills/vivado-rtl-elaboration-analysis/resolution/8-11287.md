# 8-11287: Non-Shared Variable Outside Process

**Message:** `[Synth 8-11287] variable outside a subprogram or process must be 'shared'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL variable declared outside a process or subprogram must be `shared`.

---

## Common Patterns

### P1: Non-shared variable outside a process

**Problematic Code:**
```diff
-- Before: non-shared variable in architecture
architecture rtl of top is
  variable v1 : integer;  -- ERROR: must be shared
begin
```

**Recommended Fix:**
```diff
-- After: add 'shared' or move to process
architecture rtl of top is
  shared variable v1 : integer;  -- add shared
-- Or better: use a signal instead
  signal s1 : integer;
```

---

## Fix Strategy

1. Architecture-level variables must be `shared variable`; add the `shared` keyword, or (preferred) convert to a `signal`.
2. For synthesizable state shared across processes, use a `signal` with a single well-defined driver, not a shared variable.
3. Keep ordinary `variable`s local to a process/subprogram.
4. Avoid shared variables in synthesizable code — their update semantics rarely map to intended hardware.
