# 8-11212: Assignment Pattern to String Type

**Message:** `[Synth 8-11212] target of assignment pattern cannot be a string type; expected an array or structure`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An assignment pattern `'{...}` is used where the target is a `string` type, which is not supported.

---

## Common Patterns

### P1: Assignment pattern to a string

**Problematic Code:**
```diff
// Before: assignment pattern on string target
string s;
s = '{"h", "e"};  // ERROR: string is not array/struct for pattern
```

**Recommended Fix:**
```diff
// After: use direct string assignment
string s;
s = "he";  // direct string literal
```

---

## Fix Strategy

1. Assign a `string` directly (`s = "text";`), not via an assignment pattern `'{...}` (patterns are for arrays/structs).
2. `string` is dynamic and not synthesizable — for hardware, use a fixed-width packed byte vector instead.
3. Keep string handling in simulation-only code.
4. Verify the target type matches the literal form used.
