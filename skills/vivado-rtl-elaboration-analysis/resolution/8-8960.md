# 8-8960: Wrong Number of Dimensions

**Message:** `[Synth 8-8960] identifier needs N dimensions`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An array access uses wrong number of indices for the array's dimensionality.

---

## Common Patterns

### P1: Wrong index count for array

**Problematic Code:**
```diff
// x declared as 2D, accessed with 1 index
assign out = x[0];  // ERROR: x needs 2 dimensions
```

**Recommended Fix:**
```diff
assign out = x[0][0];  // provide both indices
```

---

## Fix Strategy

1. Provide the correct number of indices for the array's dimensionality (a 2D array needs two indices: `x[i][j]`).
2. Check the array declaration to confirm how many packed/unpacked dimensions it has.
3. If you intended a whole sub-array (a slice/row), index down to the right level, or use the appropriate slice syntax.
4. Fix mismatches introduced by changing an array's dimensionality without updating all accesses.
