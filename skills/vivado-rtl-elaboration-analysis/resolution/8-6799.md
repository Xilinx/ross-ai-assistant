# 8-6799: Failed Generic Type Mapping

**Message:** `[Synth 8-6799] Failed Generic Type mapping in component instantiation`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL component instantiation has a generic type mapping that fails.

---

## Common Patterns

### P1: Incompatible generic type mapping

**Problematic Code:**
```diff
-- Before: generic type mapping fails
generic map(T => incompatible_type);  -- ERROR: type doesn't match constraints
```

**Recommended Fix:**
```diff
-- After: use a compatible type
generic map(T => std_logic_vector);  -- check generic constraints
```

---

## Fix Strategy

1. Ensure the actual type passed to a generic type parameter satisfies **all** constraints declared on the formal (e.g., required base type, element type, or width).
2. Check the generic type formal's declaration and supply a compatible, fully-constrained actual type.
3. Confirm the synthesis flow supports VHDL-2008 generic types; if not, replace the generic-type component with a concrete typed version.
4. Verify related generics/ports that depend on the type are consistent with the chosen actual type.
