# 8-11536: Assignment Pattern as Equality Operand

**Message:** `[Synth 8-11536] illegal use of assignment pattern as operand of equality operator`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An assignment pattern `'{...}` is used as an operand of `==` or `!=`, which is not valid.

---

## Common Patterns

### P1: Assignment pattern in an equality

**Problematic Code:**
```diff
// Before: pattern in comparison
if (val == '{1, 2, 3})  // ERROR: pattern not valid as equality operand
```

**Recommended Fix:**
```diff
// After: use concatenation or constant
localparam EXPECTED = '{1, 2, 3};
if (val == EXPECTED)  // compare against named constant
```

---

## Fix Strategy

1. Do not put an assignment pattern `'{...}` directly in `==`/`!=` — store it in a typed constant/variable first, then compare.
2. Compare against a named constant of the same array/struct type.
3. For structs, compare field-by-field if a whole-object comparison is awkward.
4. Ensure both operands are the same type before comparing.
