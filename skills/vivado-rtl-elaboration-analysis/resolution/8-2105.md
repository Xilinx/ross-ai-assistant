# 8-2105: Illegal Cast Operation

**Message:** `[Synth 8-2105] illegal cast operation`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A Verilog/SystemVerilog cast uses incompatible types.

---

## Common Patterns

### P1: Cast between incompatible types

**Problematic Code:**
```diff
// Before: invalid cast
string s;
int x = int'(s);  // ERROR: can't cast string to int
```

**Recommended Fix:**
```diff
// After: use compatible cast
logic [31:0] v;
int x = int'(v);  // OK: compatible types
```

---

## Fix Strategy

1. Cast only between compatible types — e.g., a packed vector to `int` (`int'(vec)`), an enum to its base type, etc.
2. Do not cast between fundamentally different kinds (`string` <-> `int`, `real` <-> bit vector without a conversion function); restructure to avoid the need.
3. For numeric/bit conversions, use the correct construct: `$signed`/`$unsigned`, size casts (`8'(x)`), or `$realtobits`/`$bitstoreal` in simulation-only code.
4. Keep non-synthesizable types (`string`, `chandle`, `real`) out of the synthesized path so illegal casts do not arise.
