# 8-439: Module Not Found

**Message:** `[Synth 8-439] module '!%1!' not found`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-439] module 'my_submodule' not found [/path/to/file.v:100]
```

---

## Root Cause

An instantiated module or entity cannot be found in the design sources. The module name in the instantiation doesn't match any defined module.

### Common Patterns

| Pattern | Symptom | Root Cause |
|---------|---------|------------|
| P1: Typo | Name similar to existing module | Misspelled module name |
| P2: Missing file | Module not in project | Source file not added |
| P3: Library issue | VHDL entity in different library | Missing library reference |
| P4: Case mismatch | Same name, different case | Case-sensitive naming |

---

## Fix Options

### P1: Fix Module Name Typo

```verilog
// Before - typo in module name
my_adder_inst my_ader (  // ERROR: module 'my_ader' not found
  .a(in1),
  .b(in2),
  .sum(out)
);
```

```diff
- my_adder_inst my_ader (
+ my_adder my_adder_inst (   // fix module name
    .a(in1),
    .b(in2),
    .sum(out)
  );
```

### P2: Add Missing Source File

Check if the module file exists and add to project:

```tcl
# In Vivado Tcl
add_files /path/to/missing_module.v
# Or for VHDL
add_files /path/to/missing_entity.vhd
```

Or in project settings, ensure the file is included:
```tcl
read_verilog /path/to/module.v
read_vhdl /path/to/entity.vhd
```

### P3: Fix VHDL Library Reference

```vhdl
-- Before - entity in different library
U0: entity my_module port map(...);  -- ERROR: module 'my_module' not found

-- After - specify correct library
U0: entity work.my_module port map(...);
-- Or if in a different library:
U0: entity mylib.my_module port map(...);
```

### P4: Fix Case Mismatch (VHDL is case-insensitive, Verilog is case-sensitive)

```verilog
// Before - case mismatch
MyModule inst1 (  // ERROR if defined as 'mymodule'
  ...
);

// After - match exact case
mymodule inst1 (
  ...
);
```

---

## Diagnostic Steps

1. Search project for the module name:
   ```tcl
   # In Vivado
   get_files *module_name*
   ```

2. Check if module is in a library:
   ```tcl
   report_compile_order -fileset sources_1
   ```

3. Verify module definition exists and is syntactically correct
