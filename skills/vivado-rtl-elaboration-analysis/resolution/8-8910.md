# 8-8910: Not a Genvar

**Message:** `[Synth 8-8910] '!%1!' is not a genvar`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A variable used in a generate loop is not declared as a genvar.

---

## Common Patterns

### P1: Non-genvar as generate loop variable

**Problematic Code:**
```diff
// Before: regular variable used as genvar
integer j;
generate for (j=0; j<4; j=j+1)  // ERROR: j is not genvar
```

**Recommended Fix:**
```diff
// After: declare as genvar
genvar j;
generate for (j=0; j<4; j=j+1)  // OK
```

---

## Fix Strategy

1. Declare the loop variable of a `generate for` as a `genvar`, not `integer`/`reg`.
2. Place the `genvar` declaration before the `generate` block and use it only for the elaboration-time loop.
3. For runtime loops (in always/process), use a normal variable — but that loop is not a generate loop.
4. Ensure the loop bounds and step use elaboration-time constants alongside the genvar.
