# 8-9312: component instance '!%1!' does not have a primary binding

**Message:** `[Synth 8-9312] component instance '!%1!' does not have a primary binding`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A component instance has no binding to an entity/architecture (no direct or configuration binding found).

---

## Common Patterns

### P1: Component instance has no primary binding

**Problematic Code:**
```vhdl
u : comp port map (...);   -- no entity bound
```

**Recommended Fix:**
```vhdl
u : entity work.ent(rtl) port map (...);   -- direct entity instantiation
```

---

## Fix Strategy

1. Use direct entity instantiation, or add a configuration/binding.
2. Ensure the entity is compiled into the visible library.
3. Match the component name to a real entity.
