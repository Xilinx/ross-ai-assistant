# 8-9873: overwriting previous definition of !%1! '!%2!'

**Message:** `[Synth 8-9873] overwriting previous definition of !%1! '!%2!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A design unit definition overwrites a previous definition of the same name.

---

## Common Patterns

### P1: Overwriting a previous definition

**Problematic Code:**
```vhdl
-- unit 'x' redefined, previous definition overwritten
```

**Recommended Fix:**
```vhdl
-- keep one definition of unit 'x'
```

---

## Fix Strategy

1. Remove the duplicate definition.
2. Ensure unique unit names across the compile set.
3. Verify library/file-list ordering.
