# 8-10180: variable '!%1!' must explicitly be declared as automatic or static

**Message:** `[Synth 8-10180] variable '!%1!' must explicitly be declared as automatic or static`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A variable declared inside a loop/initial block (or in a static task/function) has no lifetime qualifier; SystemVerilog requires it to be explicitly `automatic` or `static` in that context.

---

## Common Patterns

### P1: Variable needs explicit automatic/static lifetime

**Problematic Code:**
```systemverilog
for (int k=0;k<N;k++) begin
  int j = k-1;   // no lifetime qualifier
end
```

**Recommended Fix:**
```systemverilog
for (int k=0;k<N;k++) begin
  automatic int j = k-1;
end
```

---

## Fix Strategy

1. Add `automatic` to block-local variables that are initialized per iteration.
2. Use `static` only if the variable must persist across calls/iterations.
3. Declaring the task/function `automatic` also gives its locals automatic lifetime.
