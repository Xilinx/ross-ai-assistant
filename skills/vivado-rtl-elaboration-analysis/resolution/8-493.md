# 8-493: Design Unit Not Found

**Message:** `[Synth 8-493] no such design unit '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL `entity`, `configuration`, or `component` reference cannot find the specified design unit.

---

## Common Patterns

### P1: Entity/component not compiled or misnamed

**Problematic Code:**
```diff
-- Before: entity not found
U1: entity work.dut port map(...);  -- ERROR: 'dut' not in 'work'
```

**Recommended Fix:**
```diff
-- After: compile the entity first or fix the name
-- Ensure dut.vhd is compiled before this file
-- Or fix the entity name
```

---

## Fix Strategy

1. Ensure the referenced entity/architecture/component source file is added to the project and **compiled into the correct library** (usually `work`) before the file that uses it.
2. Fix any name/library typo — `entity work.dut` must match the compiled entity name and library exactly.
3. Check the compile order; the design unit must be analyzed before its instantiation in a file-order-sensitive flow.
4. If it comes from a separate library, add that library and reference it explicitly (`library mylib; ... mylib.dut`).
