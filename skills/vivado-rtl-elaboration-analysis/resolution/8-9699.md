# 8-9699: Invalid Use of Void Function

**Message:** `[Synth 8-9699] invalid use of void function`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A void function's return value is used in an expression.

---

## Common Patterns

### P1: Void function used as a value

**Problematic Code:**
```diff
assign out = sum(a, b);  // ERROR: sum is void (no return)
```

**Recommended Fix:**
```diff
// Change to non-void function:
function int sum(int a, b); return a+b; endfunction
assign out = sum(a, b);
```

---

## Fix Strategy

1. A `void` function returns nothing — give it a return type (`function int f(...)`) if you use its result in an expression.
2. If the routine should produce outputs but not a single return value, make it a `task`/`void function` with `output`/`ref` arguments and call it as a statement.
3. Do not use a void function call as an operand; call it standalone for its side effects.
4. Match the caller's expectation (value vs. statement) to the subprogram's kind.
