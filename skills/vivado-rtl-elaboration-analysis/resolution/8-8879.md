# 8-8879: '!%1!' expects at least !%2! arguments

**Message:** `[Synth 8-8879] '!%1!' expects at least !%2! arguments`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A system task/function is called with fewer arguments than it requires.

---

## Common Patterns

### P1: System task/function missing arguments

**Problematic Code:**
```verilog
$display();   // expects at least a format/arg
```

**Recommended Fix:**
```verilog
$display("%d", value);
```

---

## Fix Strategy

1. Provide all required arguments for the system task/function.
2. Check the expected argument count in the message.
3. Remove the call if it is not needed in RTL.
