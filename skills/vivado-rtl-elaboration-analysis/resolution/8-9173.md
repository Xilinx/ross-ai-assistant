# 8-9173: Attribute Not a Range

**Message:** `[Synth 8-9173] attribute 'base' is not a range`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL attribute that returns a type (not a range) is used where a range is expected.

---

## Common Patterns

### P1: 'base attribute used as a range

**Problematic Code:**
```diff
for i in T'base loop  -- ERROR: 'base returns type, not range
```

**Recommended Fix:**
```diff
for i in T'range loop  -- use range attribute
-- Or: for i in T'base'range loop
```

---

## Fix Strategy

1. Use a **range** attribute where a range is expected: `T'range` (or `T'reverse_range`), not `T'base` which yields the base type.
2. For explicit bounds, use `T'left`/`T'right`/`T'low`/`T'high`.
3. If you truly need the base type's range, chain the attributes: `T'base'range`.
4. Verify the loop/slice uses a discrete range compatible with the array/type being iterated.
