# 8-9767: Multiple Dimensions in Gate

**Message:** `[Synth 8-9767] multiple dimensions in gate instantiation is not allowed in this mode of Verilog`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Gate instantiation uses multiple dimensions.

---

## Common Patterns

### P1: Multi-dimensional gate array

**Problematic Code:**
```diff
and g[3:0][1:0](out, in1, in2);  // ERROR: multi-dim gate array
```

**Recommended Fix:**
```diff
and g[3:0](out, in1, in2);  // single dimension
```

---

## Fix Strategy

1. Use a single-dimension gate-array instantiation (`and g[3:0](...)`), not a multi-dimensional one.
2. To replicate gates across two dimensions, use nested `generate for` loops instantiating one gate each.
3. Flatten the intended 2D structure into a 1D range if a gate array is required.
4. Prefer RTL (`assign`/always) over primitive gate arrays for maintainability and portability.
