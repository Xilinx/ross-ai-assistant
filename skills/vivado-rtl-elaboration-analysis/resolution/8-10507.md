# 8-10507: attribute '!%1!' is already specified; last one will take precedence

**Message:** `[Synth 8-10507] attribute '!%1!' is already specified; last one will take precedence`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The same attribute is specified more than once on an object; only the last specification takes effect.

---

## Common Patterns

### P1: Attribute already specified

**Problematic Code:**
```verilog
(* keep = "true", keep = "false" *) wire w;
```

**Recommended Fix:**
```verilog
(* keep = "true" *) wire w;
```

---

## Fix Strategy

1. Specify each attribute only once per object.
2. Remove the duplicate; keep the intended value.
3. This is a warning - the last value wins.
