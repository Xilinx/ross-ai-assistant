# 8-11145: root scope declaration is not allowed in Verilog 95/2K mode

**Message:** `[Synth 8-11145] root scope declaration is not allowed in Verilog 95/2K mode`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `$unit`/root-scope declaration is used while compiling in Verilog-95/2001 mode, which does not support it.

---

## Common Patterns

### P1: Root scope declaration not allowed in Verilog 95/2K

**Problematic Code:**
```systemverilog
int g;   // at $root scope, in Verilog-2001 mode
```

**Recommended Fix:**
```systemverilog
// move 'g' into a module/package, or compile as SystemVerilog
```

---

## Fix Strategy

1. Move the declaration into a module or package.
2. Or set the file language to SystemVerilog if root-scope items are intended.
3. Verilog-95/2001 has no compilation-unit scope.
