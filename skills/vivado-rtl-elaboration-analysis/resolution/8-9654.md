# 8-9654: Not an Array Type

**Message:** `[Synth 8-9654] indexed name prefix type is not an array type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Array indexing is applied to a non-array type.

---

## Common Patterns

### P1: Indexing a non-array type

**Problematic Code:**
```diff
type t1 is record ... end record;
signal s : t1;
s(0) <= val;  -- ERROR: t1 is not array
```

**Recommended Fix:**
```diff
s.field_name <= val;  -- use field access for records
```

---

## Fix Strategy

1. Do not index a non-array type — use field access (`.field`) for records, or index only actual arrays/vectors.
2. If the object should be an array, change its type/declaration to an array before indexing.
3. Check for a typo where an index was applied to a scalar/record instead of the intended array.
4. Verify the prefix's type is an array type at the point of indexing.
