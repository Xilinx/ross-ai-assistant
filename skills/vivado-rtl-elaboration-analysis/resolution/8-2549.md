# 8-2549: Positional After Named Association

**Message:** `[Synth 8-2549] positional association cannot follow named association`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL positional association follows named association in a port/generic map.

---

## Common Patterns

### P1: Positional association after a named one

**Problematic Code:**
```diff
-- Before: positional after named
port map(a => sig1, sig2);  -- ERROR
```

**Recommended Fix:**
```diff
-- After: use all named
port map(a => sig1, b => sig2);
```

---

## Fix Strategy

1. In VHDL, once a named association appears in a `port map`/`generic map`, every following association must also be named.
2. Simplest fix: make **all** associations named (`port map(a => sig1, b => sig2)`).
3. Alternatively keep all associations positional — but named is preferred for clarity and robustness.
4. Ensure each named formal exists in the entity/component and no port is left unassociated.
