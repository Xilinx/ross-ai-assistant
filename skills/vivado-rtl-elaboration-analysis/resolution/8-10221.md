# 8-10221: Failed to Resolve External Name

**Message:** `[Synth 8-10221] Failed to resolve external name`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10221] Failed to resolve external name [/path/to/file:NN]
```

---

## Root Cause

A VHDL-2008 external name (`<< signal path >>`) references a hierarchical path that cannot be resolved during synthesis.

---

## Common Patterns

### P1: Unresolvable external name

**Problematic Code:**
```diff
-- Before: external name reference (not synthesizable)
int_rel_out <= << signal sub.intern : std_logic >>;
int_abs_out <= << signal .top.sub.intern : std_logic >>;
```

**Recommended Fix:**
```diff
-- After: bring the signal out through ports
-- In sub entity, add output port:
--   intern_out : out std_logic
-- In top, connect:
int_rel_out <= sub_intern_out;
int_abs_out <= sub_intern_out;
```

---

## Fix Strategy

1. External names (`<< signal ... >>`) are not synthesizable — bring the signal out through the module/entity port hierarchy instead.
2. Add an output port on the sub-unit and connect it upward to where the value is needed.
3. Avoid reaching into sub-hierarchy by path; route all cross-module data through ports.
4. Keep any genuine external-name usage in simulation/verification code only.
