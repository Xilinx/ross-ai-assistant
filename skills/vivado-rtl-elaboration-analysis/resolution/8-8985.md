# 8-8985: Input Mode Cannot Be Updated

**Message:** `[Synth 8-8985] input with mode 'in' cannot be updated`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL input port is assigned a value.

---

## Common Patterns

### P1: Assignment to an input port

**Problematic Code:**
```diff
port (vhgatedandin2 : in std_logic);
vhgatedandin2 <= '1';  -- ERROR: mode in
```

**Recommended Fix:**
```diff
port (vhgatedandin2 : inout std_logic);  -- change to inout
-- Or: port (vhgatedandin2 : out std_logic);
```

---

## Fix Strategy

1. An `in` port cannot be assigned — change its mode to `out` (if it is produced here) or `inout` (if genuinely bidirectional).
2. If the value should come from outside, remove the internal assignment and drive the intended internal signal instead.
3. For bidirectional pins, declare `inout` and drive through proper tri-state control.
4. Check for a naming mix-up where the assignment targeted the input port rather than an internal net.
