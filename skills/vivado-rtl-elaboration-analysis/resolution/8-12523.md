# 8-12523: type mark '!%1!' cannot be prefix of selected name

**Message:** `[Synth 8-12523] type mark '!%1!' cannot be prefix of selected name`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A type mark is used as the prefix of a selected name (`type.member`), which is illegal.

---

## Common Patterns

### P1: Type mark cannot prefix a selected name

**Problematic Code:**
```vhdl
y <= my_type.field;   -- 'my_type' is a type, not an object
```

**Recommended Fix:**
```vhdl
y <= my_signal.field;  -- select from an object of that type
```

---

## Fix Strategy

1. Select from an object (signal/variable) of the type, not the type itself.
2. Use a properly declared record/object as the prefix.
3. Check for a type name used where an object was intended.
