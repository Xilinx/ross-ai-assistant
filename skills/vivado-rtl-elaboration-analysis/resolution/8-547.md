# 8-547: port direction mismatch for port 'RON'

**Message:** `[Synth 8-547] port direction mismatch for port 'RON'`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

The direction of a signal connected to a port does not match the port's declared
direction. Typically an entity/module `out` (or `inout`) port is connected to a
signal that is also being driven inside the instantiating unit, or an `in` port
is connected to a signal that the parent expects to drive from the child — the
driver directions conflict.

---

## Common Patterns

### P1: Output port connected to a signal also driven locally

**Problematic Code:**
```vhdl
-- 'RON' is an OUTPUT of entity VJ, but the parent also reads/drives Rin
UUT : VJ PORT MAP (RON => Rin);

PROCESS(Rin)          -- parent uses Rin as if it were an input
BEGIN
  ...
END PROCESS;
```

**Fix — use a dedicated net for the output and read that:**
```vhdl
signal ron_out : std_logic;      -- driven only by the instance
UUT : VJ PORT MAP (RON => ron_out);

PROCESS(ron_out)                 -- parent consumes the instance output
BEGIN
  ...
END PROCESS;
```

### P2: Port declared with the wrong direction

**Fix — correct the entity/module port direction so it matches its real use:**
```vhdl
entity VJ is
  port (
    RON : out std_logic       -- was 'in'; make it match how it is driven
  );
end entity;
```

---

## Fix Strategy

1. Confirm the port's intended direction in the child entity/module (`in` / `out` / `inout`) and make sure the parent uses the connected signal accordingly — do not drive a signal that is fed by an `out` port, and do not read from a signal only meant to feed an `in` port.
2. If the direction is genuinely wrong, fix the port declaration in the child so it matches how the signal is used.
3. Give output ports their own dedicated nets in the parent instead of reusing a signal that the parent also drives.
4. For `inout`/bidirectional connections, ensure both sides agree on the bidirectional direction and use proper tri-state drivers; otherwise pick a single direction.
