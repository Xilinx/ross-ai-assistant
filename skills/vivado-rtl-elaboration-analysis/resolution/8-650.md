# 8-650: Too Many Ports

**Message:** `[Synth 8-650] too many ports for instance`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL instantiation has more port associations than the entity/component has ports.

---

## Common Patterns

### P1: More port associations than entity ports

**Problematic Code:**
```diff
-- Before: extra ports
U1: my_comp port map(a, b, c, d);  -- ERROR: my_comp has only 3 ports
```

**Recommended Fix:**
```diff
-- After: match port count
U1: my_comp port map(a, b, c);
```

---

## Fix Strategy

1. Match the number of port associations to the entity/component's actual port count — remove the extra one(s).
2. Use **named** association (`port => signal`) instead of positional so an extra/mis-ordered connection is obvious.
3. Verify you are instantiating the intended, current entity/component; a stale component declaration with fewer ports is a common cause.
4. If the extra signal is genuinely needed, add the corresponding port to the entity rather than forcing it onto the instance.
