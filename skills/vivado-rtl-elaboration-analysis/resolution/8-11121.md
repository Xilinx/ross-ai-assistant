# 8-11121: redeclaration of ANSI port '!%1!' is not allowed

**Message:** `[Synth 8-11121] redeclaration of ANSI port '!%1!' is not allowed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An ANSI-style port (declared in the module header) is redeclared in the body, which is not allowed.

---

## Common Patterns

### P1: Redeclaration of ANSI port

**Problematic Code:**
```verilog
module m(input a); input a;   // redeclared
```

**Recommended Fix:**
```verilog
module m(input a);   // header declaration is enough
```

---

## Fix Strategy

1. Remove the redundant body redeclaration of an ANSI header port.
2. Use either ANSI header ports or old-style body declarations, not both.
3. Keep the type/direction only in the header for ANSI style.
