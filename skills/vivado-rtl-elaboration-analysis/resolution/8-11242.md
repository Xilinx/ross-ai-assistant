# 8-11242: unexpected 'default'

**Message:** `[Synth 8-11242] unexpected 'default'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `default` keyword appears where it is not expected (e.g. outside a valid case/pattern context).

---

## Common Patterns

### P1: Unexpected 'default'

**Problematic Code:**
```systemverilog
y = default;   // not in a case/assignment-pattern context
```

**Recommended Fix:**
```systemverilog
case (s) default: y = 0; endcase
```

---

## Fix Strategy

1. Use `default` only in a `case` item or an assignment pattern.
2. Remove the misplaced `default`.
3. Check for a missing `case`/pattern around it.
