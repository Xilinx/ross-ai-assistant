# 8-6828: Ref Args Require Automatic

**Message:** `[Synth 8-6828] task or function '!%1!' with ref arguments must be automatic`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A task/function with `ref` arguments must be declared `automatic`.

---

## Common Patterns

### P1: ref argument without automatic lifetime

**Problematic Code:**
```diff
// Before: static task with ref
task my_task(ref int a);  // ERROR: needs automatic
  a = a + 1;
endtask
```

**Recommended Fix:**
```diff
// After: add automatic
task automatic my_task(ref int a);
  a = a + 1;
endtask
// Note: ref ports are not synthesizable
```

---

## Fix Strategy

1. Add the `automatic` lifetime to any task/function that has `ref` arguments (`task automatic ...`).
2. For synthesizable RTL, avoid `ref` arguments entirely — pass values via `input`/`output` arguments instead.
3. If the subprogram is recursive or reentrant, `automatic` is required regardless of `ref`; make sure locals are automatic.
4. Confirm the flow supports the construct — `ref` and dynamic-lifetime subprograms are largely verification-only.
