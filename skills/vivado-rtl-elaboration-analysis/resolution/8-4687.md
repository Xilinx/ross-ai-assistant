# 8-4687: Bad Record Element Constraint

**Message:** `[Synth 8-4687] bad record element constraint`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL record element constraint is malformed or invalid.

---

## Common Patterns

### P1: Malformed record element constraint

**Problematic Code:**
```diff
-- Before: invalid constraint on record field
type my_rec is record
  data : std_logic_vector;  -- unconstrained field
end record;
signal s : my_rec(data(7 downto 0));  -- ERROR: bad constraint syntax
```

**Recommended Fix:**
```diff
-- After: constrain in type or subtype
type my_rec is record
  data : std_logic_vector(7 downto 0);  -- constrained in type
end record;
```

---

## Fix Strategy

1. Constrain record fields **in the type definition** (`data : std_logic_vector(7 downto 0);`) so the record is fully constrained where it is declared.
2. If using VHDL-2008 element constraints on an unconstrained record, use the correct subtype-indication syntax and ensure the tool is in 2008 mode.
3. Avoid unconstrained array fields in synthesizable records unless the flow supports constraining them at the object; prefer fully-constrained types.
4. Verify each field's constraint is locally static and matches how the field is used.
