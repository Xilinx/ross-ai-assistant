# 8-4752: Not Uninstantiated Subprogram

**Message:** `[Synth 8-4752] source of subprogram instantiation is not an uninstantiated subprogram`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL subprogram instantiation source is not a generic (uninstantiated) subprogram.

---

## Common Patterns

### P1: Instantiating a non-generic subprogram

**Problematic Code:**
```diff
-- Before: instantiating non-generic subprogram
procedure p is new regular_proc generic map(...);  -- ERROR
```

**Recommended Fix:**
```diff
-- After: use a generic subprogram as source
-- Ensure the source procedure is declared with 'generic'
```

---

## Fix Strategy

1. Only **generic (uninstantiated) subprograms** can be instantiated with `is new ... generic map(...)` — make the source procedure/function a generic subprogram.
2. If the source is a regular subprogram, call it directly rather than instantiating it.
3. Confirm the referenced name resolves to a subprogram and is visible in the current scope.
4. Verify the synthesis flow supports VHDL-2008 generic subprograms; if not, refactor to plain subprograms.
