# 8-9250: Cannot Index into Non-Array

**Message:** `[Synth 8-9250] cannot index into non-array type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Array indexing is applied to a non-array type.

---

## Common Patterns

### P1: Index applied to a scalar

**Problematic Code:**
```diff
wire netArray;
assign out = netArray[0];  // ERROR: scalar wire, not array
```

**Recommended Fix:**
```diff
wire [7:0] netArray;  // make it an array
assign out = netArray[0];
```

---

## Fix Strategy

1. Declare the signal as an array/vector before indexing it (`wire [7:0] x;` then `x[0]`).
2. If the object is a scalar, remove the index; if you need multiple bits, widen its declaration.
3. For structs/records, use field access (`.field`) instead of indexing.
4. Check for a typo where an index was applied to the wrong (scalar) signal.
