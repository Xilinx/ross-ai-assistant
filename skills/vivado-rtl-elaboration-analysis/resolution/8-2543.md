# 8-2543: Mixed Ordered/Named Port Connections

**Message:** `[Synth 8-2543] port connections cannot be mixed ordered and named`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Port connections mix positional and named styles.

---

## Common Patterns

### P1: Mixed positional/named port connections

**Problematic Code:**
```diff
// Before: mixed port styles
my_mod inst(clk, .data(d));  // ERROR: can't mix
```

**Recommended Fix:**
```diff
// After: use one style
my_mod inst(.clk(clk), .data(d));  // all named
```

---

## Fix Strategy

1. Use one consistent connection style — either all **named** (`.clk(clk), .data(d)`) or all **positional** (`clk, d`), never a mix.
2. Prefer **named** connections: order-independent, self-documenting, and resilient to port additions/reordering.
3. Convert any stray positional entries to named form to resolve the mix.
4. After converting, verify each named port exists on the module and no port is left unintentionally unconnected.
