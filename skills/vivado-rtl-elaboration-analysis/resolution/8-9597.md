# 8-9597: Illegal Randomize Method

**Message:** `[Synth 8-9597] illegal randomize method`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The `randomize()` method is used in a synthesis context — it's simulation-only.

---

## Common Patterns

### P1: randomize() in synthesizable code

**Problematic Code:**
```diff
result = obj.randomize();  // ERROR: not synthesizable
```

**Recommended Fix:**
```diff
// Replace with deterministic logic for synthesis
result = counter;  // use counter or LFSR
```

---

## Fix Strategy

1. `randomize()` is simulation/verification-only — remove it from synthesizable RTL.
2. For pseudo-random hardware, use an LFSR or counter with a defined seed instead.
3. Keep constrained-random stimulus in the testbench, not the design under test.
4. Replace the randomized value with deterministic logic that meets the design's needs.
