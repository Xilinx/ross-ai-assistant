# 8-316: Illegal Module Recursion

**Message:** `[Synth 8-316] illegal module recursion detected`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-316] illegal module recursion detected [/path/to/file.v:42]
```

---

## Root Cause

A module instantiates itself directly or indirectly, creating infinite recursion. Hardware cannot be infinitely recursive - all hierarchy must be finite.

---

## Common Patterns

### P1: Direct Self-Instantiation

```verilog
// Before - module instantiates itself unconditionally
module recursive_mod (input clk, output data);
  wire sub_data;
  
  recursive_mod inst (  // ERROR: infinite recursion
    .clk(clk),
    .data(sub_data)
  );
  
  assign data = sub_data;
endmodule
```

### P2: Indirect Recursion (A -> B -> A)

```verilog
// Module A instantiates B
module mod_a (...);
  mod_b b_inst (...);
endmodule

// Module B instantiates A - creates cycle
module mod_b (...);
  mod_a a_inst (...);  // ERROR: indirect recursion
endmodule
```

### P3: Recursive Generate Without Termination

```verilog
// Before - generate without base case
module tree #(parameter DEPTH = 4) (...);
  generate
    // Missing: if (DEPTH > 0)
    tree #(.DEPTH(DEPTH-1)) left (...);
    tree #(.DEPTH(DEPTH-1)) right (...);
  endgenerate
endmodule
```

---

## Fix Options

### Option 1: Add Generate Termination Condition

```verilog
// After - proper recursive generate
module tree #(parameter DEPTH = 4) (
  input clk,
  input [7:0] in,
  output [7:0] out
);
  generate
    if (DEPTH == 0) begin : leaf
      // Base case - no more recursion
      assign out = in;
    end else begin : branch
      wire [7:0] left_out, right_out;
      tree #(.DEPTH(DEPTH-1)) left (.clk(clk), .in(in), .out(left_out));
      tree #(.DEPTH(DEPTH-1)) right (.clk(clk), .in(in), .out(right_out));
      assign out = left_out ^ right_out;
    end
  endgenerate
endmodule
```

### Option 2: Unroll Recursion Manually

```verilog
// Instead of recursive instantiation, instantiate each level explicitly
module tree_level0 (...);
  // leaf implementation
endmodule

module tree_level1 (...);
  tree_level0 left (...);
  tree_level0 right (...);
endmodule

module tree_level2 (...);
  tree_level1 left (...);
  tree_level1 right (...);
endmodule
```

### Option 3: Break Circular Dependency

```verilog
// Before: A -> B -> A (circular)
// After: A -> B -> C (linear)
```
