# 8-5535: Illegal Port Connection to Input Buffer

**Message:** `[Synth 8-5535] port <!%1!> has illegal connections. It is illegal to have a port connected to an input buffer and other components. The following are the port connections : !%2!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A port has illegal connections, typically an input buffer connected incorrectly.

---

## Common Patterns

### P1: Internal signal driving a top-level input

**Problematic Code:**
```diff
// Before: input buffer with illegal connection
```

**Recommended Fix:**
```diff
// After: check that input ports connect to proper nets
// Don't drive an input port from internal logic
// Ensure top-level input ports connect to package pins only
```

---

## Fix Strategy

1. Top-level input ports may only be driven by the external world (package pins) — do not assign to an input port from internal logic.
2. If internal logic needs to drive a signal, use an internal net or an `output`/`inout` port, not an `input`.
3. Check the I/O buffer insertion — an input port feeding an IBUF must not also be driven internally; separate the driver and the observed net.
4. For bidirectional behavior, declare the port `inout` and use a proper tri-state driver rather than forcing an input.
