# 8-9174: Attribute Requires Static Prefix

**Message:** `[Synth 8-9174] attribute 'event' requires a static signal prefix`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The `'event` attribute is applied to a non-static or non-signal expression.

---

## Common Patterns

### P1: 'event on a non-static prefix

**Problematic Code:**
```diff
if (sig(i)'event)  -- ERROR: sig(i) is not static
```

**Recommended Fix:**
```diff
if (sig'event)  -- use static signal name
```

---

## Fix Strategy

1. Apply `'event`/`'stable` to a **static signal name** (`clk'event`), not to a dynamically-indexed or computed expression.
2. For edge detection, prefer `rising_edge(clk)`/`falling_edge(clk)` on the base clock signal.
3. If you need per-element edges, restructure so each element is a separate named signal, or register and compare values instead.
4. Ensure the prefix resolves to a single, statically-known signal at elaboration.
