# 8-10976: Multiple Packed Dimensions in Verilog

**Message:** `[Synth 8-10976] multiple packed dimensions are not allowed in this mode of Verilog`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10976] multiple packed dimensions are not allowed in this mode of Verilog [/path/to/file:NN]
```

---

## Root Cause

Multiple packed dimensions (`[5:0][2:0]`) require SystemVerilog mode. Standard Verilog only allows one packed dimension.

---

## Common Patterns

### P1: Multiple packed dimensions in Verilog

**Problematic Code:**
```diff
// Before: multiple packed dimensions in Verilog mode
input [5:0][2:0] d;    // ERROR: not allowed in Verilog mode
```

**Recommended Fix:**
```diff
// After: flatten or use SystemVerilog
input [17:0] d;         // flatten: 6*3 = 18 bits
// Or compile with -sv flag:
// read_verilog -sv file.v
```

---

## Fix Strategy

1. Use a single packed dimension in Verilog mode; flatten multiple packed dimensions into one (`[A*B-1:0]`).
2. If multi-dimensional packed arrays are intended, compile in SystemVerilog mode (`read_verilog -sv`).
3. Index the flattened vector with computed offsets if you keep Verilog mode.
4. Verify downstream accesses match the chosen (flattened or SV multi-dim) layout.
