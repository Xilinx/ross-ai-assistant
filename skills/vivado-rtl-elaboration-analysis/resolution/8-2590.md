# 8-2590: Non-Static Range in Scalar Type

**Message:** `[Synth 8-2590] range constraint in scalar type definition must be locally static`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL scalar type definition has a range constraint that is not locally static.

---

## Common Patterns

### P1: Non-static range in a type definition

**Problematic Code:**
```diff
-- Before: non-static range
signal n : integer;
type my_range is range 0 to n;  -- ERROR: n is not static
```

**Recommended Fix:**
```diff
-- After: use constant range
constant N : integer := 100;
type my_range is range 0 to N;  -- static
```

---

## Fix Strategy

1. Make scalar type/subtype range bounds **locally static** — use `constant`s or `generic`s, not signals/variables.
2. If the range must be configurable, drive it from a generic that is fixed at elaboration (`generic (N : integer)` then `range 0 to N`).
3. Do not derive a type's range from runtime signal values; compute the needed constant at elaboration instead.
4. Verify any function used in the bound is a pure constant function evaluable at elaboration.
