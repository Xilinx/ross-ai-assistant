# 8-10829: illegal initialization of non-singular port '!%1!'

**Message:** `[Synth 8-10829] illegal initialization of non-singular port '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A composite (array/record) port is given an initial value at its declaration, which is not allowed for non-singular ports.

---

## Common Patterns

### P1: Illegal initialization of non-singular port

**Problematic Code:**
```vhdl
port ( d : in bus_array := (others => '0') );  -- composite init
```

**Recommended Fix:**
```vhdl
port ( d : in bus_array );  -- drive the default from outside instead
```

---

## Fix Strategy

1. Remove the initializer from the composite port declaration.
2. Provide default values through the connected signal or an unconnected-default mechanism.
3. Scalar ports may keep simple defaults; composite ones may not here.
