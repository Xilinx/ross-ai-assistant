# 8-9249: Packed Dimensions of Unpacked Type

**Message:** `[Synth 8-9249] cannot have packed dimensions of unpacked type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A packed dimension is applied to a type that is unpacked (struct, union without packed).

---

## Common Patterns

### P1: Packed dimension on unpacked type

**Problematic Code:**
```diff
myStruc1 [3:0] arr;  // ERROR: unpacked struct can't have packed dim
```

**Recommended Fix:**
```diff
myStruc1 arr [3:0];  // unpacked dimension (after name)
// Or make struct packed:
typedef struct packed {...} myStruc1;
```

---

## Fix Strategy

1. Put dimensions of an unpacked type **after** the name as unpacked dimensions (`myStruct arr [3:0];`), not as packed dimensions before it.
2. If you need a packed array of the type, make the type itself `packed` (`typedef struct packed {...} myStruct;`) then a packed dimension is legal.
3. Decide packed vs. unpacked based on whether you need bit-level contiguity (packed) or an array of elements (unpacked).
4. Verify downstream accesses match the chosen packed/unpacked layout.
