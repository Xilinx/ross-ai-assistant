# 8-2680: Sliced Name on Multi-Dimensional Array

**Message:** `[Synth 8-2680] sliced name is allowed only on single-dimensional arrays`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL slice notation is used on a multi-dimensional array, which only supports single-dimensional slicing.

---

## Common Patterns

### P1: Slice on a multi-dimensional array

**Problematic Code:**
```diff
-- Before: slice on multi-dimensional
type arr2d is array(0 to 3, 0 to 7) of integer;
signal a : arr2d;
a(0 to 1) <= ...;  -- ERROR: multi-dim not sliceable
```

**Recommended Fix:**
```diff
-- After: use single-dimensional array or index
type arr1d is array(0 to 3) of std_logic_vector(7 downto 0);
signal a : arr1d;
a(0 to 1) <= ...;  -- single-dim slice OK
```

---

## Fix Strategy

1. Slice only single-dimensional arrays; for a true multi-dimensional array (`array(a, b)`), you cannot take a range across a dimension.
2. Restructure as an array-of-arrays (`array(0 to 3) of std_logic_vector(7 downto 0)`) so slicing on the outer dimension is legal.
3. To operate on part of a multi-dim array, index individual elements in a loop rather than slicing.
4. Choose the data structure based on how you access it — array-of-vectors is usually the synthesizable, sliceable form.
