# 8-9101: Homograph Already Declared

**Message:** `[Synth 8-9101] a homograph is already declared in this region`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Two subprograms with the same signature exist in the same scope.

---

## Common Patterns

### P1: Duplicate subprogram signature

**Problematic Code:**
```diff
procedure genericproc(a:integer);
procedure genericproc(a:integer);  -- ERROR: duplicate
```

**Recommended Fix:**
```diff
-- Remove the duplicate declaration
procedure genericproc(a:integer);
```

---

## Fix Strategy

1. Remove the duplicate subprogram declaration, or change one signature (different parameter types/count) so the two are distinguishable overloads.
2. Two subprograms with identical signatures in the same region are homographs — not allowed; keep only one.
3. If both behaviors are needed, rename one or move it to a separate package/scope.
4. Check for accidental copy-paste of the same declaration.
