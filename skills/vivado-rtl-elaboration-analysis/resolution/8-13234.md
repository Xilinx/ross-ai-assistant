# 8-13234: Distributed RAM Attribute Cannot Be Applied

**Message:** `[Synth 8-13234] ram_style = distributed set but attribute cannot be applied`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

The `distributed` ram_style attribute can't be applied because the RAM pattern doesn't support it.

---

## Common Patterns

### P1: distributed style unsupported for RAM

**Problematic Code:**
```diff
attribute ram_style of RAM_reg : signal is "distributed";  -- WARNING
```

**Recommended Fix:**
```diff
-- Use "block" instead, or fix the RAM coding pattern
attribute ram_style of RAM_reg : signal is "block";
```

---

## Fix Strategy

1. Distributed RAM cannot implement every pattern — use `ram_style = "block"` for larger/asymmetric memories, or restructure to a distributed-friendly shape (small, LUT-sized).
2. Verify the memory size/access pattern actually supports distributed RAM before forcing it.
3. If BRAM is acceptable, drop the `distributed` attribute and let the tool choose.
4. Confirm the resulting implementation in the synthesis report.
