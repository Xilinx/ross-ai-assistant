# 8-11365: Instance Port Mismatch

**Message:** `[Synth 8-11365] for the instance '!%1!' of module '!%2!' declared at '!%3!:!%4!', named port connection '!%5!' does not exist`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A module instance has port connections that don't match the module definition (e.g., ports left unconnected without proper syntax).

---

## Common Patterns

### P1: Instance port connection mismatch

**Problematic Code:**
```diff
// Before: instance with mismatched ports
dut U1(.clk(clk), .in1(data));  // ERROR: missing required ports
```

**Recommended Fix:**
```diff
// After: connect all ports
dut U1(.clk(clk), .in1(data), .out1(result));  // all ports connected
```

---

## Fix Strategy

1. Connect all module ports; for intentionally unused inputs, tie to a constant, and for unused outputs, leave them open explicitly.
2. Use named connections so mismatched/unconnected ports are obvious.
3. Verify the instance's port names, widths, and directions match the module definition.
4. Confirm the instantiated module version matches the expected port list.
