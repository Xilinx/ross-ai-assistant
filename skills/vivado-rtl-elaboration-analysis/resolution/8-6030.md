# 8-6030: Inout Without Tristate

**Message:** `[Synth 8-6030] Inout pin is read and/or written without using tristate logic`
**Severity:** CRITICAL WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An inout port is used without proper tristate (`Z`/high-impedance) control.

---

## Common Patterns

### P1: inout driven without tristate

**Problematic Code:**
```diff
-- Before: inout without tristate
port (a : inout std_logic);
a <= data_out;  -- WARNING: no Z state
```

**Recommended Fix:**
```diff
-- After: add tristate control
a <= data_out when oe = '1' else 'Z';
```

---

## Fix Strategy

1. Drive `inout` ports through explicit tri-state logic: `pad <= drive_val when oe = '1' else 'Z';` (VHDL) / `assign pad = oe ? drive_val : 1'bz;` (Verilog).
2. Read the pin from the port itself (or a separate input path), and only drive it when the output-enable is asserted.
3. Ensure the design never drives the pad and reads a driven value simultaneously without the tri-state control.
4. Treat this CRITICAL WARNING seriously — an inout without proper tri-state can cause contention on the physical pin.
