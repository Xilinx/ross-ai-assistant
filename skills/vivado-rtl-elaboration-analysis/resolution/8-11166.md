# 8-11166: signed/unsigned conversion for real expression

**Message:** `[Synth 8-11166] signed/unsigned conversion for real expression`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A signed/unsigned conversion is applied to a real-valued expression, which has no bit representation for the conversion.

---

## Common Patterns

### P1: signed/unsigned conversion of a real expression

**Problematic Code:**
```systemverilog
int i = signed'(r);   // r is real
```

**Recommended Fix:**
```systemverilog
int i = int'(r);      // convert real to int first
```

---

## Fix Strategy

1. Convert the real to an integral type before signed/unsigned casting.
2. Avoid real types in the synthesizable path.
3. Use `int'(...)`/`$rtoi` for real-to-integer conversion.
