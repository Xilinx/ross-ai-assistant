# 8-3301: Unused Top-Level Parameter

**Message:** `[Synth 8-3301] Unused top level parameter/generic`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A top-level generic/parameter is declared but never used in the design.

---

## Common Patterns

### P1: Declared but unused top-level generic

**Problematic Code:**
```diff
-- Before: unused generic
generic (C_INIT_FILE : string := "");  -- WARNING: unused
```

**Recommended Fix:**
```diff
-- After: remove if unneeded or use in logic
-- Remove unused generics from top-level entity
```

---

## Fix Strategy

1. This is informational — remove the unused top-level generic/parameter if it serves no purpose.
2. If it is meant to configure logic, actually reference it (e.g., use it in a width, initial value, or `generate` condition).
3. Keep intentionally-exposed configuration parameters even if unused internally, but document why (e.g., IP-level compatibility) to justify the warning.
4. For parameters consumed only by sub-modules, ensure they are passed down via generic/parameter maps so they are not flagged as unused.
