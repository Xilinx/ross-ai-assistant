# 8-421: Array Size Mismatch in Assignment

**Message:** `[Synth 8-421] mismatched array sizes in rhs and lhs of assignment`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL array assignment has different sizes on left and right sides.

---

## Common Patterns

### P1: Width mismatch in array assignment

**Problematic Code:**
```diff
-- Before: size mismatch
signal a : std_logic_vector(7 downto 0);
signal b : std_logic_vector(3 downto 0);
a <= b;  -- ERROR: 8 bits vs 4 bits
```

**Recommended Fix:**
```diff
-- After: match sizes
a <= "0000" & b;  -- pad to match
-- Or: a(3 downto 0) <= b;  -- partial assignment
```

---

## Fix Strategy

1. Make the left- and right-hand side widths equal: use slicing (`a(3 downto 0) <= b`), padding (`a <= "0000" & b`), or the numeric `resize()` function.
2. For `signed`/`unsigned`, use `resize(unsigned(b), a'length)` (or `signed`) so sign/zero extension is explicit and correct.
3. If the mismatch is unintended, fix the declaration of one side so both arrays share the same range.
4. Assign sub-ranges explicitly when only part of the target should be driven, and ensure the remaining bits are otherwise defined to avoid latches/undriven bits.
