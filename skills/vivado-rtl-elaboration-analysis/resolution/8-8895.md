# 8-8895: '!%1!' is already implicitly declared on line !%2!

**Message:** `[Synth 8-8895] '!%1!' is already implicitly declared on line !%2!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An identifier was already implicitly declared (as a net) earlier, and is now re-declared, causing a conflict.

---

## Common Patterns

### P1: Identifier already implicitly declared

**Problematic Code:**
```verilog
assign a = b;   // implicitly declares 'a'
wire a;         // conflict
```

**Recommended Fix:**
```verilog
wire a;
assign a = b;   // declare explicitly first
```

---

## Fix Strategy

1. Declare nets explicitly before use to avoid implicit declaration.
2. Use `` `default_nettype none `` to catch implicit nets.
3. Remove the duplicate/late declaration.
