# 8-2908: Range Width Must Be Positive

**Message:** `[Synth 8-2908] range width must be a positive integer`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A range width specification is zero or negative.

---

## Common Patterns

### P1: Zero or negative range width

**Problematic Code:**
```diff
// Before: zero or negative range width
logic [0:-1] data;  // ERROR: negative width
```

**Recommended Fix:**
```diff
// After: use positive width
logic [7:0] data;  // positive width
```

---

## Fix Strategy

1. Ensure every declared range has a positive width — for a descending range `[MSB:LSB]`, `MSB >= LSB`; for ascending `[LSB:MSB]`, `MSB >= LSB`.
2. Check parameters/expressions that compute the bounds — an off-by-one or a `WIDTH` of 0 yields a non-positive width; guard or correct them.
3. If a zero-width element is conceptually valid (e.g., a generic set to 0), guard it with a `generate`/conditional so no zero-width declaration is emitted.
4. Verify MSB/LSB order matches the intended bit numbering after the fix.
