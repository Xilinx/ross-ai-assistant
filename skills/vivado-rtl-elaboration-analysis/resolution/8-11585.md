# 8-11585: Value Exceeds Integer Range

**Message:** `[Synth 8-11585] Evaluated value has exceeded beyond integer type range`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A computed value overflows the integer type range.

---

## Common Patterns

### P1: Value exceeds integer range

**Problematic Code:**
```diff
constant LARGE : integer := 2**40;  -- WARNING: overflows 32-bit integer
```

**Recommended Fix:**
```diff
constant LARGE : unsigned(39 downto 0) := (others => '0');  -- use unsigned for large values
```

---

## Fix Strategy

1. Use `unsigned`/`signed`/`std_logic_vector` for values beyond 32-bit `integer` range.
2. Compute wide intermediates in a sufficiently wide type, then resize to the target.
3. Check exponent/shift expressions that can overflow the integer range.
4. Add saturation or a wider accumulator where values can legitimately grow large.
