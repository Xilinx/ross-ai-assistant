# 8-9571: Circular Dependency

**Message:** `[Synth 8-9571] illegal circular dependency found`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A type definition circularly references itself.

---

## Common Patterns

### P1: Self-referential type definition

**Problematic Code:**
```diff
typedef struct {st_t next;} st_t;  // ERROR: circular
```

**Recommended Fix:**
```diff
typedef struct {int next_idx;} st_t;  // break circularity
```

---

## Fix Strategy

1. Break the circular type dependency — a type cannot contain a direct instance of itself.
2. Replace the self-reference with an index/handle (`int next_idx;`) or a fixed-depth structure.
3. Recursive/linked data structures are not synthesizable; model them with arrays indexed by pointers-as-integers.
4. Check for two types that reference each other and restructure to remove the cycle.
