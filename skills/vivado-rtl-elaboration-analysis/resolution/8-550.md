# 8-550: Port Width Mismatch in Instance Array

**Message:** `[Synth 8-550] port width mismatch in instance array for port '!%1!': actual width = !%2!, formal width = !%3!, instance count = !%4!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An instance array has port width mismatch between actual and formal.

---

## Common Patterns

### P1: Instance-array port width mismatch

**Problematic Code:**
```diff
// Before: width mismatch in instance array
my_mod inst[3:0](.out(bus16));  // bus16=16 bits, but 4 instances * 4-bit port = 16 expected
```

**Recommended Fix:**
```diff
// After: match widths
wire [3:0] out_arr [0:3];  // per-instance output
my_mod inst[3:0](.out(out_arr));
```

---

## Fix Strategy

1. For an instance array `inst[N-1:0]`, the connected signal width for a port must equal `N * formal_port_width` (bits are distributed one slice per instance).
2. Fix the connection by sizing the net correctly — use an unpacked array of per-instance nets or a packed vector of the exact total width.
3. If you actually want the **same** signal on every instance, connect a signal whose width equals the single-instance port width (it is then broadcast), not `N` times that width.
4. Prefer named connections and double-check whether broadcast vs. per-instance slicing is intended before restructuring.
