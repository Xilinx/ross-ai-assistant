# 8-6735: Net Type Must Be Explicit

**Message:** `[Synth 8-6735] net type must be explicitly specified for '!%1!' when default_nettype is none`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

When `default_nettype none` is set, all nets must have explicit type declarations.

---

## Common Patterns

### P1: Implicit net with default_nettype none

**Problematic Code:**
```diff
// Before: implicit net with default_nettype none
`default_nettype none
module m(input in1);  // ERROR: in1 type not explicit
```

**Recommended Fix:**
```diff
// After: declare net type explicitly
`default_nettype none
module m(input wire in1);  // explicit 'wire'
```

---

## Fix Strategy

Add explicit `wire` or `logic` type to all port and net declarations when using `default_nettype none`.
