# 8-11155: Non-Static Signal in Sensitivity List

**Message:** `[Synth 8-11155] sensitivity list can only have static signal names`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL sensitivity list contains a non-static signal name (e.g., indexed or sliced name that is not static).

---

## Common Patterns

### P1: Non-static signal in sensitivity list

**Problematic Code:**
```diff
-- Before: non-static name in sensitivity list
process(sig(i))  -- ERROR: dynamic index in sensitivity
begin
  out1 <= sig(i);
end process;
```

**Recommended Fix:**
```diff
-- After: use static signal name
process(sig)     -- use entire array
begin
  out1 <= sig(i);
end process;
```

---

## Fix Strategy

1. Use **static** (non-indexed, non-sliced) signal names in a sensitivity list.
2. To be sensitive to a whole array, list the array name, or use `process(all)` (VHDL-2008).
3. Do not put dynamically-indexed elements (`sig(i)`) in the sensitivity list.
4. For combinational processes, `process(all)` avoids incomplete/illegal sensitivity lists.
