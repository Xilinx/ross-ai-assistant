# 8-8742: Protected Type in Generic

**Message:** `[Synth 8-8742] !%1! '!%2!' cannot be associated with formal interface type '!%3!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL protected type is associated with a formal interface type, which is not allowed.

---

## Common Patterns

### P1: Protected type as a generic actual

**Problematic Code:**
```diff
-- Before: protected type as generic actual
generic map(t1 => mytype);  -- ERROR: mytype is protected
```

**Recommended Fix:**
```diff
-- After: use a synthesizable type
generic map(t1 => integer);  -- synthesizable type
```

---

## Fix Strategy

1. Protected types are not synthesizable — do not pass them as generic type actuals; use a synthesizable type (`integer`, `std_logic_vector`, a record, etc.).
2. If the protected type modeled shared state, redesign that state as ordinary signals/registers with explicit access logic.
3. Keep any genuine protected-type usage in simulation-only code, out of the synthesized path.
4. Verify the generic's constraints are satisfied by the chosen synthesizable actual type.
