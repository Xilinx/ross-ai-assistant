# 8-2415: Alias Nets Must Be Type Compatible

**Message:** `[Synth 8-2415] nets connected in alias statement must be type compatible`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Nets connected with `alias` must have compatible types.

---

## Common Patterns

### P1: alias between nets of different width

**Problematic Code:**
```diff
// Before: incompatible alias types
wire [7:0] a;
wire [15:0] b;
alias a = b;  // ERROR: different widths
```

**Recommended Fix:**
```diff
// After: match types
wire [7:0] a;
wire [7:0] b;
alias a = b;  // same type
```

---

## Fix Strategy

1. Alias only nets of **identical** type and width — declare both sides the same (`wire [7:0]` on both).
2. If widths legitimately differ, do not alias; use a continuous `assign` with an explicit slice/pad instead.
3. Ensure both aliased objects are net types (`wire`/`tri`); aliasing variables is a different error (8-1576).
4. Reconsider whether the alias is needed — a direct connection is often clearer and avoids type-compatibility pitfalls.
