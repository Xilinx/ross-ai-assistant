# 8-9386: Element Not in Record

**Message:** `[Synth 8-9386] element is not in record type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL record field name doesn't exist in the record type.

---

## Common Patterns

### P1: Reference to a non-existent record field

**Problematic Code:**
```diff
sig.pst <= val;  -- ERROR: 'pst' not a field of record type
```

**Recommended Fix:**
```diff
sig.state <= val;  -- use correct field name
```

---

## Fix Strategy

1. Use the exact field name from the record type definition (`sig.state`, not `sig.pst`).
2. Open the record type declaration and confirm the available field names (case matters where applicable).
3. Fix typos in the field access; if the field should exist, add it to the record type.
4. Ensure you are accessing the intended record type (not a similarly-named one).
