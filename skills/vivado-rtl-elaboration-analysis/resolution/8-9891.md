# 8-9891: Resolution Function Parameter Issue

**Message:** `[Synth 8-9891] parameter of resolution function is not an unconstrained array`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL resolution function's parameter must be an unconstrained array of the resolved type.

---

## Common Patterns

### P1: Constrained resolution-function parameter

**Problematic Code:**
```diff
function resolvfunc(s : std_logic_vector) return std_logic;  -- ERROR: needs unconstrained
```

**Recommended Fix:**
```diff
function resolvfunc(s : std_logic_vector) return std_logic is
-- Ensure parameter is unconstrained array of the resolved type
```

---

## Fix Strategy

1. Declare the resolution function's parameter as an **unconstrained array** of the resolved element type (e.g., `function f(s : std_logic_vector) return std_logic`).
2. Do not constrain the array parameter — the resolver must accept any number of drivers.
3. Return the resolved element type, matching the subtype that uses the function.
4. Note that custom resolution functions are rarely synthesizable; prefer standard `std_logic` resolution.
