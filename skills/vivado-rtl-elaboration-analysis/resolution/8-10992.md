# 8-10992: Port Definition Not Found

**Message:** `[Synth 8-10992] no definition could be found for port`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10992] no definition could be found for port [/path/to/file:NN]
```

---

## Root Cause

A port declared in the module header has no corresponding `input`/`output`/`inout` declaration, or a `specparam` name conflicts.

---

## Common Patterns

### P1: Header port with no declaration

**Problematic Code:**
```diff
// Before: specparam used as port name
specify
  specparam check_limit = 10;
  $removal(posedge in, check_limit);  // check_limit is specparam, not port
endspecify
```

**Recommended Fix:**
```diff
// After: ensure all ports have definitions
module top(in1, out1);
  input in1;
  output out1;
  // specparams stay inside specify blocks — don't confuse with ports
```

---

## Fix Strategy

1. Ensure every port listed in the module header has a matching `input`/`output`/`inout` declaration.
2. Do not confuse `specparam`/parameter names with port names — they are separate namespaces.
3. Fix typos so header names and body direction declarations agree.
4. Prefer ANSI-style headers (declare direction inline) to avoid header/body mismatch.
