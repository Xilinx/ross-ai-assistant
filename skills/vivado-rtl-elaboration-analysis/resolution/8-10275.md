# 8-10275: $bits system function cannot have an argument of type real

**Message:** `[Synth 8-10275] $bits system function cannot have an argument of type real`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The `$bits` system function was given an argument of type `real` (or `shortreal`). `$bits` requires a bit-stream (integral) type; real has no defined bit width for it.

---

## Common Patterns

### P1: $bits argument cannot be real

**Problematic Code:**
```systemverilog
real r;
int n = $bits(r);   // real not allowed
```

**Recommended Fix:**
```systemverilog
logic [63:0] r_bits;
int n = $bits(r_bits);   // use an integral type
```

---

## Fix Strategy

1. Pass an integral/bit-stream type to `$bits`, not a real.
2. If you need the storage size of a real, use a fixed 32/64-bit vector model instead.
3. Real types are non-synthesizable; remove real from the synthesizable path.
