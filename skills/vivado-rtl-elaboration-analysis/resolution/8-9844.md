# 8-9844: Non-Net Input Port

**Message:** `[Synth 8-9844] non-net port cannot be of mode input`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An input port is declared with a variable type in a context requiring net type.

---

## Common Patterns

### P1: reg used for an input port

**Problematic Code:**
```diff
module m(input reg in1);  // ERROR in some Verilog modes
```

**Recommended Fix:**
```diff
module m(input wire in1);  // wire for input
// Or: module m(input logic in1);  // SV mode
```

---

## Fix Strategy

1. Declare input ports as a **net** type — `wire` in Verilog, `logic`/`wire` in SystemVerilog — not `reg`.
2. Inputs are driven externally, so they cannot be variables; use `reg`/`logic` only for internally-driven signals.
3. In SystemVerilog, `input logic` is fine; in strict Verilog, use `input wire`.
4. Check for an accidental `reg` on a port that should be a net.
