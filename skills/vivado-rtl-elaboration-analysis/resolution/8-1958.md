# 8-1958: event expressions must result in a singular type

**Message:** `[Synth 8-1958] event expressions must result in a singular type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An event control expression resolves to a non-singular (composite) type; event expressions must be singular.

---

## Common Patterns

### P1: Event expression must be singular

**Problematic Code:**
```systemverilog
always @(struct_sig) ...   // composite in event
```

**Recommended Fix:**
```systemverilog
always @(struct_sig.field) ...   // a singular sub-element
```

---

## Fix Strategy

1. Sensitize to singular signals (scalars/vectors), not whole composites.
2. List individual elements in the event control.
3. Use `always @*` to auto-build the sensitivity list.
