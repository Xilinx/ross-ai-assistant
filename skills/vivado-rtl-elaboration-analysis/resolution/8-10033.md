# 8-10033: Missing Record Elements in Aggregate

**Message:** `[Synth 8-10033] some record elements are missing in this aggregate of 'rectype'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10033] some record elements are missing in this aggregate of 'rectype' [/path/to/file:NN]
```

---

## Root Cause

A VHDL record aggregate does not provide values for all fields of the record type.

---

## Common Patterns

### P1: Record aggregate missing fields

**Problematic Code:**
```diff
-- Before: record aggregate missing fields
type rec_t is record
  r1 : std_logic_vector(3 downto 0);
  r2 : integer;
end record;
variable var1 : rec_t := (r1 => "1010");  -- ERROR: r2 missing
```

**Recommended Fix:**
```diff
-- After: provide all fields or use others
variable var1 : rec_t := (r1 => "1010", r2 => 0);
-- Or use others:
variable var1 : rec_t := (r1 => "1010", others => 0);
```

---

## Fix Strategy

1. Provide a value for **every** field of the record aggregate.
2. Use `others => <default>` to fill any remaining fields in one place (`(r1 => "1010", others => 0)`).
3. Prefer named field association so a missing field is immediately visible.
4. For nested records, ensure each sub-aggregate is likewise complete.
