# 8-9664: Input Cannot Have Type Conversion

**Message:** `[Synth 8-9664] input designator cannot contain a formal type-conversion`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL input port has a type conversion on the formal side.

---

## Common Patterns

### P1: Type conversion on a formal input

**Problematic Code:**
```diff
port map(std_logic_vector(f) => sig);  -- ERROR: conversion on formal input
```

**Recommended Fix:**
```diff
port map(f => std_logic_vector(sig));  -- conversion on actual side
```

---

## Fix Strategy

1. Put any type conversion on the **actual** side of an input port association (`port map(f => std_logic_vector(sig))`), not on the formal.
2. Formal-side conversions are only permitted for outputs; inputs must have the conversion applied to the actual expression.
3. Prefer connecting a pre-converted intermediate signal to keep the port map simple.
4. Ensure the converted type/width matches the formal input port.
