# 8-9195: Bit-Select in Force Not Allowed

**Message:** `[Synth 8-9195] bit-select or part-select is not allowed in a force statement for non-net`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `force` statement targets a bit-select of a variable.

---

## Common Patterns

### P1: force on a variable bit-select

**Problematic Code:**
```diff
force c[0] = 1;  // ERROR: bit-select force on non-net
```

**Recommended Fix:**
```diff
force c = val;  // force entire signal
// Note: force is simulation-only
```

---

## Fix Strategy

1. `force` on a bit/part-select of a **variable** is illegal — force the entire variable, or make the target a `net` if a bit-select force is truly needed.
2. `force`/`release` are simulation-only; remove them from synthesizable RTL and model the override with real logic (mux/enable).
3. If this is testbench code, force the whole signal or a net bit-select, keeping it out of the synthesized path.
4. Prefer a normal assignment over `force` wherever possible.
