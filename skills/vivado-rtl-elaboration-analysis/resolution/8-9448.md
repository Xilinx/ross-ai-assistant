# 8-9448: extra semicolon in $unit (global) scope

**Message:** `[Synth 8-9448] extra semicolon in $unit (global) scope`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An extra semicolon appears at the compilation-unit ($unit/global) scope.

---

## Common Patterns

### P1: Extra semicolon in $unit scope

**Problematic Code:**
```systemverilog
;   // stray semicolon at global scope
```

**Recommended Fix:**
```systemverilog
// remove the stray global-scope semicolon
```

---

## Fix Strategy

1. Remove the extra semicolon at global scope.
2. Keep only real declarations at $unit scope.
3. Check for a leftover `;` after an include/define.
