# 8-2088: ignoring unknown pragma value !%1!

**Message:** `[Synth 8-2088] ignoring unknown pragma value !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A pragma carries a value the tool does not know, so the pragma value is ignored.

---

## Common Patterns

### P1: Ignoring unknown pragma value

**Problematic Code:**
```verilog
// synthesis unknown_attr = xyz
```

**Recommended Fix:**
```verilog
// remove or correct the unrecognized pragma value
```

---

## Fix Strategy

1. Remove or correct the unrecognized pragma value.
2. Use Vivado-supported pragmas/attributes.
3. This is a warning; the value is ignored.
