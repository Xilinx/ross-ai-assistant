# 8-2551: possible infinite loop; process does not have a wait statement

**Message:** `[Synth 8-2551] possible infinite loop; process does not have a wait statement`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A process has no sensitivity list and no `wait` statement, so it would run forever without suspending.

---

## Common Patterns

### P1: Process has no wait (possible infinite loop)

**Problematic Code:**
```vhdl
process begin
  a <= b;
end process;   -- never suspends
```

**Recommended Fix:**
```vhdl
process (b) begin
  a <= b;
end process;   -- or add wait;
```

---

## Fix Strategy

1. Add a sensitivity list or a `wait` statement so the process suspends.
2. For combinational logic use `process(all)`/an explicit list.
3. For a one-shot init process, end it with `wait;`.
