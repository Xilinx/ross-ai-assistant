# 8-9398: empty port in !%1! declaration

**Message:** `[Synth 8-9398] empty port in !%1! declaration`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A port list contains an empty port (e.g. a trailing/stray comma).

---

## Common Patterns

### P1: Empty port in declaration

**Problematic Code:**
```verilog
module m(a, , b);   // empty port
```

**Recommended Fix:**
```verilog
module m(a, b);
```

---

## Fix Strategy

1. Remove the empty port / stray comma from the port list.
2. Ensure every port position has a name.
3. Check for a deleted port that left a comma.
