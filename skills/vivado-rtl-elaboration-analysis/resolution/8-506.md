# 8-506: Null Port Ignored

**Message:** `[Synth 8-506] null port ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A port with null/empty name is ignored.

---

## Common Patterns

### P1: Null/empty port association

**Problematic Code:**
```diff
-- Before: null port in instance
port map(FaultInjectECC => open);  -- WARNING if null
```

**Recommended Fix:**
```diff
-- After: properly handle unused ports
-- Omit the port entirely or use 'open' for outputs
```

---

## Fix Strategy

1. Remove the null/empty port association from the port map entirely.
2. For unused **outputs**, map them to `open` (VHDL) or leave them unconnected (Verilog) explicitly.
3. For unused **inputs**, tie them to a defined constant so they are not left floating.
4. Confirm the null port was not meant to carry a real signal — an accidental empty association silently drops connectivity.
