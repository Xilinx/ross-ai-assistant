# 8-9372: direction of port '!%1!' does not match that in extern !%2! declaration

**Message:** `[Synth 8-9372] direction of port '!%1!' does not match that in extern !%2! declaration`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A port's direction differs from that in the module's `extern` declaration.

---

## Common Patterns

### P1: Port direction mismatches extern declaration

**Problematic Code:**
```systemverilog
extern module m(input a);
module m(output a); ...   // direction differs
```

**Recommended Fix:**
```systemverilog
extern module m(input a);
module m(input a); ...
```

---

## Fix Strategy

1. Make the port directions in the definition match the `extern` declaration exactly.
2. Keep extern and definition prototypes in sync.
3. Fix whichever prototype is wrong.
