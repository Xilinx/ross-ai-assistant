# 8-211: Could Not Evaluate Expression

**Message:** `[Synth 8-211] could not evaluate expression: !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-211] could not evaluate expression: my_func(x) [/path/to/file.v:42]
```

---

## Root Cause

The synthesis tool cannot evaluate an expression that must be known at elaboration time. This occurs when:
- Function has dependencies on runtime values
- Expression involves unsupported operations
- Circular dependencies exist
- Expression references undefined symbols

---

## Common Patterns

### P1: Function with Runtime Input

```verilog
// Before - function called with signal
function integer calc_width;
  input integer depth;
  calc_width = $clog2(depth);
endfunction

input [7:0] runtime_depth;
localparam WIDTH = calc_width(runtime_depth);  // ERROR

// After - use constant input
parameter DEPTH = 256;
localparam WIDTH = calc_width(DEPTH);
```

### P2: Undefined Reference

```verilog
// Before - DEPTH not defined
localparam SIZE = DEPTH * 2;  // ERROR: DEPTH undefined

// After - define before use
parameter DEPTH = 16;
localparam SIZE = DEPTH * 2;
```

### P3: Circular Parameter Dependency

```verilog
// Before - circular
localparam A = B + 1;
localparam B = A + 1;  // ERROR: circular

// After - break circularity
localparam A = 5;
localparam B = A + 1;  // B = 6
```

### P4: Unsupported Operation in Constant Context

```verilog
// Before - division by variable
parameter X = 100;
input [7:0] y;
localparam RESULT = X / y;  // ERROR: y not constant

// After - use constant divisor
parameter X = 100;
parameter Y = 4;
localparam RESULT = X / Y;  // Works
```

---

## Fix Strategy

1. Ensure all inputs to the expression are constants
2. Check for undefined symbols
3. Verify no circular dependencies
4. Replace runtime values with parameters
