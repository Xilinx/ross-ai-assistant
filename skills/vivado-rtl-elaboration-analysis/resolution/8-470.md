# 8-470: Interface Not Found

**Message:** `[Synth 8-470] no interface '!%1!' found`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A SystemVerilog interface referenced in a port or instantiation doesn't exist.

---

## Common Patterns

### P1: Reference to an undeclared interface

**Problematic Code:**
```diff
// Before: non-existent interface
module m(idResolInDefiNameSpace_3.modp port1);  // ERROR: interface not found
```

**Recommended Fix:**
```diff
// After: declare the interface first
interface idResolInDefiNameSpace_3;
  ...
endinterface
// Or fix the interface name
```

---

## Fix Strategy

1. Declare the interface and ensure the file defining it is added to the project and **compiled before** the modules that reference it.
2. Fix the interface name/typo so it matches the `interface ... endinterface` declaration exactly (names are case-sensitive).
3. Check compile order / file set — in a single-file flow, put the interface definition ahead of its users; in a project flow, make sure the file is included.
4. If the interface lives in a package, `import` that package before use.
