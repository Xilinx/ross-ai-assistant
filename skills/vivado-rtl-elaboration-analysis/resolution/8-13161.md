# 8-13161: RAM Optimized Away

**Message:** `[Synth 8-13161] RAM is optimized away because it doesn't have a valid read/write`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A RAM has no valid read or write port and is removed during optimization.

---

## Common Patterns

### P1: RAM optimized away

**Problematic Code:**
```diff
// RAM_reg optimized away — no read or write
```

**Recommended Fix:**
```diff
-- Ensure RAM has both read and write operations
-- Check that address and data signals are properly connected
```

---

## Fix Strategy

1. Ensure the RAM has functioning read **and** write paths — a memory with no effective read or write is optimized away.
2. Verify the write-enable and address/data connections are actually driven by real logic.
3. Confirm the read data reaches a used output; if nothing consumes it, connect it.
4. If the RAM is intentional (debug), mark it `(* dont_touch = "true" *)`; otherwise treat removal as a missing-connection bug.
