# 8-27: Not Supported

**Message:** `[Synth 8-27] !%1! not supported`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-27] 'feature_name' not supported [/path/to/file.v:42]
```

---

## Root Cause

The RTL uses a language construct, feature, or syntax that is not supported by Vivado synthesis. This could be:
- SystemVerilog features not supported for synthesis
- VHDL constructs not synthesizable
- Vendor-specific extensions
- Simulation-only constructs

---

## Common Unsupported Constructs

| Category | Examples |
|----------|----------|
| Timing | `#delay`, `wait`, `fork/join` |
| Dynamic | Dynamic arrays, queues, associative arrays |
| Object-oriented | Classes, virtual interfaces |
| File I/O | `$fopen`, `$fwrite`, `$readmem` (in some contexts) |
| Assertions | `assert`, `assume`, `cover` (for synthesis) |

---

## Fix Options

### Option 1: Remove Unsupported Construct

```verilog
// Before - timing delay not synthesizable
always @(posedge clk) begin
  #10 data_out <= data_in;  // ERROR: '#' not supported
end
```

```diff
  always @(posedge clk) begin
-   #10 data_out <= data_in;
+   data_out <= data_in;  // remove delay
  end
```

### Option 2: Use Synthesizable Alternative

```verilog
// Before - dynamic array
int data[];  // ERROR: dynamic array not supported

// After - fixed-size array
int data[256];
```

### Option 3: Wrap in Synthesis Pragma

```verilog
// Before - simulation-only code mixed with synthesis
initial begin
  $readmemh("data.hex", memory);  // ERROR in synthesis
end

// After - use synthesis translate_off
// synthesis translate_off
initial begin
  $readmemh("data.hex", memory);
end
// synthesis translate_on
```
