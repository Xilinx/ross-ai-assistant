# 8-8882: No Port on Task Call

**Message:** `[Synth 8-8882] '!%1!' has no port called '!%2!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A task is called with a named port that doesn't exist in the task definition.

---

## Common Patterns

### P1: Wrong argument name in task call

**Problematic Code:**
```diff
// Before: wrong port name in task call
task_demo(.tin1(val));  // ERROR: no port 'tin1'
```

**Recommended Fix:**
```diff
// After: use correct port name
task_demo(.in1(val));  // matches task definition
```

---

## Fix Strategy

1. Use the exact argument names from the task definition in a named call (`task_demo(.in1(val))`).
2. Open the task declaration and match names, order, and directions of its arguments.
3. Fix typos in the named-argument connections; prefer named binding so mismatches are obvious.
4. Confirm you are calling the intended task (not a same-named one from another scope).
