# 8-6850: RAM (v_bram_tdp_be_arw_rf_brw_nc_01_03_inst/RAM...

**Message:** `[Synth 8-6850] RAM (v_bram_tdp_be_arw_rf_brw_nc_01_03_inst/RAM_reg) has partial Byte Wide Write Enable pattern with ram_style = "block", however no output register found in fanout of RAM. Recommended to use supported Byte Wide Write Enable template.`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A Block RAM using a partial **byte-wide write-enable** pattern has no output
register in its fanout. The supported byte-write BRAM template requires a
registered output; without it the memory may not map efficiently or correctly.

---

## Common Patterns

### P1: Byte-write BRAM without output register

**Problematic Code:**
```diff
-- RAM (v_bram_tdp_be_arw_rf_brw_nc_01_03_inst/RAM_reg) has partial Byte Wide Write Enable pattern with ram_style = "block", however no output register found in fanout of RAM. Recommended to use supported Byte Wide Write Enable template.
```

**Recommended Fix:**
```verilog
// Add an output register on the RAM read data (byte-write template needs it)
always @(posedge clk) begin
  if (we[0]) RAM[addr][7:0]  <= din[7:0];
  if (we[1]) RAM[addr][15:8] <= din[15:8];
  rd  <= RAM[addr];
  dout <= rd;                 // extra output register -> supported template
end
```

---

## Fix Strategy

1. Add an **output register** on the RAM read data — the supported byte-wide write-enable BRAM template requires a registered output in the fanout.
2. Register the read data one additional stage (`rd <= RAM[addr]; dout <= rd;`) so the byte-write pattern maps cleanly to BRAM.
3. Keep the byte-enable writes synchronous and consistent with the UG901 byte-write template.
4. Re-check the synthesis report to confirm the RAM now implements as a proper byte-write BRAM.
