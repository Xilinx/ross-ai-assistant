# 8-2056: Time-Controlled Statement in Function

**Message:** `[Synth 8-2056] functions cannot contain time-controlled statements`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A Verilog function contains a time-controlled statement (`#delay`, `@event`, `wait`).

---

## Common Patterns

### P1: Timing control inside a function

**Problematic Code:**
```diff
// Before: delay in function
function [7:0] calc;
  input [7:0] a;
  #10 calc = a + 1;  // ERROR: time control in function
endfunction
```

**Recommended Fix:**
```diff
// After: remove time control
function [7:0] calc;
  input [7:0] a;
  calc = a + 1;  // no delay
endfunction
```

---

## Fix Strategy

1. Remove all time/event control (`#delay`, `@(...)`, `wait`) from the function — functions must execute in zero time and are purely combinational.
2. If the logic needs sequencing, move it into a clocked `always` block and call the function only for the combinational part.
3. Do not substitute a task with delays — tasks with timing are also unsynthesizable; model timing with clocked state instead.
4. Ensure the function has no side effects beyond computing its return value so it maps to combinational hardware.
