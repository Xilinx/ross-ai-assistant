# 8-2496: Packed Dimension Needs Range

**Message:** `[Synth 8-2496] packed dimension must specify a range`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A packed dimension must specify an explicit range (e.g., `[7:0]`), not just a size.

---

## Common Patterns

### P1: Packed dimension without a range

**Problematic Code:**
```diff
// Before: packed dimension without range
logic [] data;  // ERROR: must specify range
```

**Recommended Fix:**
```diff
// After: specify range
logic [7:0] data;  // explicit range
```

---

## Fix Strategy

1. Give every packed dimension an explicit range `[MSB:LSB]` (e.g., `logic [7:0] data;`), never an empty `[]`.
2. Reserve unsized `[]` for **dynamic arrays** (an unpacked, non-synthesizable construct) — do not use it for packed vectors.
3. Parameterize the width with a `localparam`/`parameter` (`logic [WIDTH-1:0] data;`) so the range stays explicit and configurable.
4. Verify the intended width and bit order (descending `[N-1:0]` is conventional).
