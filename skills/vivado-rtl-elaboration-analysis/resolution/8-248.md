# 8-248: Slice Direction Mismatch

**Message:** `[Synth 8-248] direction of slice does not match direction of prefix`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-248] direction of slice does not match direction of prefix [/path/to/file.vhd:42]
```

---

## Root Cause

In VHDL, when taking a slice of an array or vector, the slice direction (to/downto) must match the original declaration's direction.

---

## Example

```vhdl
-- Signal declared with 'downto'
signal data : std_logic_vector(7 downto 0);

-- ERROR: slice uses 'to' but signal uses 'downto'
result <= data(0 to 3);

-- CORRECT: slice uses matching 'downto'
result <= data(3 downto 0);
```

---

## Common Patterns

### P1: Mismatched Slice in Assignment

```vhdl
-- Before
signal bus : std_logic_vector(15 downto 0);
signal nibble : std_logic_vector(3 downto 0);

nibble <= bus(0 to 3);  -- ERROR: direction mismatch

-- After
nibble <= bus(3 downto 0);  -- CORRECT
```

### P2: Mismatched in Port Map

```vhdl
-- Entity port
port (
  data_in : in std_logic_vector(7 downto 0)
);

-- Before - wrong direction
inst: my_module port map(
  data_in => bus(0 to 7)  -- ERROR
);

-- After - correct direction
inst: my_module port map(
  data_in => bus(7 downto 0)
);
```

### P3: Array with 'to' Direction

```vhdl
-- Declared with 'to'
type mem_t is array (0 to 15) of std_logic_vector(7 downto 0);
signal mem : mem_t;

-- Slice must use 'to'
signal subset : mem_t(0 to 7);  -- CORRECT (for compatible type)

-- For vector portions
signal word : std_logic_vector(7 downto 0);
word <= mem(5)(7 downto 0);  -- Inner slice uses 'downto' to match element type
```

---

## Fix Strategy

1. Check the original declaration's direction
2. Match the slice direction to the declaration
3. For `downto`: larger index first (7 downto 0)
4. For `to`: smaller index first (0 to 7)

---

## Direction Rules

| Declaration | Slice Example | Valid |
|-------------|---------------|-------|
| `(7 downto 0)` | `(3 downto 0)` | Yes |
| `(7 downto 0)` | `(0 to 3)` | No |
| `(0 to 7)` | `(0 to 3)` | Yes |
| `(0 to 7)` | `(3 downto 0)` | No |
