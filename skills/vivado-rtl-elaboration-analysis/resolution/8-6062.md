# 8-6062: Asymmetric RAM Ratio Mismatch

**Message:** `[Synth 8-6062] Asymetric Ram !%1! width ratio of !%2! doesn't match depth ratio !%3!. Address size difference is !%4!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Asymmetric RAM width ratio doesn't match depth ratio.

---

## Common Patterns

### P1: Inconsistent asymmetric RAM ratios

**Problematic Code:**
```diff
// Before: width ratio 4 but depth ratio 1
// Read port: 32-bit, Write port: 8-bit (ratio 4)
// But address spaces don't reflect the 4:1 depth ratio
```

**Recommended Fix:**
```diff
// After: match ratios per UG901
// Width ratio of 4 needs depth ratio of 4
// Read addr = Write addr width + 2 (for ratio 4)
```

---

## Fix Strategy

Ensure asymmetric RAM width and depth ratios are consistent. Follow UG901 guidelines for address width adjustments.
