# 8-10616: No Match for Subprogram

**Message:** `[Synth 8-10616] could not find a match for subprogram`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10616] could not find a match for subprogram [/path/to/file:NN]
```

---

## Root Cause

A VHDL function/procedure call doesn't match any visible declaration — wrong argument types, count, or missing package import.

---

## Common Patterns

### P1: No matching subprogram signature

**Problematic Code:**
```diff
-- Before: resize called with wrong arguments
out1 <= resize(in1);       -- ERROR: missing size argument
out2 <= resize(in1, in2);  -- ERROR: in2 is signal, need integer
```

**Recommended Fix:**
```diff
-- After: use correct signature
use ieee.numeric_std.all;
out1 <= resize(unsigned(in1), 8);    -- provide target size as integer
out2 <= resize(unsigned(in1), in2'length);
```

---

## Fix Strategy

Check the function signature in the package. Ensure argument types and count match. For `resize`, provide both the value and target size.
