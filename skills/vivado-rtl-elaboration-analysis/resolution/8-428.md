# 8-428: Missing Elements in Aggregate

**Message:** `[Synth 8-428] missing elements in aggregate or subelement association`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL aggregate is missing some elements or sub-element associations.

---

## Common Patterns

### P1: Incomplete aggregate

**Problematic Code:**
```diff
-- Before: incomplete aggregate
type rec is record a,b,c : integer; end record;
sig <= (a => 1, b => 2);  -- ERROR: c missing
```

**Recommended Fix:**
```diff
-- After: provide all elements
sig <= (a => 1, b => 2, c => 0);  -- all fields
-- Or: sig <= (a => 1, others => 0);
```

---

## Fix Strategy

1. Provide a value for **every** element/field of the record or array aggregate.
2. Use `others => <default>` to fill any remaining elements in one place (e.g., `(a => 1, others => 0)`).
3. Prefer **named** association (`field => value`) over positional so a missing field is immediately visible.
4. For nested records/arrays, ensure each sub-aggregate is likewise complete — a missing sub-element triggers the same error.
