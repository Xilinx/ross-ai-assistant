# 8-10551: Missing With Clause for Array Method

**Message:** `[Synth 8-10551] cannot omit 'with' clause for method; relational operators are not defined for element type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10551] cannot omit 'with' clause for method; relational operators are not defined for element type [/path/to/file:NN]
```

---

## Root Cause

Array ordering methods like `.unique` require a `with` clause when the element type doesn't have built-in comparison operators.

---

## Common Patterns

### P1: Array method missing with clause

**Problematic Code:**
```diff
// Before: unique without 'with' clause on complex type
q2 = n1.unique;  // ERROR: relational operators not defined for element type
```

**Recommended Fix:**
```diff
// After: add 'with' clause specifying comparison field
q2 = n1.unique with (item.field);  // specify which field to compare
// Or use on simple types where operators are defined:
int arr[$] = '{1,2,3,1};
q2 = arr.unique;  // OK: int has relational operators
```

---

## Fix Strategy

1. Add a `with (expression)` clause to array ordering/reduction methods so the tool knows what to compare (`arr.unique(x) with (x.key)`).
2. Alternatively, use the method only on element types that have built-in relational operators.
3. For structs/objects, specify the comparison field explicitly in the `with` clause.
4. Note many array methods are verification-only; avoid them in synthesizable RTL.
