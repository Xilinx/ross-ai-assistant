# 8-7193: Integer Conversion Truncation

**Message:** `[Synth 8-7193] Integer conversion function is truncating input`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An integer conversion truncates the input value (losing bits).

---

## Common Patterns

### P1: Integer conversion loses bits

**Problematic Code:**
```diff
-- WARNING: to_integer truncating input
```

**Recommended Fix:**
```diff
-- Add explicit range check or resize before conversion
sig <= to_integer(resize(unsigned_val, 31));
```

---

## Fix Strategy

1. Resize the value to the conversion function's expected width before converting so no bits are lost (`to_integer(resize(x, N))` where N fits the target).
2. Verify the source range actually fits the destination — if it can exceed it, add a range check or saturate.
3. Prefer keeping arithmetic in `unsigned`/`signed` and convert to `integer` only at boundaries where the range is known safe.
4. Confirm the truncation was not masking a real width/design mismatch upstream.
