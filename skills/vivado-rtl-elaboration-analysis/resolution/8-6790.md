# 8-6790: Constant Variable Reassignment

**Message:** `[Synth 8-6790] Constant variable cannot be reassigned, ignoring`
**Severity:** CRITICAL WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A constant/localparam is reassigned, which is ignored.

---

## Common Patterns

### P1: Reassignment of a constant

**Problematic Code:**
```diff
// Before: reassigning constant
const int myConst1 = 5;
myConst1 = 10;  // CRITICAL WARNING: ignored
```

**Recommended Fix:**
```diff
// After: use variable if mutable
int myVar1 = 5;
myVar1 = 10;  // OK for variable
```

---

## Fix Strategy

1. If the value must change, declare it as a mutable **variable** (`int`/`logic`/`reg`, or VHDL `variable`/`signal`), not a `const`/`localparam`/`parameter`.
2. If it should stay constant, remove the reassignment — that write is the actual bug and is being ignored.
3. Separate compile-time configuration (constants) from runtime state (variables/registers); do not reuse a constant as storage.
4. Treat this CRITICAL WARNING seriously: the ignored assignment means the intended update never happens.
