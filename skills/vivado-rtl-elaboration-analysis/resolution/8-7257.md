# 8-7257: Removed RAM (dpram_testcase_inst/dpram_1/ram_re...

**Message:** `[Synth 8-7257] Removed RAM (dpram_testcase_inst/dpram_1/ram_reg) due to inactive write enable.`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An inferred RAM was removed because its **write enable is never asserted** (tied
inactive) or its contents are never observable. With no effective write, the
memory holds no useful state and is optimized away.

---

## Common Patterns

### P1: RAM removed due to inactive write enable

**Problematic Code:**
```diff
-- Removed RAM (dpram_testcase_inst/dpram_1/ram_reg) due to inactive write enable.
```

**Recommended Fix:**
```verilog
// Ensure the write enable is actually driven and the RAM output is used
always @(posedge clk)
  if (we) ram[addr] <= din;     // 'we' must be a real, sometimes-active signal
assign dout = ram[raddr];       // and 'dout' must reach a used output
```

---

## Fix Strategy

1. Ensure the RAM's write enable can actually be asserted — a permanently-inactive `we` makes the memory dead and it is removed.
2. Verify the RAM's read data reaches a used output; if nothing consumes it, connect it or the memory is optimized away.
3. Check for a tied-off or mis-decoded write-enable signal that should be driven by real control logic.
4. If the RAM is intentionally present (debug), mark it `(* dont_touch = "true" *)`; otherwise treat removal as a sign of a missing connection.
