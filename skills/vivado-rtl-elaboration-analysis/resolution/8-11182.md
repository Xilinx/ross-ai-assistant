# 8-11182: String Has No Matching Type

**Message:** `[Synth 8-11182] string '!%1!' has !%2! possible matching types`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL string literal cannot be resolved to any visible type in the current scope.

---

## Common Patterns

### P1: String literal with no matching type

**Problematic Code:**
```diff
-- Before: string literal with no matching type
signal s : my_type;
s <= "N";  -- ERROR: no type matches string "N"
```

**Recommended Fix:**
```diff
-- After: use correct type or add type qualification
s <= my_type'("N");  -- explicit type qualification
-- Or ensure the type supports string assignment
```

---

## Fix Strategy

1. Add explicit type qualification so the string literal resolves to the intended type (`string_type'("...")`).
2. Ensure the target type actually accepts string literals (character-array types).
3. Import the package that defines the target string/character-array type.
4. If assigning to a vector, use a bit-string literal (`x"..."`/`"1010"`) instead of a text string.
