# 8-4557: Cannot Dissolve RAM

**Message:** `[Synth 8-4557] Cannot dissolve ram to registers because of more than 1 write`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

RAM cannot be dissolved into registers due to multiple write ports.

---

## Common Patterns

### P1: Multi-write-port RAM cannot become registers

**Problematic Code:**
```diff
-- WARNING: RAM with multiple write ports can't become registers
```

**Recommended Fix:**
```diff
-- Use block RAM instead:
attribute ram_style : string;
attribute ram_style of RAM_reg : signal is "block";
```

---

## Fix Strategy

1. This is informational — a RAM with more than one write port cannot be flattened to registers, so let it map to Block RAM (`(* ram_style = "block" *)` / VHDL `ram_style` attribute).
2. If you actually wanted registers, reduce to a single write port; true-dual-write memories require BRAM, not FF fabric.
3. Ensure the write/read style matches a supported BRAM template (synchronous accesses) so the BRAM maps cleanly.
4. Verify the intended implementation (BRAM vs. distributed) meets your timing/resource goals and set `ram_style` accordingly.
