# 8-10797: Illegal Character in Number

**Message:** `[Synth 8-10797] illegal character in binary number`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10797] illegal character in binary number [/path/to/file:NN]
```

---

## Root Cause

A binary number literal contains characters outside the valid set (`0`, `1`, `x`, `z`, `_`).

---

## Common Patterns

### P1: Illegal digit for the number base

**Problematic Code:**
```diff
// Before: invalid digit in binary literal
f2 = 32'b1101121;   // ERROR: '2' is not valid in binary
```

**Recommended Fix:**
```diff
// After: use correct digits for the base
f2 = 32'b11011001;  // only 0,1,x,z allowed in binary
// Or use hex for mixed values:
f2 = 32'hD9;
```

---

## Fix Strategy

1. Use only legal digits for the literal's base — binary (`'b`) allows `0 1 x z _`; octal `0-7`; hex `0-9 a-f`.
2. Fix the base prefix to match the digits you intend (`'h` for hex values, etc.).
3. Remove stray characters/typos from the numeric literal.
4. Verify the value fits the declared width.
