# 8-9397: empty parameter declaration is only allowed in SystemVerilog mode

**Message:** `[Synth 8-9397] empty parameter declaration is only allowed in SystemVerilog mode`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An empty parameter declaration is used, which is only allowed in SystemVerilog mode - the file is compiled as Verilog.

---

## Common Patterns

### P1: Empty parameter declaration (SystemVerilog only)

**Problematic Code:**
```verilog
parameter ;   // empty, in Verilog mode
```

**Recommended Fix:**
```verilog
parameter W = 8;   // give it a value, or compile as SystemVerilog
```

---

## Fix Strategy

1. Give the parameter a name/value, or compile the file as SystemVerilog.
2. Remove the empty declaration if unintended.
3. Set the correct language on the source file.
