# 8-10631: Decimal Constant Overflow

**Message:** `[Synth 8-10631] decimal constant should be smaller than 2147483648`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10631] decimal constant should be smaller than 2147483648 [/path/to/file:NN]
```

---

## Root Cause

An unsized decimal literal exceeds the 32-bit integer range (2^31).

---

## Common Patterns

### P1: Unsized decimal literal overflow

**Problematic Code:**
```diff
// Before: oversized decimal literal
assign {c,a,b} = {101110101101};  // ERROR: treated as decimal, too large
```

**Recommended Fix:**
```diff
// After: use proper binary literal syntax
assign {c,a,b} = 12'b101110101101;  // add size and base prefix
```

---

## Fix Strategy

Add proper size and base prefix (`'b`, `'h`, `'d`) to numeric literals. Unsized numbers default to decimal and must fit in 32 bits.
