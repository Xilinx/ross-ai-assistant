# 8-10911: Interface Package Default Mapping Conflict

**Message:** `[Synth 8-10911] interface package element cannot contain mapping 'default' with interface type element`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10911] interface package element cannot contain mapping 'default' with interface type element [/path/to/file:NN]
```

---

## Root Cause

A VHDL generic package with `generic map(default)` conflicts when the package contains an interface type — default mapping is ambiguous for types.

---

## Common Patterns

### P1: default mapping with interface types

**Problematic Code:**
```diff
-- Before: default mapping with interface type
package UnInstPack is
  generic(package pack is new work.InstfPack generic map(default));  -- ERROR
```

**Recommended Fix:**
```diff
-- After: provide explicit mapping
package UnInstPack is
  generic(package pack is new work.InstfPack generic map(T1 => integer));
```

---

## Fix Strategy

1. Provide **explicit** generic mappings (not `default`) when the interface/generic package contains interface-type elements.
2. Map each interface-type generic to a concrete instance so no default-mapping conflict arises.
3. Confirm the flow supports VHDL-2008 interface/generic packages; otherwise use concrete types.
4. Ensure all mapped actuals satisfy the formal's constraints.
