# 8-10826: Identifier Too Long

**Message:** `[Synth 8-10826] illegal identifier (exceeds maximum length)`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10826] illegal identifier (exceeds maximum length) [/path/to/file:NN]
```

---

## Root Cause

A VHDL library or identifier name exceeds the maximum allowed length.

---

## Common Patterns

### P1: Identifier exceeds length limit

**Problematic Code:**
```diff
-- Before: extremely long library name
LIBRARY very_long_name_lib_for_testing...lib;  -- ERROR: too long
```

**Recommended Fix:**
```diff
-- After: shorten the identifier
LIBRARY my_lib;
USE my_lib.my_pkg;
```

---

## Fix Strategy

1. Shorten the identifier/library name to within the tool's maximum length (typically a few hundred characters).
2. Avoid extremely long auto-generated names; use concise, meaningful identifiers.
3. If the name comes from a tool/script, adjust the generator to emit shorter names.
4. Check for accidental concatenation that produced an over-long name.
