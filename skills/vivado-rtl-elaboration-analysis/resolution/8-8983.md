# 8-8983: '!%1!' was previously declared with a range

**Message:** `[Synth 8-8983] '!%1!' was previously declared with a range`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An object is redeclared with a different (or missing) range from its earlier declaration.

---

## Common Patterns

### P1: Object previously declared with a range

**Problematic Code:**
```vhdl
signal s : std_logic_vector(3 downto 0);
signal s : std_logic;   -- range differs
```

**Recommended Fix:**
```vhdl
signal s : std_logic_vector(3 downto 0);   -- one consistent declaration
```

---

## Fix Strategy

1. Keep a single, consistent declaration with the intended range.
2. Remove the conflicting redeclaration.
3. Match the range everywhere the object is declared.
