# 8-6104: Input Port Has Internal Driver

**Message:** `[Synth 8-6104] Input port has an internal driver`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An input port is also driven internally, creating a conflict.

---

## Common Patterns

### P1: Input port driven internally

**Problematic Code:**
```diff
-- Before: input port driven internally
port (x : in std_logic);
x <= internal_sig;  -- WARNING: input driven internally
```

**Recommended Fix:**
```diff
-- After: change to inout or remove internal driver
port (x : inout std_logic);  -- if bidirectional needed
-- Or remove internal driver
```

---

## Fix Strategy

Change port mode to `inout` if bidirectional, or remove the internal driver.
