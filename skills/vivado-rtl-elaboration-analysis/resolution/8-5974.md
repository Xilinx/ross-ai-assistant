# 8-5974: Deprecated Attribute

**Message:** `[Synth 8-5974] attribute has been deprecated, please use replacement`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A synthesis attribute is deprecated — use the new name.

---

## Common Patterns

### P1: Deprecated attribute name

**Problematic Code:**
```diff
-- Before: deprecated attribute
attribute use_dsp48 : string;  -- WARNING: deprecated
```

**Recommended Fix:**
```diff
-- After: use updated attribute
attribute use_dsp : string;
attribute use_dsp of mult : signal is "yes";
```

---

## Fix Strategy

1. Replace the deprecated attribute with its current equivalent (e.g., `use_dsp48` -> `use_dsp`); check UG901 for the current attribute name and legal values.
2. Update both the attribute declaration and its application to the new name.
3. Verify the new attribute still produces the intended implementation (e.g., DSP mapping) after the change.
4. Search the codebase for other occurrences of the deprecated attribute and update them consistently.
