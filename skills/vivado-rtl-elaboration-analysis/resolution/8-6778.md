# 8-6778: Null Array Port Ignored

**Message:** `[Synth 8-6778] Component port with null array found, Will be ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A component port with a null (zero-length) array is ignored.

---

## Common Patterns

### P1: Zero-length (null) array port

**Problematic Code:**
```diff
-- Before: zero-length array port
port (data : in std_logic_vector(-1 downto 0));  -- null array
```

**Recommended Fix:**
```diff
-- After: fix array range or remove port
port (data : in std_logic_vector(7 downto 0));
```

---

## Fix Strategy

1. Fix the array range so the port has a positive length — a range like `(-1 downto 0)` (or a zero-valued width parameter) yields a null array that is ignored.
2. Correct the width parameter/generic that produced the zero/negative length.
3. If the port is genuinely not needed, remove it from the component/entity rather than leaving a null array.
4. Guard configurations where a width can be zero with a `generate`/conditional so no null port is declared.
