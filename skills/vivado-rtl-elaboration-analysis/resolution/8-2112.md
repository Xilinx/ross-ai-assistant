# 8-2112: Illegal Concat Label for Array

**Message:** `[Synth 8-2112] illegal concat label for !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A concatenation label is used incorrectly with an array type.

---

## Common Patterns

### P1: Concatenation used to init an array

**Problematic Code:**
```diff
// Before: illegal concat label
int arr[4] = {1, 2, 3, 4};  // ERROR: use '{ for arrays
```

**Recommended Fix:**
```diff
// After: use assignment pattern
int arr[4] = '{1, 2, 3, 4};  // correct: '{ for arrays
```

---

## Fix Strategy

1. Initialize/assign unpacked arrays with an **assignment pattern** `'{...}` (note the leading apostrophe), not a concatenation `{...}`.
2. For replicated defaults, use `'{default:0}` or `'{N{value}}` inside the pattern.
3. Reserve plain `{...}` concatenation for packed vectors only.
4. Match the number and types of pattern elements to the array's element count and type.
