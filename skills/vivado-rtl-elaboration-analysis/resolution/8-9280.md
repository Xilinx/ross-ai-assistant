# 8-9280: Case Expression Not Character Array

**Message:** `[Synth 8-9280] case expression type is not a character array type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL case expression uses a type that's not a character array (required for `case?` matching).

---

## Common Patterns

### P1: Non-character-array case expression

**Problematic Code:**
```diff
case boolean_vec is  -- ERROR: boolean_vector not character type
```

**Recommended Fix:**
```diff
case std_logic_vec is  -- use std_logic_vector (character array)
  when "01" => ...
```

---

## Fix Strategy

1. Use a character-array type (`std_logic_vector`, `bit_vector`) for the case expression, especially with `case?`/wildcard matching.
2. Convert a non-character type (e.g., `boolean_vector`) to `std_logic_vector` before the case, or restructure to a plain `case` on a discrete type.
3. Ensure the case-item literals are the same character-array type and width as the selector.
4. For enumerated selectors, use a normal `case` (not `case?`) since wildcards apply to character arrays.
