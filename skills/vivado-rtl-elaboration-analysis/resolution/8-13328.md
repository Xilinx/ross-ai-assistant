# 8-13328: Null Range Expression

**Message:** `[Synth 8-13328] null range expression ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A range expression evaluates to a null (empty) range.

---

## Common Patterns

### P1: Range evaluates to null

**Problematic Code:**
```diff
sig(4 downto 7)  -- WARNING: 4 downto 7 is null/empty
```

**Recommended Fix:**
```diff
sig(7 downto 4)  -- valid descending range
```

---

## Fix Strategy

1. Ensure range bounds produce a non-empty range — check ascending (`to`) vs descending (`downto`) direction.
2. Verify width/count parameters are positive so computed ranges are not null.
3. Guard zero-width cases with a `generate`/conditional instead of emitting a null range.
4. Confirm both bounds evaluate to the intended constants at elaboration.
