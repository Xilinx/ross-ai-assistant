# 8-9923: Port Declaration Not Allowed with Formal List

**Message:** `[Synth 8-9923] port declaration not allowed with formal port declaration list`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A module with formal port list has additional port declarations in the body.

---

## Common Patterns

### P1: Body port not in the header list

**Problematic Code:**
```diff
module top(a, b);
  input a;
  input b;
  input c;  // ERROR: c not in formal list
```

**Recommended Fix:**
```diff
module top(a, b, c);  // add c to formal list
  input a, b, c;
```

---

## Fix Strategy

1. List **every** port in the module header's formal port list — non-ANSI bodies may only declare directions for ports that appear in the header.
2. Add the missing port name(s) to the header, then declare their direction/type in the body.
3. Prefer ANSI-style headers (declare direction/type inline) to avoid header/body drift.
4. Ensure no body port declaration references a name absent from the header.
