# 8-11899: Assignment Pattern to Single Bit

**Message:** `[Synth 8-11899] target of assignment pattern cannot be a single bit type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An assignment pattern `'{...}` targets a single-bit type, which is not an array or struct.

---

## Common Patterns

### P1: Assignment pattern on a single bit

**Problematic Code:**
```diff
// Before: pattern assigned to single bit
logic b;
b = '{1};  // ERROR: single bit is not array/struct
```

**Recommended Fix:**
```diff
// After: direct assignment
logic b;
b = 1'b1;  // direct bit assignment
```

---

## Fix Strategy

1. Use a direct value assignment for scalar/single-bit targets — assignment patterns `'{...}` are only for arrays and structs.
2. If you meant to assign a vector, declare the target as a vector/array and match the pattern shape.
3. Check for a pattern accidentally applied to a 1-bit signal.
4. Verify the target type before choosing pattern vs. direct assignment.
