# 8-35: Not a Constant

**Message:** `[Synth 8-35] '!%1!' is not a constant`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An identifier used in a constant-required context is not a constant (it's a variable or signal).

---

## Common Patterns

### P1: Signal/variable used where a constant is required

**Problematic Code:**
```diff
// Before: variable used where constant required
reg [7:0] num2;
parameter P = num2;  // ERROR: num2 is not constant
```

**Recommended Fix:**
```diff
// After: use a constant
localparam num2 = 8;
parameter P = num2;  // now constant
```

---

## Fix Strategy

1. Move the value into an elaboration-time constant: `parameter`/`localparam` (Verilog) or `constant` (VHDL).
2. If the value currently comes from a `reg`/`wire`/signal, it cannot be used in a constant context — restructure so the value is known at elaboration (e.g., derive it from a parameter, or compute it in a `generate`/`for-generate`).
3. Constant-required contexts include: array/vector bounds, replication counts (`{N{...}}`), parameter defaults, case labels, and generate conditions — ensure only constants appear there.
4. Share common constants via a `package` (SystemVerilog) or a constants package (VHDL) and import them, rather than recomputing from signals.
