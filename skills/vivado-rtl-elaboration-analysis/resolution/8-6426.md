# 8-6426: Mix of Sync and Async assignments

**Message:** `[Synth 8-6426] Mix of Sync and Async assignments to register 'status_reg_reg' in module 'pci_cfg' in the same process may cause logic issues.`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A register is assigned **both synchronously and asynchronously** in the same
process. Mixing synchronous and asynchronous assignments to one register can
misinfer its set/reset behavior and cause functional issues.

---

## Common Patterns

### P1: Sync and async writes to one register

**Problematic Code:**
```diff
-- Mix of Sync and Async assignments to register 'status_reg_reg' in module 'pci_cfg' in the same process may cause logic issues.
```

**Recommended Fix:**
```verilog
// Keep async control separate from synchronous data updates
always @(posedge clk or posedge arst)
  if (arst)       status_reg <= '0;     // async reset only
  else if (clr)   status_reg <= '0;     // synchronous clear
  else            status_reg <= status_nxt;
```
