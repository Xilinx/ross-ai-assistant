# 8-13076: $bits system function cannot have an argument of non bit-stream type

**Message:** `[Synth 8-13076] $bits system function cannot have an argument of non bit-stream type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

`$bits` was given a non bit-stream type (e.g. a real, event, chandle) that has no bit representation.

---

## Common Patterns

### P1: $bits argument is not a bit-stream type

**Problematic Code:**
```systemverilog
event e;
int n = $bits(e);   // not a bit-stream type
```

**Recommended Fix:**
```systemverilog
logic [7:0] v;
int n = $bits(v);
```

---

## Fix Strategy

1. Pass a bit-stream (integral/packed) type to `$bits`.
2. Do not use real/event/chandle types with `$bits`.
3. Model the data with packed vectors/structs.
