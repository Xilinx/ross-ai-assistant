# 8-2210: Incompatible Complex Type Assignment

**Message:** `[Synth 8-2210] incompatible complex type assignment`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An assignment between complex types (arrays, structs) with incompatible structures.

---

## Common Patterns

### P1: Assignment between incompatible complex types

**Problematic Code:**
```diff
// Before: incompatible struct assignment
typedef struct {int a; byte b;} t1;
typedef struct {int x; int y;} t2;
t1 s1; t2 s2;
s1 = s2;  // ERROR: different struct types
```

**Recommended Fix:**
```diff
// After: assign field by field
s1.a = s2.x;
s1.b = byte'(s2.y);  // explicit field mapping
```

---

## Fix Strategy

1. Assign only between **identical** complex types — the same `typedef`/record/array type on both sides, not two separately-declared types with matching fields.
2. For differing structures, assign field-by-field (or element-by-element) with explicit casts where member types differ (`s1.a = s2.x; s1.b = byte'(s2.y);`).
3. Define shared struct/array types in a package so producer and consumer use one compatible type.
4. Verify packed vs. unpacked kind and total width match before any whole-object assignment.
