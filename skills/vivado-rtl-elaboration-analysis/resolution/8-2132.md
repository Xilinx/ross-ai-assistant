# 8-2132: Illegal Expression in Target

**Message:** `[Synth 8-2132] illegal expression in target`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The left-hand side of an assignment contains an expression that cannot be a target (e.g., function call).

---

## Common Patterns

### P1: Non-assignable expression on LHS

**Problematic Code:**
```diff
// Before: expression as assignment target
func(a) = b;  // ERROR: func() can't be on LHS
```

**Recommended Fix:**
```diff
// After: assign to variable
result = b;
func_input = result;
```

---

## Fix Strategy

1. Put only assignable targets on the LHS — a variable, signal, net, or a bit/part-select/field/index of one; never a function call or arbitrary expression.
2. If you intended to store a computed result, assign to a declared variable/signal, then use that (`result = b; func_input = result;`).
3. To "return" a value from a subprogram, use its return value or an `out`/`inout` parameter (VHDL procedure), not an assignment to the call.
4. Check for a mistyped LHS (e.g., missing index/field) that turned a valid target into an expression.
