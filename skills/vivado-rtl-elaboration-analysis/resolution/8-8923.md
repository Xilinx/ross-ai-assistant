# 8-8923: Not a Task

**Message:** `[Synth 8-8923] '!%1!' is not a task`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An identifier used in a task call is not a task.

---

## Common Patterns

### P1: Non-task called as a task

**Problematic Code:**
```diff
// Before: signal used as task
in2(val);  // ERROR: 'in2' is not a task
```

**Recommended Fix:**
```diff
// After: call actual task
my_task(val);  // correct task name
```

---

## Fix Strategy

1. Ensure the called identifier is a declared **task** — fix the name to the actual task or declare the task.
2. Do not call a signal/variable/function as a task; use the correct construct for the intent.
3. Match the task's argument list (count, order, direction) in the call.
4. Confirm the task is visible in scope (imported/declared before the call).
