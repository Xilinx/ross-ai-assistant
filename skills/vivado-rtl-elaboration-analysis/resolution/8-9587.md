# 8-9587: illegal initial value of !%1! port '!%2!' for !%3! '!%4!' ignored

**Message:** `[Synth 8-9587] illegal initial value of !%1! port '!%2!' for !%3! '!%4!' ignored`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An initial value on a port of a given mode is illegal for that mode and is ignored.

---

## Common Patterns

### P1: Illegal initial value on a port ignored

**Problematic Code:**
```vhdl
port ( q : out std_logic := '1' );  -- init on out ignored
```

**Recommended Fix:**
```vhdl
port ( q : out std_logic );          -- drive the default internally
```

---

## Fix Strategy

1. Remove the illegal port initializer.
2. Establish the initial value through a reset/driver instead.
3. Port initial values are limited by mode.
