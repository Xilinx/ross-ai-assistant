# 8-9182: Automatic Variable in Procedural Continuous

**Message:** `[Synth 8-9182] automatic variable is not allowed in procedural continuous assignments`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An `automatic` variable is used in `assign`/`deassign` or `force`/`release` inside a procedural block.

---

## Common Patterns

### P1: automatic var in procedural continuous assign

**Problematic Code:**
```diff
automatic int a;
assign a = val;  // ERROR: can't use automatic in procedural continuous
```

**Recommended Fix:**
```diff
int a;
a = val;  // regular procedural assignment
```

---

## Fix Strategy

1. Do not use `automatic` variables as targets of procedural continuous assignments (`assign`/`force`) — use ordinary blocking/non-blocking assignments instead.
2. Procedural continuous assignments (`assign`/`deassign`/`force`/`release`) are largely simulation-only; remove them from synthesizable RTL.
3. Model the intended behavior with a normal register/combinational assignment.
4. If the variable must be `automatic` (reentrant task), assign it with `=`/`<=`, not `assign`.
