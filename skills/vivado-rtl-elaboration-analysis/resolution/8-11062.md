# 8-11062: package import cannot be inside a class

**Message:** `[Synth 8-11062] package import cannot be inside a class`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `import pkg::*;` appears inside a class body, which is not allowed.

---

## Common Patterns

### P1: Package import inside a class

**Problematic Code:**
```systemverilog
class c; import p::*; ... endclass
```

**Recommended Fix:**
```systemverilog
import p::*;
class c; ... endclass   // import at compilation-unit/module scope
```

---

## Fix Strategy

1. Move the package import to module or compilation-unit scope.
2. Reference package items with explicit `pkg::name` if needed inside the class.
3. Classes are non-synthesizable; keep them in testbench code.
