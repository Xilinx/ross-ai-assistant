# 8-9212: Cannot Assign Signal from Subprogram

**Message:** `[Synth 8-9212] cannot assign signal from within a subprogram`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL subprogram (function/procedure) tries to assign a signal that's not in its parameter list.

---

## Common Patterns

### P1: Signal driven from a subprogram

**Problematic Code:**
```diff
procedure p is begin
  out1 <= '1';  -- ERROR: out1 not a parameter of p
end;
```

**Recommended Fix:**
```diff
procedure p(signal out1 : out std_logic) is begin
  out1 <= '1';  -- out1 is now a parameter
end;
```

---

## Fix Strategy

1. Pass the signal to the subprogram as a `signal`-class parameter (`procedure p(signal s : out std_logic)`) so it can be driven from inside.
2. Alternatively, return the value from the subprogram and assign the signal at the call site.
3. Do not assign a signal that is not in the subprogram's parameter list — subprograms cannot reach out to enclosing signals for driving.
4. Keep the subprogram's driver single and well-defined to avoid multiple-driver issues.
