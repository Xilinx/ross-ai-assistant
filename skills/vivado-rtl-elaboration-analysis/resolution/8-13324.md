# 8-13324: Generic Value Out of Range

**Message:** `[Synth 8-13324] !%1! value !%2! is out of allowable range`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL generic value exceeds the allowed range defined by the generic's type constraint.

---

## Common Patterns

### P1: Generic value out of range

**Problematic Code:**
```diff
-- Before: generic value exceeds range
generic (n : integer range 0 to 100);
-- instantiation:
generic map(n => 101);  -- ERROR: 101 > 100
```

**Recommended Fix:**
```diff
-- After: use value within range
generic map(n => 100);  -- within 0..100
-- Or widen the generic range
```

---

## Fix Strategy

1. Provide a generic value within the range constraint declared for that generic's type/subtype.
2. Widen the generic's type/range if the value is legitimately larger, or correct the override.
3. Check dependent generics/parameters that derive from this one for consistency.
4. Validate overrides at instantiation against the declared constraint.
