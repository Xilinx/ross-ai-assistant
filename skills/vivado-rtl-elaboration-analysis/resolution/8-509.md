# 8-509: Logical Operator Length Mismatch

**Message:** `[Synth 8-509] operands of logical operator '!%1!' have different lengths (!%2! vs. !%3!)`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL logical operators require operands of equal length.

---

## Common Patterns

### P1: Logical operator on unequal-length operands

**Problematic Code:**
```diff
-- Before: different lengths
signal a : std_logic_vector(3 downto 0);
signal b : std_logic_vector(6 downto 0);
c <= a and b;  -- ERROR: 4 vs 7 bits
```

**Recommended Fix:**
```diff
-- After: match lengths
c <= ("000" & a) and b;  -- pad a to 7 bits
-- Or resize: c <= resize(a,7) and b;
```

---

## Fix Strategy

1. Make both operands of the logical operator the same length: pad the narrower one (`"000" & a`) or use `resize(a, b'length)` from `numeric_std`.
2. Decide sign semantics before resizing — use `unsigned`/`signed` types so `resize` zero- or sign-extends correctly.
3. If one operand's width is wrong by declaration, fix the declaration rather than padding at every use site.
4. Verify the result target is wide enough to hold the operation's output.
