# 8-10886: Incorrect Line Directive

**Message:** `[Synth 8-10886] incorrect use of predefined macro 'line'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10886] incorrect use of predefined macro 'line' [/path/to/file:NN]
```

---

## Root Cause

The `` `line`` directive has incorrect syntax — must be `` `line <number> "<filename>" <level>``.

---

## Common Patterns

### P1: Malformed line directive

**Problematic Code:**
```diff
// Before: malformed `line directive
`line "file.v"            // ERROR: missing line number and level
```

**Recommended Fix:**
```diff
// After: use correct syntax or remove
`line 1 "file.v" 0        // correct: number "filename" level
// Or simply remove the `line directive
```

---

## Fix Strategy

1. Use correct `` `line `` syntax with all three arguments (`` `line <n> "<file>" <level> ``), or remove the directive.
2. `` `line `` is rarely needed for synthesis — removing it is usually safe.
3. Ensure the numeric arguments are integers and the filename is quoted.
4. Fix the tool/preprocessor that emitted the malformed directive.
