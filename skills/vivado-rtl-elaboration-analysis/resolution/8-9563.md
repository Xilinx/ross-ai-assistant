# 8-9563: Illegal Actual for Ref Port

**Message:** `[Synth 8-9563] illegal actual value for ref port`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `ref` port's actual is not a valid variable.

---

## Common Patterns

### P1: Non-variable actual for a ref port

**Problematic Code:**
```diff
function f(ref int itime);
f(constant_val);  // ERROR: ref needs variable
```

**Recommended Fix:**
```diff
int var_val;
f(var_val);  // variable as ref actual
// Note: ref is not synthesizable
```

---

## Fix Strategy

1. Pass a **variable** (not a constant/expression) to a `ref` port/argument.
2. For synthesizable RTL, avoid `ref` entirely — use `input`/`output` arguments with matching types.
3. If `ref` is verification-only, ensure the actual is an assignable variable of the exact same type.
4. Do not pass literals or `const` values where a `ref` is expected.
