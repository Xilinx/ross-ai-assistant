# 8-837: Assignment Operator in Wrong Context

**Message:** `[Synth 8-837] assignment operator only allowed in blocking assignment context`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A SystemVerilog assignment operator (`+=`, `-=`, etc.) is used in a non-blocking or continuous assignment context.

---

## Common Patterns

### P1: Compound operator with non-blocking assignment

**Problematic Code:**
```diff
// Before: += in non-blocking context
always @(posedge clk)
  count += 1;  // ERROR: only allowed in blocking
```

**Recommended Fix:**
```diff
// After: use regular operator
always @(posedge clk)
  count <= count + 1;  // non-blocking with explicit +
```

---

## Fix Strategy

1. Compound assignment operators (`+=`, `-=`, `*=`, `<<=`, etc.) are blocking-only — use them with `=` inside procedural blocks, not with non-blocking `<=`.
2. For sequential logic, expand the compound form explicitly with non-blocking assignment: `count <= count + 1;` instead of `count += 1;`.
3. Never use compound operators in continuous (`assign`) statements — rewrite as a full expression.
4. Keep blocking (`=`) for combinational/temporary computation and non-blocking (`<=`) for register updates, and expand compound ops accordingly.
