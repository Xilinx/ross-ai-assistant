# 8-281: Expression Must Be Packed Type

**Message:** `[Synth 8-281] expression must be of a packed type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-281] expression must be of a packed type [/path/to/file.sv:42]
```

---

## Root Cause

An operation that requires a packed (bit-vector) type is being applied to an unpacked type. Packed types have contiguous bit representation; unpacked types do not.

---

## Packed vs Unpacked

| Type | Packed | Example |
|------|--------|---------|
| `logic [7:0]` | Yes | 8-bit vector |
| `logic [7:0][3:0]` | Yes | 2D packed array |
| `logic [7:0] arr[4]` | No | Array of 8-bit values |
| `struct packed` | Yes | Packed structure |
| `struct` | No | Unpacked structure |

---

## Common Patterns

### P1: Bit-Select on Unpacked Array

```systemverilog
// Before - unpacked array, can't use as vector
logic [7:0] data [4];  // unpacked array
wire [31:0] flat = data;  // ERROR: can't flatten unpacked

// After - use packed array
logic [3:0][7:0] data;  // packed 2D array (32 bits total)
wire [31:0] flat = data;  // OK: packed can be assigned
```

### P2: Concatenation with Unpacked

```systemverilog
// Before - unpacked in concatenation
logic [7:0] arr [2];
wire [15:0] combined = {arr[0], arr[1]};  // ERROR if arr is unpacked

// After - declare as packed or use explicit elements
logic [1:0][7:0] arr;  // packed
wire [15:0] combined = arr;  // OK
```

### P3: Unpacked Struct in Bit Operation

```systemverilog
// Before - unpacked struct
typedef struct {
  logic [7:0] a;
  logic [7:0] b;
} my_struct_t;

my_struct_t s;
wire [15:0] bits = s;  // ERROR: unpacked

// After - packed struct
typedef struct packed {
  logic [7:0] a;
  logic [7:0] b;
} my_struct_t;

my_struct_t s;
wire [15:0] bits = s;  // OK
```

### P4: Function with Unpacked Return

```systemverilog
// Before - unpacked return type
function logic [7:0] get_bytes [4] ();  // returns unpacked
  ...
endfunction

// After - packed return or explicit handling
function logic [31:0] get_bytes();  // packed 32-bit return
  ...
endfunction
```

---

## Fix Strategy

1. Add `packed` keyword to structs/unions
2. Change unpacked arrays `[N]` to packed `[N-1:0]`
3. Use explicit element access for unpacked types
4. Rearrange dimensions: `[W][D]` (packed) vs `[W] arr[D]` (unpacked)
