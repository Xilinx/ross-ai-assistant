# 8-6880: Tagged Union as Normal

**Message:** `[Synth 8-6880] Tagged union is treated as normal union`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A tagged union is treated as a regular union for synthesis (tagged semantics ignored).

---

## Common Patterns

### P1: Tagged union in synthesizable code

**Problematic Code:**
```diff
// Before: tagged union
union tagged { int i; bit [7:0] b; } u;  // WARNING
```

**Recommended Fix:**
```diff
// After: use regular union or struct
union { int i; bit [7:0] b; } u;  // or struct for clarity
```

---

## Fix Strategy

1. Tagged-union semantics are not synthesized — the tag is ignored, so do not rely on it for hardware behavior.
2. Use a plain packed `union` (all members same width) or a packed `struct` with an explicit tag field you manage yourself.
3. If you need discriminated access, encode the tag as a separate signal and select members with a mux.
4. Ensure all union members are packed and same-width so the union is synthesizable.
