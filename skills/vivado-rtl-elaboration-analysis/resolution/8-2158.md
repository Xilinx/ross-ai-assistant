# 8-2158: Illegal Operand for Operator

**Message:** `[Synth 8-2158] illegal operand for operator !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An operator is used with incompatible operand types.

---

## Common Patterns

### P1: Operator on incompatible operand types

**Problematic Code:**
```diff
// Before: != on incompatible types
string s;
int i;
if (s != i)  // ERROR: can't compare string with int
```

**Recommended Fix:**
```diff
// After: use compatible types
int a, b;
if (a != b)  // same types
```

---

## Fix Strategy

1. Make both operands types the operator supports — do not mix fundamentally different kinds (e.g., `string` vs `int`).
2. Add an explicit conversion when a controlled mix is intended (`int'(...)`, `unsigned(...)`, `to_integer(...)`), so both sides share a type.
3. Check for an accidental type from an implicit declaration or wrong signal, and fix the declaration.
4. Keep non-synthesizable types (`string`, `real`, `chandle`) out of operator expressions in synthesizable RTL.
