# 8-2212: Incompatible Unpacked Dimensions

**Message:** `[Synth 8-2212] incompatible unpacked dimensions in assignment`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An assignment between arrays (or array expressions) whose unpacked dimensions do not match. This includes:
- Direct assignment between arrays with different unpacked dimension sizes or ranges.
- Assigning the result of an array method (`.find`, `.sort`, `.unique`, etc.) on a multi-dimensional unpacked array to a variable with incompatible dimensions.
- Mixing fixed-size unpacked arrays with queues (`[$]`) or dynamic arrays (`[]`) when dimension shapes differ.

---

## Common Patterns

### P1: Direct Assignment — Different Unpacked Dimensions

**Problematic Code:**
```systemverilog
int a[4][8];
int b[8][4];
a = b;  // ERROR: unpacked dimensions [4][8] vs [8][4]
```

**Fix — Match the dimensions on both sides:**
```systemverilog
int a[4][8];
int b[4][8];
a = b;  // OK: same unpacked dimensions
```

### P2: Array Method on Multi-Dimensional Array Assigned to Incompatible Target

**Problematic Code:**
```systemverilog
int a[4:0][1:0];   // 2D unpacked array
int l[$];           // 1D queue
l = a.find(x) with (x > a[1][2]);  // ERROR: .find() on 2D array returns result
                                     // with outermost unpacked dimension, not int
```

**Fix Option A — Use a manual loop (most synthesizable):**
```systemverilog
int a[4:0][1:0];
int l[$];
l = {};
for (int i = 0; i < 5; i++)
    for (int j = 0; j < 2; j++)
        if (a[i][j] > a[1][2])
            l.push_back(a[i][j]);
```

**Fix Option B — Flatten the array to 1D before calling the array method:**
```systemverilog
int a[4:0][1:0];
int a_flat[10];
int l[$];
for (int i = 0; i < 5; i++)
    for (int j = 0; j < 2; j++)
        a_flat[i*2 + j] = a[i][j];
l = a_flat.find(x) with (x > a[1][2]);
```

**Fix Option C — Operate on a single row (slice) of the array:**
```systemverilog
int a[4:0][1:0];
int row[1:0];
int l[$];
row = a[1];  // extract one row
l = row.find(x) with (x > a[1][2]);
```

### P3: Assigning Between Fixed-Size and Dynamic/Queue Arrays with Mismatched Structure

**Problematic Code:**
```systemverilog
int a[3:0][7:0];
int b[];             // dynamic array of int (1D)
b = a;               // ERROR: 2D unpacked vs 1D dynamic
```

**Fix — Flatten or restructure to match:**
```systemverilog
int a[3:0][7:0];
int b[];
b = new[32];
for (int i = 0; i < 4; i++)
    for (int j = 0; j < 8; j++)
        b[i*8 + j] = a[i][j];
```

---

## Fix Strategy

1. **Inspect both sides of the assignment** — check the unpacked dimension count and sizes on the LHS and RHS. They must be identical for direct assignment.
2. **For array methods on multi-dimensional arrays** — array methods like `.find()`, `.sort()`, `.unique()` on N-dimensional arrays produce results whose dimensions may not match a simple 1D target. Prefer replacing with an explicit loop (most synthesizable) or flatten the array to 1D first.
3. **For synthesis** — queue (`[$]`) and dynamic array (`[]`) types are generally not synthesizable. Replace with fixed-size arrays and explicit loops for synthesizable designs.
4. **Never just delete the offending line** — the design intent must be preserved. Choose the fix option that maintains the original logic while ensuring dimension compatibility.
