# 8-3919: Null Assignment

**Message:** `[Synth 8-3919] null assignment ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL null waveform or null assignment is ignored during synthesis.

---

## Common Patterns

### P1: null waveform assignment

**Problematic Code:**
```diff
-- Before: null assignment
sig <= null;  -- WARNING: ignored
```

**Recommended Fix:**
```diff
-- After: assign actual value
sig <= (others => '0');  -- use real value
```

---

## Fix Strategy

1. Replace the `null` waveform/assignment with a real value (`sig <= (others => '0');`) — `null` transactions are ignored by synthesis.
2. If the intent was to disconnect a driver, restructure the logic (use an enable/valid scheme) rather than a null assignment.
3. For guarded/resolved signals, drive them explicitly on every path so no null waveform is emitted.
4. Confirm the ignored assignment was not the only intended driver — if it was, the signal is now undriven and needs a real source.
