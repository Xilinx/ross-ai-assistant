# 8-9872: overwriting existing secondary unit '!%1!'

**Message:** `[Synth 8-9872] overwriting existing secondary unit '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A secondary unit (architecture/package body) is being recompiled/overwritten.

---

## Common Patterns

### P1: Overwriting existing secondary unit

**Problematic Code:**
```vhdl
-- architecture 'rtl' of 'e' defined twice
```

**Recommended Fix:**
```vhdl
-- keep a single architecture/package body
```

---

## Fix Strategy

1. Ensure each architecture/package body is defined once.
2. Remove duplicate secondary-unit sources.
3. Check for repeated files in the compile order.
