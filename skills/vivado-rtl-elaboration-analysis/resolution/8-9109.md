# 8-9109: Module Has No Port

**Message:** `[Synth 8-9109] actual module definition does not have port`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An instance port map references a port not present in the actual module.

---

## Common Patterns

### P1: Connection to a non-existent port

**Problematic Code:**
```diff
my_mod inst(.out1(sig));  -- ERROR: my_mod has no port 'out1'
```

**Recommended Fix:**
```diff
my_mod inst(.out(sig));  -- use correct port name
```

---

## Fix Strategy

1. Use the exact port names from the module definition in the instance connection.
2. Fix typos in the offending port name; prefer named connections so mismatches are obvious.
3. Verify you are instantiating the intended, current module version — a stale definition without that port is a common cause.
4. If the port should exist, add it to the module definition rather than forcing the connection.
