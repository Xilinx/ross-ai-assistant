# 8-2918: Illegal Port Connections

**Message:** `[Synth 8-2918] Failing due to illegal port connections`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Port connections are illegal — typically mismatched directions or types between connected ports.

---

## Common Patterns

### P1: Direction/type-incompatible port connection

**Problematic Code:**
```diff
// Before: illegal port connection (type/direction mismatch)
my_mod inst(.out(wire_sig));  // out port connected to driven wire
```

**Recommended Fix:**
```diff
// After: fix connection type
wire result;
my_mod inst(.out(result));  // proper net for output
```

---

## Fix Strategy

1. Check each connection's direction and type — outputs must drive a **net** (`wire`), inputs must connect to a drivable expression/net.
2. Do not connect two outputs to the same net or drive an input port from the child side; fix the direction mismatch at the source.
3. Match widths/types between formal and actual; add explicit slicing/casts only where a controlled adaptation is intended.
4. Prefer named connections so direction/type errors are localized, and confirm the instantiated module version is correct.
