# 8-9926: potential always loop found

**Message:** `[Synth 8-9926] potential always loop found`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A combinational `always` block may loop forever because a variable it assigns also appears in its own trigger/read path.

---

## Common Patterns

### P1: Potential always loop

**Problematic Code:**
```verilog
always @(a) a = a + 1;   // self-retriggering
```

**Recommended Fix:**
```verilog
always @(posedge clk) a <= a + 1;   // register it
```

---

## Fix Strategy

1. Break the combinational feedback - register the signal on a clock.
2. Do not assign a variable that also drives the same block's sensitivity.
3. Use `always @*` and ensure no unclocked self-dependency.
