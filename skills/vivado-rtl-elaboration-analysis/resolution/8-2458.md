# 8-2458: Variable Kind for Function Parameter

**Message:** `[Synth 8-2458] object kind '!%1!' is not allowed for function parameters`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL function parameter has object kind `variable`, which is not allowed.

---

## Common Patterns

### P1: variable-class function parameter

**Problematic Code:**
```diff
-- Before: variable parameter in function
function f(variable v : integer) return integer;  -- ERROR
```

**Recommended Fix:**
```diff
-- After: use default (constant) kind
function f(v : integer) return integer;  -- default is constant for functions
```

---

## Fix Strategy

1. Remove the explicit `variable` class from function parameters — function formals default to (and must be) `constant`/`in`.
2. If the subprogram genuinely needs a mutable `variable` parameter, make it a `procedure` instead of a `function`.
3. Use function-local `variable` declarations (inside the function body) for temporary mutable storage, keeping parameters read-only.
4. Confirm the function is side-effect free so it maps to combinational logic.
