# 8-10656: Modport Direction Override

**Message:** `[Synth 8-10656] direction for signal in modport changed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10656] direction for signal in modport changed [/path/to/file:NN]
```

---

## Root Cause

A modport declaration changes the direction of an interface signal, which conflicts with the signal's declaration direction.

---

## Common Patterns

### P1: Direction conflict with modport

**Problematic Code:**
```diff
// Before: conflicting directions in modports
interface intf(input utype udata, output utype usum);
  modport add(input udata, output usum);
  modport dummy(output udata, input usum);  // WARNING/ERROR: udata was input
```

**Recommended Fix:**
```diff
// After: declare interface signals without direction
interface intf;
  utype udata;   // no direction — let modports define it
  utype usum;
  modport add(input udata, output usum);
  modport dummy(output udata, input usum);
endinterface
```

---

## Fix Strategy

Declare interface signals without direction in the interface header. Let each modport define the direction independently.
