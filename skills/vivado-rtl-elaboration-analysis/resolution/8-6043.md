# 8-6043: Blackbox for Interface Illegal

**Message:** `[Synth 8-6043] blackbox for instance '!%1!' of interface '!%2!' is illegal`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An interface is treated as a blackbox, which is not legal for synthesis.

---

## Common Patterns

### P1: Interface treated as a black box

**Problematic Code:**
```diff
// Before: interface instance treated as blackbox
geocalc_bf_ch_ifc cal_bf_ch();  // ERROR: interface can't be blackbox
```

**Recommended Fix:**
```diff
// After: provide the interface definition
interface geocalc_bf_ch_ifc;
  ...
endinterface
// Compile the interface source file before the module that uses it
```

---

## Fix Strategy

1. Interfaces cannot be black-boxed — ensure the interface's source file is added and **compiled before** the modules that use it.
2. Fix any name/case mismatch between the interface reference and its `interface ... endinterface` definition.
3. Check compile order / filesets so the interface definition is visible at elaboration.
4. If the interface comes from a package or IP, import/generate it so its full definition (not a stub) is available.
