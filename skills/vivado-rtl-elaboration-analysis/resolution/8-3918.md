# 8-3918: Module Inside Interface

**Message:** `[Synth 8-3918] module '!%1!' can not be instantiated inside interface`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A module (like a UDP) is instantiated inside a SystemVerilog interface, which is not allowed.

---

## Common Patterns

### P1: Module instantiated inside an interface

**Problematic Code:**
```diff
// Before: module inside interface
interface intf;
  udp_latch u1(q, d, en);  // ERROR: can't instantiate module in interface
endinterface
```

**Recommended Fix:**
```diff
// After: move instantiation outside
module wrapper;
  intf i1();
  udp_latch u1(i1.q, i1.d, i1.en);  // instantiate at module level
endmodule
```

---

## Fix Strategy

1. Do not instantiate modules/UDPs inside a SystemVerilog `interface` — an interface may only contain signals, modports, tasks/functions, and assertions.
2. Move the instantiation up to a `module` level and connect it to the interface's signals (`udp_latch u1(i1.q, i1.d, i1.en);`).
3. Keep interfaces as pure connectivity/protocol definitions; put behavioral logic in modules.
4. If the interface needs helper behavior, expose it via tasks/functions rather than embedded module instances.
