# 8-3330: Empty Top Module

**Message:** `[Synth 8-3330] design has an empty top module`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

The top-level module/entity has no logic inside — all instances removed or empty architecture.

---

## Common Patterns

### P1: Top module with no logic

**Problematic Code:**
```diff
-- Before: empty architecture
architecture rtl of top is
begin
  -- nothing here
end;
```

**Recommended Fix:**
```diff
-- After: add logic or check that correct top is specified
-- synth_design -top correct_module_name
```

---

## Fix Strategy

1. Confirm the intended top module is selected (`synth_design -top <name>`); an empty top usually means the wrong module was chosen.
2. If the architecture is genuinely empty, add the missing logic/instances or connect the ports so the design is not optimized to nothing.
3. Check that sub-instances were not all removed by optimization due to unconnected outputs — connect outputs so logic is retained.
4. If this wrapper is meant to be a pass-through, ensure its ports are actually wired to the instantiated child.
