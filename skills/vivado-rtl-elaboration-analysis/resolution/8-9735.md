# 8-9735: Missing Full Type Definition

**Message:** `[Synth 8-9735] missing full type definition`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A forward type declaration was never completed with a full definition.

---

## Common Patterns

### P1: Incomplete type never completed

**Problematic Code:**
```diff
type type1;  -- forward declaration
-- never completed  -- ERROR
```

**Recommended Fix:**
```diff
type type1 is record
  data : integer;
end record;  -- complete definition
```

---

## Fix Strategy

1. Complete the forward/incomplete type with a full definition in the same declarative region (`type type1 is record ... end record;`).
2. Use incomplete types only to define access types until completion; for synthesizable data, define the full type directly.
3. Ensure the full definition appears before objects of that type are declared.
4. Remove the forward declaration if it is not needed for a mutual reference.
