# 8-5767: Invalid File Name

**Message:** `[Synth 8-5767] Invalid file name for task file_open`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL `file_open` has an invalid file name.

---

## Common Patterns

### P1: file_open with an invalid name

**Problematic Code:**
```diff
-- Before: invalid file name
file_open(f, invalid_path, READ_MODE);  -- ERROR
```

**Recommended Fix:**
```diff
-- After: file I/O is not synthesizable
-- Remove file operations
-- Or wrap in synthesis translate_off/on
```

---

## Fix Strategy

1. `file_open`/file operations are simulation-only — remove them from synthesizable RTL or guard with `-- synthesis translate_off` / `translate_on`.
2. For data that must exist in hardware, use ROM inference from a constant array or `$readmemh` (Verilog) rather than runtime file opens.
3. If the file name was simply wrong, fix the path in the simulation model; it still must not be in the synthesized path.
4. Keep all file handling in the testbench, not the design under test.
