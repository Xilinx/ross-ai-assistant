# 8-6090: variable 'clk_gate_en_nxt' is written by both

**Message:** `[Synth 8-6090] variable 'clk_gate_en_nxt' is written by both blocking and non-blocking assignments, entire logic could be removed`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A variable is written by **both** blocking (`=`) and non-blocking (`<=`)
assignments. Mixing assignment types on one variable is illegal for synthesis
and can cause the entire block of logic to be optimized away.

---

## Common Patterns

### P1: Blocking and non-blocking on one variable

**Problematic Code:**
```diff
// Problematic line:
if(host_req & config_reg2_sel )
                   begin
                    clk_gate_en_nxt[host_wr_data] <= 1'b1;
                    encod_clk_gate_en_nxt         = host_wr_data;
                   end
```

**Recommended Fix:**
```verilog
// Use one assignment type consistently for the variable
if (host_req & config_reg2_sel) begin
  clk_gate_en_nxt[host_wr_data] = 1'b1;   // blocking in a comb block...
  encod_clk_gate_en_nxt         = host_wr_data;
end
// ...or non-blocking everywhere in a clocked block -- never both on one signal
```

---

## Fix Strategy

Review the warning and apply the recommended coding practice from UG901.
