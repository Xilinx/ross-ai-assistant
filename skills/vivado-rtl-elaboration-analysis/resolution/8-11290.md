# 8-11290: Wait Statement in Function

**Message:** `[Synth 8-11290] wait statement is not allowed inside a function`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL `wait` statements are not allowed inside functions (they are only allowed in processes and procedures).

---

## Common Patterns

### P1: wait inside a function

**Problematic Code:**
```diff
-- Before: wait in function
function calc return integer is
begin
  wait for 10 ns;  -- ERROR: not allowed in function
  return 42;
end;
```

**Recommended Fix:**
```diff
-- After: remove wait (not synthesizable anyway)
function calc return integer is
begin
  return 42;  -- wait removed
end;
```

---

## Fix Strategy

1. Remove `wait` from functions — functions execute in zero time and cannot suspend.
2. If sequencing/timing is needed, move the logic into a clocked process (or a procedure used within one).
3. Model delays as clock-cycle counts in a state machine, not `wait` statements.
4. Keep the function pure and combinational so it synthesizes.
