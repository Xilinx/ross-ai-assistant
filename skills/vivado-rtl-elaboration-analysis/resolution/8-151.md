# 8-151: Unreachable Case Item

**Message:** `[Synth 8-151] case item is unreachable`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A case item value can never match because a previous item already covers it.

---

## Common Patterns

### P1: Duplicate / shadowed case item

**Problematic Code:**
```diff
case(sel)
  4'b1010: out = a;
  4'b1010: out = b;  // WARNING: unreachable, same as above
```

**Recommended Fix:**
```diff
case(sel)
  4'b1010: out = a;
  4'b1011: out = b;  // unique value
```

---

## Fix Strategy

1. Remove the duplicate/shadowed case item, or correct its label if a different value was intended.
2. For `casex`/`casez`, check whether an earlier wildcard item subsumes a later one — reorder items most-specific-first or make labels mutually exclusive.
3. Verify the `default` (or `when others`) is placed last; items after it are unreachable.
4. Confirm the selector width matches the case labels — a too-narrow selector can make wider labels unreachable.
