# 8-11229: Ambiguous Type Conversion

**Message:** `[Synth 8-11229] type conversion expression type for '!%1!' cannot be uniquely determined`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL type conversion for `std_logic_vector` has multiple matching interpretations.

---

## Common Patterns

### P1: Ambiguous conversion across packages

**Problematic Code:**
```diff
-- Before: ambiguous type conversion
use ieee.std_logic_arith.all;
use ieee.numeric_std.all;  -- both define conversions
out1 <= std_logic_vector(in1);  -- ERROR: ambiguous
```

**Recommended Fix:**
```diff
-- After: use only one numeric package
use ieee.numeric_std.all;  -- remove std_logic_arith
out1 <= std_logic_vector(unsigned(in1));  -- explicit
```

---

## Fix Strategy

1. Remove conflicting numeric packages — use only `ieee.numeric_std` (preferred) or only `ieee.std_logic_arith`, not both.
2. If both are unavoidable, qualify ambiguous conversions with the package name.
3. Standardize the codebase on `numeric_std` to prevent recurring ambiguity.
4. Replace ambiguous conversions with typed expressions/literals where possible.
