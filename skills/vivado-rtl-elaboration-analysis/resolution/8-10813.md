# 8-10813: illegal empty item in case item list

**Message:** `[Synth 8-10813] illegal empty item in case item list`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `case` item list contains an empty/missing item (e.g. a stray comma), which is illegal.

---

## Common Patterns

### P1: Empty item in case item list

**Problematic Code:**
```verilog
case (s)
  2'b00, : y=1;   // empty item before ':'
endcase
```

**Recommended Fix:**
```verilog
case (s)
  2'b00: y=1;
endcase
```

---

## Fix Strategy

1. Remove the empty item / stray comma in the case label list.
2. Every case item must be a valid expression.
3. Add a `default:` if you intended a catch-all.
