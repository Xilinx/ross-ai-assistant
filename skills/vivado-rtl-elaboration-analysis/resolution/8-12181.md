# 8-12181: Package Item Treated as Module-Local

**Message:** `[Synth 8-12181] Package item is treated as module-local`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A package item name conflicts with a local declaration and is treated as local.

---

## Common Patterns

### P1: Local name shadows a package item

**Problematic Code:**
```diff
// Package defines str1, but module also has local str1
// WARNING: local takes precedence
```

**Recommended Fix:**
```diff
// Rename local variable to avoid conflict
// Or qualify: pkg_name::str1
```

---

## Fix Strategy

1. Rename the local declaration that shadows the package item, or reference the package item with a qualified name (`pkg::item` / `work.pkg.item`).
2. Avoid reusing package-exported names for local signals/variables.
3. Import only the specific items you need instead of a wildcard to reduce clashes.
4. Verify which declaration is intended at each use site after resolving the conflict.
