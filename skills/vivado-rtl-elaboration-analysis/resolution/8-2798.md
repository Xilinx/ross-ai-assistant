# 8-2798: Unexpected EOF

**Message:** `[Synth 8-2798] unexpected EOF`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The Verilog/VHDL file ends unexpectedly — a module, entity, or block is not properly closed.

---

## Common Patterns

### P1: Unclosed module/entity at end of file

**Problematic Code:**
```diff
// Before: unclosed module
module top;
  assign out = in;
// missing: endmodule
```

**Recommended Fix:**
```diff
// After: close the module
module top;
  assign out = in;
endmodule
```

---

## Fix Strategy

1. Add the missing closing keyword — `endmodule`, `endfunction`, `endtask`, `end` / `endcase`, or VHDL `end architecture;` / `end entity;` — for the construct that was left open.
2. Balance brackets and `begin`/`end` pairs; an unclosed `(`/`[`/`begin` earlier in the file causes the parser to hit EOF.
3. Use editor bracket-matching or re-indent to locate the unclosed scope near the reported end of file.
4. Check for a stray block comment (`/* ... */` or `-- ... `) that swallowed the closing statement.
