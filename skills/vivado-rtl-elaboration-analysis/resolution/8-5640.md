# 8-5640: Port 'clk_out' is missing in component

**Message:** `[Synth 8-5640] Port 'clk_out' is missing in component declaration`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL `component` declaration is missing a port that exists on the actual entity
(here `clk_out`). When the component declaration does not match the entity's port
list, the extra entity port has no corresponding component port, so it cannot be
associated and Vivado warns that the port is missing from the component.

---

## Common Patterns

### P1: Component declaration out of sync with the entity

**Problematic Code:**
```vhdl
architecture structural of lin_network_xapp432 is
  component lin_controller
    port (
      clk : in  std_logic
      -- clk_out : out std_logic;   <- entity has this port, component omits it
    );
  end component;
```

**Fix - add the missing port to the component declaration:**
```vhdl
  component lin_controller
    port (
      clk     : in  std_logic;
      clk_out : out std_logic     -- now matches the entity
    );
  end component;
```

### P2: Prefer direct entity instantiation to avoid drift

**Fix - instantiate the entity directly so no component copy can go stale:**
```vhdl
u_ctrl : entity work.lin_controller
  port map (clk => clk, clk_out => clk_out);
```

---

## Fix Strategy

1. Compare the `component` declaration against the real entity and add any missing ports (matching name, direction, and type).
2. Keep the component declaration and entity in sync whenever the entity's ports change — or avoid the copy entirely by using direct entity instantiation (`entity work.<name>`).
3. After adding the port, connect it in the `port map` (or leave outputs as `open` if genuinely unused).
4. Verify no other ports differ in direction/type between the component and entity.
