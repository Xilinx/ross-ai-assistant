# 8-274: General Error

**Message:** `[Synth 8-274] error: !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-274] error: <specific error message> [/path/to/file.v:42]
```

---

## Root Cause

This is a generic error message that wraps various specific errors. The actual cause is described in the `!%1!` placeholder.

---

## Common Sub-Messages

| Sub-message | Likely Cause | Fix |
|-------------|--------------|-----|
| "type mismatch" | Incompatible types in operation | Fix type declarations |
| "undefined identifier" | Name not declared | Add declaration |
| "invalid syntax" | Parsing error | Fix syntax |
| "out of range" | Index exceeds bounds | Fix index values |

---

## Diagnostic Steps

1. Read the full error message after "error:"
2. Identify the specific file and line number
3. Examine the code at that location
4. Apply fix based on the specific sub-message

---

## Example Fixes

### Type Mismatch

```verilog
// Before
wire [7:0] a;
wire [15:0] b;
assign a = b;  // error: type mismatch

// After - explicit truncation
assign a = b[7:0];
```

### Undefined Identifier

```verilog
// Before
assign out = undefined_sig;  // error: undefined_sig not declared

// After
wire undefined_sig;
assign out = undefined_sig;
```

### Out of Range

```verilog
// Before
wire [7:0] data;
assign bit = data[10];  // error: out of range

// After
assign bit = data[7];  // valid index
```

---

## Fix Strategy

1. Read the concrete sub-message after `error:` (the `!%1!` text) — it names the real problem; fix that, not the generic wrapper.
2. Go to the reported file and line and address the specific cause (type mismatch, undeclared name, out-of-range index, or syntax).
3. Apply the matching fix from the sub-message table above (declare the name, truncate/resize widths, correct the index, or fix syntax).
4. Re-run elaboration; the `8-274` line disappears once its underlying sub-error is resolved.
