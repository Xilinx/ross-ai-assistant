# 8-478: No Matching Signal

**Message:** `[Synth 8-478] no matching signal '!%1!' for .* connection`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A referenced signal name doesn't exist in the specified scope.

---

## Common Patterns

### P1: Reference to an undeclared signal

**Problematic Code:**
```diff
// Before: signal not found
assign out = a;  // ERROR: 'a' not declared
```

**Recommended Fix:**
```diff
// After: declare the signal
wire a;
assign out = a;
```

---

## Fix Strategy

1. Declare the missing signal with the correct type (`wire` for combinational/`assign` targets, `reg` for procedural targets).
2. Check for a typo — compare against similarly named signals in the same scope and fix the spelling (names are case-sensitive).
3. Verify scope/visibility: the signal may exist in another module or package — import the package or route it through ports rather than referencing across scope.
4. Confirm the reference is in the intended scope and that any generate/block labels in the path are correct.
