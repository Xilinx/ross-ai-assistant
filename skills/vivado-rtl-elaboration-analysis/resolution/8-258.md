# 8-258: Duplicate Association

**Message:** `[Synth 8-258] duplicate !%1! association for '!%2!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-258] duplicate port association for 'clk' [/path/to/file.v:42]
```

---

## Root Cause

A port or generic/parameter is connected more than once in the same instantiation. Each port can only have one connection.

---

## Common Patterns

### P1: Same Port Named Twice (Verilog)

```verilog
// Before - 'clk' connected twice
my_module inst (
  .clk(sys_clk),
  .data(data_in),
  .clk(alt_clk),    // ERROR: duplicate association for 'clk'
  .out(result)
);

// After - remove duplicate
my_module inst (
  .clk(sys_clk),
  .data(data_in),
  .out(result)
);
```

### P2: Mixed Positional and Named (Verilog)

```verilog
// Before - clk connected positionally AND by name
my_module inst (
  sys_clk,          // positional: connects to first port (clk)
  .clk(alt_clk),    // ERROR: clk already connected
  .data(data_in)
);

// After - use only one style
my_module inst (
  .clk(sys_clk),
  .data(data_in)
);
```

### P3: VHDL Generic Duplicate

```vhdl
-- Before - WIDTH specified twice
U0: entity work.my_fifo
  generic map (
    WIDTH => 8,
    DEPTH => 16,
    WIDTH => 16    -- ERROR: duplicate association
  )
  port map (...);

-- After - remove duplicate
U0: entity work.my_fifo
  generic map (
    WIDTH => 8,
    DEPTH => 16
  )
  port map (...);
```

### P4: Mixed-Language Case-Sensitivity (VHDL instantiating Verilog)

```verilog
// Verilog module with case-sensitive ports
module my_mod(a, A, z);    // ports 'a' and 'A' are different in Verilog
  input a;
  input [1:0] A;
  output [1:0] z;
endmodule
```

```vhdl
-- VHDL instantiation — VHDL is case-INSENSITIVE
-- Both 'a' and 'A' resolve to same identifier -> duplicate!
component my_mod
  port (a : in std_logic; \A\ : in std_logic_vector(1 downto 0); z : out std_logic_vector);
end component;

-- ERROR: port map with \A\ seen as duplicate of 'a'
U0 : my_mod port map(a => sig_a, \A\ => sig_B, z => sig_z);
```

**Root Cause:** VHDL is case-insensitive. Escaped identifier `\A\` and regular `a`
resolve to the same port name. This is a mixed-language limitation.

**Fix:** Rename one port in the Verilog module to avoid case-only difference:
```diff
- module my_mod(a, A, z);
-   input a;
-   input [1:0] A;
+ module my_mod(a, data_in, z);
+   input a;
+   input [1:0] data_in;
```

**Important:** This pattern CANNOT be fixed from VHDL side alone. The Verilog
module must be modified to avoid ports that differ only in case.

### P4: VHDL Port Duplicate

```vhdl
-- Before - data_in connected twice
U0: entity work.processor
  port map (
    clk     => sys_clk,
    data_in => input_a,
    data_in => input_b,  -- ERROR: duplicate
    data_out => result
  );

-- After
U0: entity work.processor
  port map (
    clk      => sys_clk,
    data_in  => input_a,
    data_out => result
  );
```

---

## Fix Strategy

1. Search for the duplicated port/generic name
2. Remove one of the associations
3. Verify the remaining connection is correct
