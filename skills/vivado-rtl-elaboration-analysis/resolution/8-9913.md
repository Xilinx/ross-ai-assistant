# 8-9913: Port Not Connected on Function Call

**Message:** `[Synth 8-9913] port is not connected on function call`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A function call is missing a required argument.

---

## Common Patterns

### P1: Missing argument in a call

**Problematic Code:**
```diff
result = func2(a);  // ERROR: 'in1' not connected (needs 2 args)
```

**Recommended Fix:**
```diff
result = func2(a, b);  // provide all arguments
```

---

## Fix Strategy

1. Provide all required arguments in the function/task call — match the subprogram's argument count.
2. Use named argument binding so a missing argument is obvious.
3. If some arguments are optional, give them defaults in the subprogram declaration.
4. Verify argument types/directions match the declaration for each connected argument.
