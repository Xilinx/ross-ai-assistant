# 8-9414: Prefix Not Found in Context

**Message:** `[Synth 8-9414] prefix not found in context reference`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL context reference or use clause has a prefix that doesn't resolve.

---

## Common Patterns

### P1: Unresolved prefix in use/context

**Problematic Code:**
```diff
use pack2.all;  -- ERROR: 'pack2' not found
```

**Recommended Fix:**
```diff
library work;
use work.pack2.all;  -- qualify with library
```

---

## Fix Strategy

1. Qualify the reference with the correct library (`library work; use work.pack2.all;`) so the prefix resolves.
2. Ensure the referenced package/context is compiled into that library before this file.
3. Fix typos in the library/package prefix and confirm it is declared (`library <name>;`).
4. For context references, verify the context declaration exists in the named library.
