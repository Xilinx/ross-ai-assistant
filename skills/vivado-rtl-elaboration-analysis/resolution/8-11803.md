# 8-11803: hierarchical reference is not allowed in net alias statement

**Message:** `[Synth 8-11803] hierarchical reference is not allowed in net alias statement`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `alias` statement references a hierarchical name, which is not allowed in a net alias.

---

## Common Patterns

### P1: Hierarchical reference in net alias

**Problematic Code:**
```systemverilog
alias top.sub.n = w;   // hierarchical
```

**Recommended Fix:**
```systemverilog
alias local_n = w;     // alias only local nets
```

---

## Fix Strategy

1. Alias only local (non-hierarchical) nets.
2. Connect hierarchical signals through ports instead of aliases.
3. Remove the hierarchical path from the alias.
