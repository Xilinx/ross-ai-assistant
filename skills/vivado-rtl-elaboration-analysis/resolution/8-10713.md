# 8-10713: Extra Comma in Port List

**Message:** `[Synth 8-10713] extra comma in port association list is not allowed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10713] extra comma in port association list is not allowed [/path/to/file:NN]
```

---

## Root Cause

A trailing comma after the last port connection in a Verilog instantiation.

---

## Common Patterns

### P1: Trailing comma in port list

**Problematic Code:**
```diff
// Before: trailing comma in port connections
my_mod inst(
  .clk(clk),
  .data(data),   // trailing comma before )
);
```

**Recommended Fix:**
```diff
// After: remove trailing comma
my_mod inst(
  .clk(clk),
  .data(data)    // no trailing comma
);
```

---

## Fix Strategy

1. Remove the trailing comma before the closing parenthesis in the port-connection list.
2. Check for a removed connection that left a dangling comma.
3. Ensure connections are comma-separated with no trailing separator.
4. For intentionally unconnected ports, use `.port()` rather than an empty comma slot.
