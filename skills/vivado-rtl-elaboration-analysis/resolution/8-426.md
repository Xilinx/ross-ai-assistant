# 8-426: Missing Choices in Case

**Message:** `[Synth 8-426] missing choice(s) !%1! in case statement`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL case statement doesn't cover all possible values of the selector.

---

## Common Patterns

### P1: Incomplete case coverage

**Problematic Code:**
```diff
-- Before: missing case choices
case sel is
  when "00" => out <= a;
  when "01" => out <= b;
end case;  -- ERROR: missing 10, 11
```

**Recommended Fix:**
```diff
-- After: cover all choices
case sel is
  when "00" => out <= a;
  when "01" => out <= b;
  when others => out <= c;  -- covers remaining
end case;
```

---

## Fix Strategy

1. Add a `when others =>` choice to cover every remaining selector value — this is the simplest complete fix.
2. Alternatively, explicitly enumerate all possible values of the selector so the case is exhaustive.
3. Assign a default value to the target signal before the `case` so any unlisted path still has a defined value (prevents latches).
4. Check the selector's type/range — for `std_logic_vector`, metavalues (`X`,`Z`,`U`,...) mean only `when others` can make the case complete.
