# 8-9932: Wildcard Associative Array Method

**Message:** `[Synth 8-9932] prefix of array method should not be a wildcard associative array`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An array method is called on a wildcard associative array, which doesn't support the method.

---

## Common Patterns

### P1: Array method on a wildcard assoc array

**Problematic Code:**
```diff
int arr[*];
q = arr.unique_index;  // ERROR: wildcard assoc can't use this
```

**Recommended Fix:**
```diff
int arr[int];  // use typed key instead of wildcard
q = arr.unique_index;
```

---

## Fix Strategy

1. Do not call array methods (`.unique_index`, etc.) on a **wildcard** associative array (`[*]`) — use a typed-key associative array (`[int]`, `[string]`).
2. Associative/dynamic array methods are generally not synthesizable; keep them in verification code.
3. For hardware, use a fixed-size array with explicit index logic instead of associative arrays.
4. Choose the array kind based on the methods you need and synthesizability.
