# 8-1560: Variable Required for Formal

**Message:** `[Synth 8-1560] actual !%1! of formal !%2! must be a !%3!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL actual argument for a formal `variable` parameter is not a variable (e.g., it's a signal).

---

## Common Patterns

### P1: Signal passed where variable formal expected

**Problematic Code:**
```diff
-- Before: signal used where variable required
signal s : integer;
proc(in1 => s);  -- ERROR if formal is variable class
```

**Recommended Fix:**
```diff
-- After: use variable or change formal class
variable v : integer;
proc(in1 => v);  -- variable matches formal
```

---

## Fix Strategy

1. Match the object class of the actual to the formal: if the subprogram formal is `variable`, pass a `variable`; if it is `signal`, pass a `signal`.
2. If you must pass a signal, change the formal's class to `signal` (or `constant` for read-only inputs) in the procedure/function declaration.
3. For `out`/`inout` variable formals, ensure the actual is an assignable variable in the caller's scope.
4. Remember signals and variables have different update semantics — pick the class that matches the intended behavior, not just to silence the error.
