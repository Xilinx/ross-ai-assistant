# 8-8945: Not Declared in Package

**Message:** `[Synth 8-8945] function is not declared in package`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A function referenced via a package-qualified name doesn't exist in that package.

---

## Common Patterns

### P1: Function not in the referenced package

**Problematic Code:**
```diff
result := pack1.func(args);  -- ERROR: func not in pack1
```

**Recommended Fix:**
```diff
-- Check package declaration for the function
-- Or import: use work.pack1.func;
```

---

## Fix Strategy

1. Verify the function is actually declared in the referenced package (check the package declaration, not just the body).
2. Fix the function name/signature in the qualified call to match the package's declaration.
3. Ensure the package is compiled and visible (`use work.pack1.all;`) before the reference.
4. If the function lives in a different package, qualify with that package name instead.
