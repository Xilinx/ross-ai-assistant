# 8-1892: Real Number Missing Digits After Decimal

**Message:** `[Synth 8-1892] digits must follow decimal point in real !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A real number literal has a decimal point but no digits after it.

---

## Common Patterns

### P1: Malformed real literal

**Problematic Code:**
```diff
// Before: malformed real literal
real r = 10.;  // ERROR: no digits after decimal
```

**Recommended Fix:**
```diff
// After: add digit after decimal
real r = 10.0;
// Note: real types are not synthesizable
```

---

## Fix Strategy

1. Write real literals with at least one digit on both sides of the decimal point (`10.0`, not `10.`).
2. For exponent form, ensure a valid mantissa and exponent (`1.0e3`), not a bare `10.e3`.
3. Real/floating-point types are not synthesizable — if this value drives hardware, convert to fixed-point (scaled integer) representation.
4. Keep genuine real-valued computation in simulation/parameter contexts only, and derive synthesizable integer constants from it at elaboration.
