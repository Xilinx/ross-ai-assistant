# 8-9288: Character Not in Generic Type

**Message:** `[Synth 8-9288] character is not in generic type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A character literal doesn't match a generic type parameter.

---

## Common Patterns

### P1: Character invalid for generic type

**Problematic Code:**
```diff
sig <= '1';  -- ERROR: gentype2 may not include '1'
```

**Recommended Fix:**
```diff
-- Ensure generic type supports the character literal
-- Or use type-appropriate value
```

---

## Fix Strategy

1. Check the generic type parameter's actual type and use only character values it permits.
2. If the generic type does not include the literal you need, pass a different actual type at instantiation, or constrain the value to the supported set.
3. Ensure the value assigned matches the generic type's element type exactly.
4. Avoid assuming a generic type supports `std_logic` metavalues — verify against the actual bound type.
