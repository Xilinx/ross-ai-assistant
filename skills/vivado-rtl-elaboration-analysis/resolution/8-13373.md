# 8-13373: Removed Macro Instance

**Message:** `[Synth 8-13373] Removed Macro Instance`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A macro instance was removed during optimization (no outputs connected or constant outputs).

---

## Common Patterns

### P1: Macro instance removed by optimization

**Problematic Code:**
```diff
// Instance removed — outputs not used
```

**Recommended Fix:**
```diff
-- If removal is unintended, add keep attribute:
(* dont_touch = "true" *) my_macro inst(...);
```

---

## Fix Strategy

1. If the macro/instance should be kept, apply `(* dont_touch = "true" *)` / `keep`; otherwise the removal is a correct optimization.
2. Check for unconnected or constant outputs that made the instance dead — connect the outputs if they are needed.
3. Trace whether upstream logic that should drive it is missing.
4. Remove the instance entirely if it is genuinely unused.
