# 8-9610: Illegal Select on Unpacked Struct

**Message:** `[Synth 8-9610] illegal select on unpacked structure/union type variable`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A bit-select or part-select is applied to an unpacked struct/union.

---

## Common Patterns

### P1: Bit-select on an unpacked struct

**Problematic Code:**
```diff
struct {int a; int b;} cd;
assign out = cd[0];  // ERROR: bit-select on unpacked struct
```

**Recommended Fix:**
```diff
assign out = cd.a;  // use field access
// Or make packed: struct packed {...}
```

---

## Fix Strategy

1. Access struct/union members by field name (`cd.a`), not by bit/part-select, unless the type is `packed`.
2. Make the struct `packed` (`typedef struct packed {...}`) if you need bit-level selects across its fields.
3. For a specific field's bits, index the field (`cd.a[3:0]`), not the whole struct.
4. Verify the layout matches how downstream logic reads the data after switching to field access or packed.
