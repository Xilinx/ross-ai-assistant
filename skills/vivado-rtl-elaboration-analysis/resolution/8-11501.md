# 8-11501: Mixed Packed/Unpacked in Operator

**Message:** `[Synth 8-11501] cannot mix packed and unpacked type for operator '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An operator like `==` is used with mixed packed and unpacked operands.

---

## Common Patterns

### P1: Mixed packed/unpacked operands

**Problematic Code:**
```diff
// Before: comparing packed with unpacked
logic [7:0] a;
int b [2];
if (a == b)  // ERROR: can't compare packed with unpacked
```

**Recommended Fix:**
```diff
// After: use consistent types
logic [7:0] a;
logic [7:0] b;  // same packed type
if (a == b)  // OK
```

---

## Fix Strategy

1. Make both operands of a comparison the same packed-vs-unpacked kind and type.
2. Convert one side explicitly (pack via concatenation/streaming) so both match before `==`/`!=`.
3. For arrays/structs, compare element/field-wise or use matching packed representations.
4. Verify widths match so the comparison is meaningful.
