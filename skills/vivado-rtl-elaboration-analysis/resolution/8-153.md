# 8-153: Case Item Never Executed

**Message:** `[Synth 8-153] case item will never be executed`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A case item with `x` or `z` bits will never match in synthesis.

---

## Common Patterns

### P1: Case label with x/z bits

**Problematic Code:**
```diff
case(sel)
  2'bx0: out = a;  // WARNING: x never matches in synthesis
  2'b10: out = b;
```

**Recommended Fix:**
```diff
case(sel)
  2'b00: out = a;  // use concrete values
  2'b10: out = b;
  default: out = c;
```

---

## Fix Strategy

1. Replace `x`/`z` in case labels with concrete `0`/`1` values — in synthesis, `x`/`z` labels never match.
2. If don't-care matching is intended, use `casez` (for `z`/`?`) or `casex` deliberately, and understand that synthesis treats `?` as don't-care but real signals are only 0/1.
3. Add a `default` (or `when others`) branch to cover values that no explicit item matches.
4. Remove dead items entirely if they can never be selected.
