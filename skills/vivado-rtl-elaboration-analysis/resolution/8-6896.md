# 8-6896: Out of Range in Initial

**Message:** `[Synth 8-6896] index out of range inside initial block, initial block items will be ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An index in an initial block is out of range, causing the entire initial block to be ignored.

---

## Common Patterns

### P1: Out-of-range index in initial block

**Problematic Code:**
```diff
// Before: out-of-range in initial
initial mem[0] = data;  // WARNING: index 0 out of range
```

**Recommended Fix:**
```diff
// After: fix index or use valid initialization
initial mem[0] = 8'h00;  -- ensure index is within bounds
```

---

## Fix Strategy

1. Fix the out-of-range index in the `initial` block — the entire block is ignored otherwise, so intended memory initialization is lost.
2. Ensure indices are within the declared array bounds (`0 .. DEPTH-1`) and the array is declared large enough.
3. Prefer `$readmemh`/`$readmemb` or a synchronous reset for memory initialization rather than an `initial` block with computed indices.
4. Verify the memory actually gets its intended initial contents after correcting the index.
