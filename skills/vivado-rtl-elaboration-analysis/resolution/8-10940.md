# 8-10940: macro '!%1!' is redefined

**Message:** `[Synth 8-10940] macro '!%1!' is redefined`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `` `define `` macro is defined more than once. The later definition overrides the earlier one.

---

## Common Patterns

### P1: Macro redefined

**Problematic Code:**
```verilog
`define W 8
`define W 16   // redefined
```

**Recommended Fix:**
```verilog
`ifndef W
`define W 8
`endif
```

---

## Fix Strategy

1. Guard the definition with `` `ifndef ``/`` `endif ``.
2. Remove the duplicate `` `define `` if unintended.
3. Ensure a single header owns each macro.
