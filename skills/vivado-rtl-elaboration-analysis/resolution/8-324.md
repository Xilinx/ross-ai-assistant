# 8-324: Index Out of Range

**Message:** `[Synth 8-324] index out of range`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An array index exceeds the declared bounds. Vivado warns but may still synthesize with truncation.

---

## Common Patterns

### P1: Index outside declared range

**Problematic Code:**
```diff
-- Before: index 32 on 32-bit vector (valid: 0-31)
sig(32) <= '1';  -- WARNING: out of range
```

**Recommended Fix:**
```diff
-- After: use valid index
sig(31) <= '1';  -- within 0..31
```

---

## Fix Strategy

1. Correct a literal index so it stays within the declared bounds (remember the valid range for `[N-1:0]` is `0 .. N-1`; check for off-by-one on the MSB).
2. If the index is computed at runtime, size the index expression to the array's address width and/or add an explicit range guard so it cannot exceed bounds.
3. If the index is legitimately larger, widen the vector/array declaration to match the required range.
4. For VHDL, ensure the index type/range matches the array's declared range (`downto` vs `to`).
