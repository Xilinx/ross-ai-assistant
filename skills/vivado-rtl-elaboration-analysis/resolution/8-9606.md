# 8-9606: Illegal Reference to Automatic Variable

**Message:** `[Synth 8-9606] illegal reference to automatic variable`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An automatic variable is referenced from a static context.

---

## Common Patterns

### P1: automatic variable in static context

**Problematic Code:**
```diff
automatic int mu2;
assign out = mu2;  // ERROR: can't reference from static context
```

**Recommended Fix:**
```diff
int mu2;  // make static
assign out = mu2;
```

---

## Fix Strategy

1. Do not reference an `automatic` (dynamic-lifetime) variable from a static context (continuous assign, module scope) — make the variable static.
2. If the variable must be automatic (reentrant task/function), keep its use inside that automatic scope.
3. For signals read by continuous assignments, declare them at module scope (static), not as automatic locals.
4. Restructure so the value crosses scopes via a port/signal rather than a direct automatic-variable reference.
