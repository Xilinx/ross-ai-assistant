# 8-734: Invalid Parameter

**Message:** `[Synth 8-734] Invalid parameter '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A parameter name used in an override or `defparam` doesn't match any parameter in the target module.

---

## Common Patterns

### P1: Override of a non-existent parameter

**Problematic Code:**
```diff
// Before: parameter doesn't exist
my_mod #(.enableElabSystemTasks(0)) inst(...);  // ERROR: no such parameter
```

**Recommended Fix:**
```diff
// After: use valid parameter name
my_mod #(.WIDTH(8)) inst(...);  // parameter exists in module
```

---

## Fix Strategy

1. Open the target module and use only parameter names that actually exist in its `#(...)` list (names are case-sensitive).
2. Fix typos in the override name, or remove overrides for parameters that no longer exist.
3. Verify you are instantiating the intended, current version of the module — a stale definition without that parameter is a common cause.
4. If the parameter should exist, add it to the module definition rather than forcing the override.
