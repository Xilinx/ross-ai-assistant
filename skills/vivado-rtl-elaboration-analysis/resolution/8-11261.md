# 8-11261: Unpacked Member in Packed Struct

**Message:** `[Synth 8-11261] unpacked member '!%1!' is not allowed in a packed struct/union`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A packed struct/union contains an unpacked member, which is not allowed.

---

## Common Patterns

### P1: Unpacked member in a packed struct

**Problematic Code:**
```diff
// Before: unpacked type in packed struct
typedef struct packed {
  int a;        // OK: int is packed
  string b;     // ERROR: string is unpacked
} my_struct;
```

**Recommended Fix:**
```diff
// After: use only packed types
typedef struct packed {
  int a;
  logic [63:0] b;  // replace string with packed type
} my_struct;
```

---

## Fix Strategy

1. Use only packed members in a packed struct/union — replace `string`, dynamic arrays, and other unpacked types with fixed-width `logic`/`bit`/`byte` fields.
2. If a member must be a struct, make that nested struct `packed` too.
3. For textual data, use a fixed-length packed byte vector instead of `string`.
4. Verify every member is a same-family packed type so the union/struct has a defined bit layout.
