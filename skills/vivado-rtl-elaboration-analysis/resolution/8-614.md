# 8-614: Missing Sensitivity List Signal

**Message:** `[Synth 8-614] signal is read in the process but is not in the sensitivity list`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A signal read in a process is not listed in the sensitivity list.

---

## Common Patterns

### P1: Signal read but missing from sensitivity list

**Problematic Code:**
```diff
-- Before: 'a' read but not in sensitivity
process(clk)
begin
  out1 <= a and b;  -- WARNING: a not in list
```

**Recommended Fix:**
```diff
-- After: add all signals or use 'all'
process(all)  -- VHDL-2008
  out1 <= a and b;
```

---

## Fix Strategy

1. Add every signal read in the process to the sensitivity list, or use `process(all)` (VHDL-2008) / `process(*)` to have it inferred completely.
2. An incomplete sensitivity list on combinational logic causes simulation/synthesis mismatch — treat it as a real bug, not just a warning.
3. For a clocked process, the sensitivity list should contain only the clock (and async reset); do not add data signals there — instead move purely combinational reads into a separate `process(all)` block.
4. Verify whether the block is meant to be combinational or sequential and structure the sensitivity list accordingly.
