# 8-2887: Directive Unsupported

**Message:** `[Synth 8-2887] Directive on instance is unsupported and ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A synthesis directive or attribute is not recognized by Vivado.

---

## Common Patterns

### P1: Unsupported directive/attribute on instance

**Problematic Code:**
```diff
// Unsupported directive on instance
```

**Recommended Fix:**
```diff
-- Remove unsupported directives or replace with Vivado equivalents
-- See UG901 for supported attributes
```

---

## Fix Strategy

1. The unsupported directive/attribute is ignored — remove it or replace it with the Vivado-supported equivalent (see UG901 for the supported attribute list).
2. Map common third-party pragmas to Vivado attributes (e.g., keep/preserve -> `(* keep = "true" *)` / `(* dont_touch = "true" *)`).
3. If the directive was load-bearing (affecting optimization/mapping), apply the equivalent Vivado constraint in XDC or as an attribute so intent is preserved.
4. Confirm after synthesis that the intended behavior (retention, RAM style, etc.) actually took effect.
