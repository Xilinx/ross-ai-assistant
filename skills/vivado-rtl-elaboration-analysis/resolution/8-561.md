# 8-561: Range Not Constant

**Message:** `[Synth 8-561] range expression could not be resolved to a constant`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A range expression could not be resolved to a constant, required for array bounds or generate ranges.

---

## Common Patterns

### P1: Non-constant range/bound

**Problematic Code:**
```diff
// Before: non-constant range
wire [func(x):0] data;  // ERROR: func(x) not constant
```

**Recommended Fix:**
```diff
// After: use constant
localparam WIDTH = 8;
wire [WIDTH-1:0] data;
```

---

## Fix Strategy

1. Use elaboration-time constants for all array bounds and ranges: `parameter`/`localparam` (Verilog) or `constant`/`generic` (VHDL).
2. If the range currently depends on a signal or non-constant function, restructure so the value is fixed at elaboration (derive it from parameters).
3. Ensure any function used in a bound is a constant function evaluable at elaboration — no signal reads inside it.
4. Parameterize widths (`localparam WIDTH = ...; wire [WIDTH-1:0] data;`) so ranges stay constant and configurable.
