# 8-11065: parameter '!%1!' becomes localparam in '!%2!' with formal parameter ...

**Message:** `[Synth 8-11065] parameter '!%1!' becomes localparam in '!%2!' with formal parameter declaration list`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `parameter` in a module using a formal parameter declaration list is treated as a `localparam` because it cannot be overridden there.

---

## Common Patterns

### P1: Parameter becomes localparam (formal parameter list)

**Problematic Code:**
```verilog
module m #(parameter W=8) (...);  // with formal list, W is fixed
```

**Recommended Fix:**
```verilog
module m #(parameter W=8) (...);  // declare truly-fixed values as localparam
```

---

## Fix Strategy

1. Declare values that are not meant to be overridden as `localparam`.
2. Pass real overrides through the module's parameter port list.
3. This is advisory; the parameter is fixed to its default.
