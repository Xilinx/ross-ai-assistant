# 8-11057: overflow of 32-bit signed integer !%1!; using !%2! instead

**Message:** `[Synth 8-11057] overflow of 32-bit signed integer !%1!; using !%2! instead`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An integer constant expression overflows 32-bit signed range; the tool uses a substituted value.

---

## Common Patterns

### P1: Overflow of 32-bit signed integer

**Problematic Code:**
```verilog
localparam BIG = 3000000000;   // > 2^31-1
```

**Recommended Fix:**
```verilog
localparam longint BIG = 3000000000;   // use a wider type
```

---

## Fix Strategy

1. Use a wider type (`longint`/64-bit) or a sized literal for large constants.
2. Verify the intended magnitude fits the declared width.
3. This is a warning; size the constant explicitly.
