# 8-6038: Cannot Resolve Hierarchical Name

**Message:** `[Synth 8-6038] cannot resolve hierarchical name for the item '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A hierarchical reference to a signal cannot be resolved — the path doesn't exist.

---

## Common Patterns

### P1: Unresolvable hierarchical reference

**Problematic Code:**
```diff
// Before: bad hierarchical reference
assign out1 = inst.sub.out1;  // ERROR: path not found
```

**Recommended Fix:**
```diff
// After: fix the hierarchy or use ports
// Check instance names in the hierarchy
// Or bring signal out through ports instead of hierarchical refs
```

---

## Fix Strategy

1. Cross-module **hierarchical references** are not synthesizable — replace them by bringing the signal out through module ports and connecting it structurally.
2. If you must keep a hierarchical path (e.g., for simulation), verify every instance name in the path exactly matches the design tree.
3. Route shared signals through the port list of each level rather than reaching into sub-instances.
4. Fix typos in instance/signal names and confirm the referenced scope actually exists.
