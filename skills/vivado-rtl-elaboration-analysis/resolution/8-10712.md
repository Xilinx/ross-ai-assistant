# 8-10712: Extra Comma in Parameter List

**Message:** `[Synth 8-10712] extra comma in parameter association list is not allowed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10712] extra comma in parameter association list is not allowed [/path/to/file:NN]
```

---

## Root Cause

A trailing or misplaced comma in a Verilog parameter list.

---

## Common Patterns

### P1: Trailing comma in parameter list

**Problematic Code:**
```diff
// Before: trailing comma after last parameter
module #(parameter A = 1,
         parameter B = 2,  // trailing comma
        ) my_mod(...);
```

**Recommended Fix:**
```diff
// After: remove trailing comma
module #(parameter A = 1,
         parameter B = 2   // no trailing comma
        ) my_mod(...);
```

---

## Fix Strategy

1. Remove the extra/trailing comma from the parameter list — Verilog does not allow trailing commas.
2. Check for a deleted item that left a dangling comma.
3. Ensure each parameter is separated by exactly one comma with no trailing separator.
4. Re-check adjacent lists (ports) for the same issue.
