# 8-13162: Box Not Allowed in Package Instantiation

**Message:** `[Synth 8-13162] illegal generic map aspect; '!%1!' is not allowed in '!%2!' instantiation`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL generic map uses `<>` (box) in a package instantiation, which is not allowed.

---

## Common Patterns

### P1: Box <> in package instantiation

**Problematic Code:**
```diff
-- Before: box in package instantiation
package my_pkg is new work.gen_pkg generic map(<>);  -- ERROR
```

**Recommended Fix:**
```diff
-- After: provide explicit mapping
package my_pkg is new work.gen_pkg generic map(T => integer);
```

---

## Fix Strategy

1. Provide **explicit** generic mappings in a package instantiation — the box `<>` (default) is not allowed there.
2. Map each generic to a concrete value/type when instantiating the generic package.
3. Confirm the flow supports VHDL-2008 generic packages; otherwise use a concrete package.
4. Ensure the mapped actuals satisfy the package's generic constraints.
