# 8-10791: illegal assignment to constant '!%1!'

**Message:** `[Synth 8-10791] illegal assignment to constant '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A `localparam`/`parameter`/`const` is assigned a new value in procedural or continuous code. Constants cannot be reassigned.

---

## Common Patterns

### P1: Illegal assignment to a constant

**Problematic Code:**
```verilog
localparam W = 8;
always @* W = 16;   // illegal
```

**Recommended Fix:**
```verilog
localparam W = 8;   // keep constant; use a variable if it must change
```

---

## Fix Strategy

1. Do not assign to a constant; declare a `reg`/`logic` variable if the value must change.
2. If the value is fixed, remove the reassignment.
3. Check that the target is not accidentally a parameter/localparam.
