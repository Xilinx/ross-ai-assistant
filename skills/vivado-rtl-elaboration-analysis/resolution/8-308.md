# 8-308: Ignoring Empty Port

**Message:** `[Synth 8-308] ignoring empty port`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An empty port connection `()` is ignored.

---

## Common Patterns

### P1: Empty port association

**Problematic Code:**
```diff
my_mod inst(.clk(clk), .data(), .out(result));  // WARNING: empty data port
```

**Recommended Fix:**
```diff
my_mod inst(.clk(clk), .out(result));  // omit unconnected port entirely
```

---

## Fix Strategy

1. Remove the empty `.port()` association entirely if the port is truly unused, or connect it to a real signal.
2. For an intentionally unused **input**, tie it to an explicit constant (`.port(1'b0)` / `.port('0)`) so the intent is clear and the tool does not float it.
3. For an unused **output**, simply omit it (leave it unconnected) rather than writing `.port()`.
4. Double-check the empty port was not meant to carry a needed signal — an accidental empty connection silently drops functionality.
