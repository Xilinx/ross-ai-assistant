# 8-9121: Always_ff Must Have One Event

**Message:** `[Synth 8-9121] an always_ff block must have one and only one event control`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An `always_ff` block has zero or multiple event controls.

---

## Common Patterns

### P1: always_ff with wrong event control

**Problematic Code:**
```diff
always_ff @(posedge clk or posedge clk2)  // ERROR: 2 clock edges
  ...
```

**Recommended Fix:**
```diff
always_ff @(posedge clk)  // single clock
  if (!rst_n) ... else ...;
```

---

## Fix Strategy

1. Give `always_ff` exactly **one** event control with a single clock edge (`@(posedge clk)`).
2. For an asynchronous reset, use `@(posedge clk or negedge rst_n)` — one clock edge plus one reset edge — not two clocks.
3. Do not list two clock edges or omit the event control in an `always_ff`.
4. Move purely combinational logic to `always_comb`; keep `always_ff` for single-clock registers.
