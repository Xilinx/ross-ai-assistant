# 8-11534: New on Non-Dynamic Array

**Message:** `[Synth 8-11534] illegal target for 'new' expression with size argument; expected dynamic array`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The `new[size]` expression is used on a non-dynamic array type.

---

## Common Patterns

### P1: new[] on a fixed-size array

**Problematic Code:**
```diff
// Before: new on fixed array
int arr[4];
arr = new[8];  // ERROR: arr is fixed-size, not dynamic
```

**Recommended Fix:**
```diff
// After: use dynamic array or fixed size
int arr[];    // dynamic array
arr = new[8]; // OK
```

---

## Fix Strategy

1. `new[size]` applies only to **dynamic** arrays (`type name[]`) — declare the array dynamic, or size a fixed array at declaration instead.
2. Dynamic arrays are not synthesizable; for hardware, use a fixed-size array with a constant depth.
3. Keep `new[]` allocation in verification code only.
4. Verify the array declaration matches how you intend to size it.
