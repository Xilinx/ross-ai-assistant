# 8-10302: !%1! is not allowed here

**Message:** `[Synth 8-10302] !%1! is not allowed here`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A construct is used in a place the language does not permit (e.g. a statement or declaration in a scope where it is illegal).

---

## Common Patterns

### P1: Construct not allowed in this context

**Problematic Code:**
```systemverilog
// construct placed where it is not allowed
```

**Recommended Fix:**
```systemverilog
// move the construct to a legal scope, or remove it
```

---

## Fix Strategy

1. Read the flagged line and move the construct to a context where it is legal.
2. Common cause: a declaration/statement in the wrong scope (module vs block vs $unit).
3. Remove the construct if it is not needed in synthesizable RTL.
