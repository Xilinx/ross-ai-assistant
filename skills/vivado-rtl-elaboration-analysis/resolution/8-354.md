# 8-354: Integer Overflow in Array Size

**Message:** `[Synth 8-354] integer overflow when computing array size`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Array size computation overflows the integer range.

---

## Common Patterns

### P1: Array size overflows integer range

**Problematic Code:**
```diff
// Before: array size too large
reg [31:0] mem [0:2**32-1];  // ERROR: 4G entries overflows
```

**Recommended Fix:**
```diff
// After: use reasonable size
reg [31:0] mem [0:1023];  // 1K entries
// Or parameterize:
parameter DEPTH = 1024;
reg [31:0] mem [0:DEPTH-1];
```

---

## Fix Strategy

1. Reduce the array depth to a realistic, implementable size; a multi-gigabit memory almost always indicates a mistake.
2. Check exponent/shift expressions (`2**N`, `1 << N`) — an oversized `N` overflows the 32-bit size computation; clamp or correct it.
3. Parameterize the depth (`parameter DEPTH = 1024; reg [W-1:0] mem [0:DEPTH-1];`) and ensure the computed size fits within the tool's limits.
4. For large storage, target a block-RAM-sized array and let the tool infer BRAM instead of declaring an unrealistic flat array.
