# 8-8896: Unknown Type

**Message:** `[Synth 8-8896] '!%1!' is an unknown type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A type name is not recognized — it's not declared or imported.

---

## Common Patterns

### P1: Use of an undeclared type

**Problematic Code:**
```diff
// Before: unknown type
pc_intsvadr my_var;  // ERROR: 'pc_intsvadr' unknown
```

**Recommended Fix:**
```diff
// After: declare or import the type
typedef logic [31:0] pc_intsvadr;
pc_intsvadr my_var;  // now known
```

---

## Fix Strategy

1. Declare the type before use (`typedef ...`) or `import`/`use` the package that defines it.
2. Ensure the defining package/file is compiled before this file and the type is visible in scope.
3. Fix typos — type names are case-sensitive in SystemVerilog and must match exactly.
4. If the type comes from a package, add the correct `import pkg::*;` / `use work.pkg.all;`.
