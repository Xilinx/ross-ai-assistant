# 8-2716: syntax error near '!%1!'

**Message:** `[Synth 8-2716] syntax error near '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The parser reached a token it did not expect near the reported location. This is a
*general* syntax error - the actual cause is whatever is malformed just before the
named token. It fires for many different mistakes, so inspect the exact file:line and
match it to one of the patterns below.

---

## Common Patterns

### P1: Invalid keyword/qualifier on a declaration

**Problematic Code:**
```verilog
reg scalared [3:0] data;   // 'scalared'/'vectored' apply only to nets
```

**Recommended Fix:**
```verilog
reg [3:0] data;            // drop the net-only qualifier
```

### P2: Missing loop variable in a for/generate loop (VHDL)

**Problematic Code:**
```vhdl
forgen: for in 0 to 1 generate   -- syntax error near 'in' (no loop variable)
```

**Recommended Fix:**
```vhdl
forgen: for i in 0 to 1 generate -- add the loop variable
```

### P3: Wrong statement/keyword in a subprogram body (VHDL)

**Problematic Code:**
```vhdl
procedure p(signal b : out bit) is
begin
  return (a and b);   -- syntax error near 'begin'/'return': procedures don't return a value
end procedure;
```

**Recommended Fix:**
```vhdl
procedure p(signal b : out bit) is
begin
  b <= a;             -- assign the out parameter instead
end procedure;
```

### P4: Unsupported verification construct (PSL/assertions) in synthesizable source

**Problematic Code:**
```vhdl
default clock is (clk'event and clk = '1');   -- syntax error near 'default'
assume always(prop);                          -- PSL, not synthesizable VHDL
```

**Recommended Fix:**
```vhdl
-- remove PSL directives from the synthesized source (keep them in a verification file,
-- or wrap as '-- psl' comment pragmas that synthesis ignores)
```

### P5: Cascade from an undefined macro / earlier error

**Problematic Code:**
```verilog
case (state)
  `CYC_NOOP :   // `CYC_NOOP undefined -> expands to nothing -> "syntax error near ':'"
```

**Recommended Fix:**
```verilog
`include "cyc_defs.vh"   // define the macro (or fix the earlier error); the syntax error clears
case (state)
  `CYC_NOOP :
```

### P6: Stray/placeholder or misplaced token (missing/extra ';', template text)

**Problematic Code:**
```vhdl
end process;
file_open([<file_handle>, <file_name>, <file_mode>);   -- leftover template line
```

**Recommended Fix:**
```vhdl
end process;
-- delete the placeholder/misplaced line; check for a missing or extra ';'
```

---

## Fix Strategy

1. Read the exact file:line - the error is in the token(s) **just before** the named token.
2. Match it to a pattern above: bad keyword/qualifier, missing loop variable, illegal
   statement in a subprogram, unsupported PSL/assertion, undefined-macro cascade, or a
   stray/placeholder/misplaced token.
3. Fix that construct, then re-run - later `8-2716` errors on following lines are often
   cascades that clear once the first one is fixed.
4. For undefined-macro cascades, add the missing `` `include ``/`` `define `` first.
5. Check balanced `begin`/`end`, `module`/`endmodule`, `entity`/`end`, parentheses and
   semicolons around the reported line.
