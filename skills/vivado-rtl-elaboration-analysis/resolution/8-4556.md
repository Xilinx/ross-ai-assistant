# 8-4556: Variable Too Large

**Message:** `[Synth 8-4556] size of variable '!%1!' is too large to handle; the size of the variable is !%2!, the limit is !%3!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A variable/array exceeds the maximum size the synthesis tool can handle.

---

## Common Patterns

### P1: Array larger than tool limits

**Problematic Code:**
```diff
// Before: 1GB array
reg [7:0] netArray [0:134217727];  // ERROR: 1GB too large
```

**Recommended Fix:**
```diff
// After: reduce size
reg [7:0] netArray [0:65535];  // 64KB — reasonable for synthesis
```

---

## Fix Strategy

1. Reduce the array/variable depth to a realistic, implementable size — a multi-hundred-MB/GB array is almost always a mistake.
2. Check the depth/width expressions (`2**N`, address widths) for an oversized parameter and correct it.
3. For large storage, target BRAM-sized memories and let the tool infer BRAM instead of a huge flat array.
4. If the data set is genuinely large, restructure to external memory (DDR) accessed through a controller rather than on-chip arrays.
