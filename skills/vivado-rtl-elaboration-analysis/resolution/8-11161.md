# 8-11161: signal '!%1!' is used in a subtype-indication or type-definition

**Message:** `[Synth 8-11161] signal '!%1!' is used in a subtype-indication or type-definition`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A signal is referenced inside a subtype indication or type definition, where only static/constant values are allowed.

---

## Common Patterns

### P1: Signal used in a subtype/type definition

**Problematic Code:**
```vhdl
subtype st is std_logic_vector(sig-1 downto 0);  -- 'sig' is a signal
```

**Recommended Fix:**
```vhdl
constant N : integer := 8;
subtype st is std_logic_vector(N-1 downto 0);
```

---

## Fix Strategy

1. Use constants/generics (not signals) in type/subtype definitions.
2. Types must be statically determinable at elaboration.
3. Replace the signal bound with a constant or generic.
