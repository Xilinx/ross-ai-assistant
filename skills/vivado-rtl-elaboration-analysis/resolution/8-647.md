# 8-647: Too Many Elements in Subexpression

**Message:** `[Synth 8-647] too many elements in subexpression`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A concatenation or expression has more elements than the target can hold.

---

## Common Patterns

### P1: More source elements than targets

**Problematic Code:**
```diff
// Before: too many elements
assign {a, b, c} = {d, e, f, g};  // ERROR: 4 sources for 3 targets
```

**Recommended Fix:**
```diff
// After: match element counts
assign {a, b, c} = {d, e, f};  // 3 = 3
```

---

## Fix Strategy

1. Make the element count on both sides of a concatenation/assignment equal — remove the extra source(s) or add matching targets.
2. Check total bit widths, not just element counts: the concatenation's total width must match the target's width.
3. If some sources are unneeded, drop them; if a target bit is missing, extend the target vector.
4. Use explicit widths on literals inside the concatenation so the total width is unambiguous.
