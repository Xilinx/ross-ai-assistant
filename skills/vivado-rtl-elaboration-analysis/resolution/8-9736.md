# 8-9736: missing or empty argument against format specification for '!%1!'

**Message:** `[Synth 8-9736] missing or empty argument against format specification for '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A format string (e.g. in `$display`) has a specifier with no matching argument.

---

## Common Patterns

### P1: Missing argument for format specifier

**Problematic Code:**
```verilog
$display("%d %d", a);   // second %d has no arg
```

**Recommended Fix:**
```verilog
$display("%d %d", a, b);
```

---

## Fix Strategy

1. Provide one argument per format specifier.
2. Remove extra specifiers, or add the missing arguments.
3. Check the format string for a stray `%`.
