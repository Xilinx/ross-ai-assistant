# 8-10790: Assignment to Const Variable

**Message:** `[Synth 8-10790] illegal assignment to const variable`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10790] illegal assignment to const variable [/path/to/file:NN]
```

---

## Root Cause

A SystemVerilog `const` variable is modified after initialization.

---

## Common Patterns

### P1: Assignment to a const variable

**Problematic Code:**
```diff
// Before: modifying const variable
const int a = 5;
always_comb begin
  a = a + in;     // ERROR: a is const
end
```

**Recommended Fix:**
```diff
// After: use non-const variable or parameter
int a;              // remove const for mutable variable
always_comb begin
  a = 5 + in;
end
// Or use localparam if truly constant:
localparam int A = 5;
```

---

## Fix Strategy

1. If the variable must change, remove `const` and declare it as a normal variable.
2. If it should stay constant, remove the assignment — that write is the bug.
3. Use `localparam`/`parameter` for true compile-time constants, not a mutable `const` misuse.
4. Separate compile-time configuration from runtime state.
