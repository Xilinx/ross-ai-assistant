# 8-9114: Out Port Actual Cannot Be Expression

**Message:** `[Synth 8-9114] actual of formal out port cannot be an expression`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An output port is connected to an expression (not a simple net/variable).

---

## Common Patterns

### P1: Expression on an output port actual

**Problematic Code:**
```diff
port map(o => a and b);  -- ERROR: expression on out port
```

**Recommended Fix:**
```diff
signal temp : std_logic;
port map(o => temp);
-- Then: result <= temp and other_sig;
```

---

## Fix Strategy

1. Connect an `out` port to a **simple net/variable**, not an expression — introduce an intermediate signal and compute the expression separately.
2. Drive the intermediate from the port (`port map(o => temp);`) then use `temp` in the expression on the consuming side.
3. Prefer named association and ensure the intermediate's type/width matches the port.
4. Never place logic (`a and b`) directly on an output port actual.
