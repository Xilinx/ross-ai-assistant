# 8-9871: overwriting existing primary unit '!%1!'

**Message:** `[Synth 8-9871] overwriting existing primary unit '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A primary unit (entity/package declaration) is being recompiled/overwritten, hiding the previous one.

---

## Common Patterns

### P1: Overwriting existing primary unit

**Problematic Code:**
```vhdl
-- entity 'e' defined twice in the compile set
```

**Recommended Fix:**
```vhdl
-- keep a single definition of entity/package 'e'
```

---

## Fix Strategy

1. Ensure each primary unit is defined once in the compile set.
2. Remove duplicate entity/package sources.
3. Check the file list for a repeated unit.
