# 8-9224: Cannot Convert Types

**Message:** `[Synth 8-9224] cannot convert type to another type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL type conversion between incompatible types.

---

## Common Patterns

### P1: Direct cast between incompatible types

**Problematic Code:**
```diff
sig <= signed(bit_vec);  -- ERROR: can't convert bit_vector to signed directly
```

**Recommended Fix:**
```diff
sig <= signed(to_stdlogicvector(bit_vec));  -- convert via std_logic_vector
```

---

## Fix Strategy

1. Convert through a compatible intermediate type — e.g., `bit_vector` -> `std_logic_vector` -> `signed`/`unsigned` using the proper conversion functions.
2. Use `numeric_std`/`std_logic_1164` conversion functions (`to_stdlogicvector`, `std_logic_vector`, `signed`, `unsigned`, `to_integer`) rather than direct casts between unrelated types.
3. Ensure the source and destination have the same width before a value-preserving conversion.
4. Import the packages that define the needed conversion functions.
