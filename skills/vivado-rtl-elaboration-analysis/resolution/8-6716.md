# 8-6716: converting !%1! to !%2!

**Message:** `[Synth 8-6716] converting !%1! to !%2!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The tool reports an implicit conversion between two types (informational); a mismatch or unintended conversion may be occurring.

---

## Common Patterns

### P1: Implicit type conversion

**Problematic Code:**
```vhdl
y <= std_logic_vector(int_sig);  -- verify the conversion is intended
```

**Recommended Fix:**
```vhdl
-- make the conversion explicit and width-matched
y <= std_logic_vector(to_unsigned(int_sig, y'length));
```

---

## Fix Strategy

1. Confirm the source/target types and widths are intended.
2. Make conversions explicit (numeric_std functions) rather than relying on implicit ones.
3. Match widths to avoid silent truncation/extension.
