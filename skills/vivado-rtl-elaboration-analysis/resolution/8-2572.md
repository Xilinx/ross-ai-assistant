# 8-2572: Previous Syntax Error

**Message:** `[Synth 8-2572] previous syntax error may be due to incorrect attribute placement`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

This error indicates a follow-on issue caused by an earlier syntax error. Often caused by incorrect attribute placement.

---

## Common Patterns

### P1: Cascading error from an earlier line

**Problematic Code:**
```diff
// The actual fix is usually on a PREVIOUS line
// Check for missing semicolons, unclosed brackets, or misplaced attributes
```

**Recommended Fix:**
```diff
// Fix: look at the line BEFORE this error
// Common causes:
// - Missing semicolon on previous line
// - Misplaced (* attribute *)
// - Unclosed parenthesis
```

---

## Fix Strategy

1. This is a **cascading** error — the real problem is on or before the line the parser reports; fix the earlier issue and this one usually disappears.
2. Check the preceding lines for a missing `;`, an unclosed `(`/`[`/`begin`, or a misplaced `(* attribute *)`.
3. Re-elaborate after each fix; parser recovery can generate several spurious follow-on errors from one root cause.
4. Work top-down through the file — fix the first reported syntax error first, then rebuild.
