# 8-10300: !%1! is deprecated in IEEE Std 1800-2017

**Message:** `[Synth 8-10300] !%1! is deprecated in IEEE Std 1800-2017`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

The RTL uses a construct that is deprecated in IEEE Std 1800-2017. It still elaborates but should be replaced with the current form.
