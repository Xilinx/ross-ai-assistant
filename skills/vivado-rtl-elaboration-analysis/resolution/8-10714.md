# 8-10714: extra semicolon is not allowed here in this dialect; use SystemVerilog ...

**Message:** `[Synth 8-10714] extra semicolon is not allowed here in this dialect; use SystemVerilog mode instead`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A stray/extra semicolon appears where the current Verilog dialect does not allow it (SystemVerilog is more permissive).

---

## Common Patterns

### P1: Extra semicolon not allowed in this dialect

**Problematic Code:**
```systemverilog
always @* begin;; a=b; end   // extra ';'
```

**Recommended Fix:**
```systemverilog
always @* begin a=b; end
```

---

## Fix Strategy

1. Remove the extra semicolon.
2. Or compile in SystemVerilog mode if empty statements are intended.
3. Check for a misplaced `;` after begin/end or a block header.
