# 8-9486: Formal Port Has No Actual

**Message:** `[Synth 8-9486] formal port has no actual or default value`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL port is not connected and has no default value.

---

## Common Patterns

### P1: Unconnected port with no default

**Problematic Code:**
```diff
port (vegatednandin : in std_logic);  -- no default
-- instantiation: port map(...)  -- vegatednandin missing
```

**Recommended Fix:**
```diff
port (vegatednandin : in std_logic := '0');  -- add default
-- Or connect: port map(vegatednandin => sig)
```

---

## Fix Strategy

1. Connect the port in the `port map`, or give it a default value in the entity (`port (p : in std_logic := '0')`).
2. For unused outputs, map to `open`; for required inputs, they must be driven — connect a real signal.
3. Use named association so a missing port association is obvious.
4. Verify the component declaration matches the entity so no port is unexpectedly unconnected.
