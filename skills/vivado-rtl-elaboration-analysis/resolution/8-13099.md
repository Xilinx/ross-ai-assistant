# 8-13099: dynamic variables shall not be written with !%1! assignments

**Message:** `[Synth 8-13099] dynamic variables shall not be written with !%1! assignments`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A dynamic variable is written with an assignment kind not permitted for it (e.g. a nonblocking assignment to a dynamic object).

---

## Common Patterns

### P1: Dynamic variable written with wrong assignment

**Problematic Code:**
```systemverilog
dyn_q <= x;   // nonblocking to a dynamic variable
```

**Recommended Fix:**
```systemverilog
dyn_q = x;    // use a blocking assignment
```

---

## Fix Strategy

1. Use the permitted assignment kind (usually blocking) for dynamic variables.
2. Dynamic types (queues/dynamic arrays) are non-synthesizable - keep in testbench.
3. Restructure to a static vector/array for synthesis.
