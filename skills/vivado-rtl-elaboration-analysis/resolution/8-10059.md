# 8-10059: System Task in Constant Function

**Message:** `[Synth 8-10059] system function/task may not be used in constant function`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10059] system function/task may not be used in constant function [/path/to/file:NN]
```

---

## Root Cause

A constant function (used for compile-time evaluation) calls a system task like `$time`, `$display`, etc. which are runtime-only.

---

## Common Patterns

### P1: System task in a constant function

**Problematic Code:**
```diff
// Before: $time in constant function
reg [0:consfunc(1)] r;
function integer consfunc;
  input i;
  time t;
  begin
    consfunc = 31;
    t = $time;       // ERROR: $time not allowed in constant function
  end
endfunction
```

**Recommended Fix:**
```diff
// After: remove system task call
function integer consfunc;
  input i;
  begin
    consfunc = 31;   // removed $time — not needed for constant evaluation
  end
endfunction
```

---

## Fix Strategy

1. Remove all system task/function calls (`$time`, `$display`, `$finish`, `$random`, ...) from constant functions — they cannot be evaluated at elaboration.
2. Keep constant functions pure: only their arguments, locals, and constant operations.
3. If runtime behavior was intended, move it out of the constant context into simulation/runtime logic.
4. Ensure the function still returns the intended constant value after removing the system calls.
