# 8-10604: concatenation with an unsized literal will be treated as 32 bits

**Message:** `[Synth 8-10604] concatenation with an unsized literal will be treated as 32 bits`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An unsized literal (e.g. `'1`, `1`) is used inside a concatenation, where it defaults to 32 bits - usually not what was intended.

---

## Common Patterns

### P1: Unsized literal in concatenation treated as 32 bits

**Problematic Code:**
```verilog
assign y = {a, 1};   // '1' is 32 bits here
```

**Recommended Fix:**
```verilog
assign y = {a, 1'b1};   // give the literal an explicit width
```

---

## Fix Strategy

1. Give every literal in a concatenation an explicit width (`N'bxxx`).
2. Unsized literals default to 32 bits inside concatenations.
3. This is a warning; size the literal to avoid width surprises.
