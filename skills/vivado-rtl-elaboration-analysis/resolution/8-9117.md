# 8-9117: Self-Aliasing Not Allowed

**Message:** `[Synth 8-9117] aliasing an individual signal to itself is not allowed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL alias points a signal back to itself.

---

## Common Patterns

### P1: Alias of a signal to itself

**Problematic Code:**
```diff
alias a : std_logic is in1;
-- where a and in1 are the same signal  -- ERROR
```

**Recommended Fix:**
```diff
-- Remove the self-alias or alias to a different signal
alias a : std_logic is other_sig;
```

---

## Fix Strategy

1. Remove the self-referential alias — aliasing a signal to itself is meaningless and illegal.
2. If an alias was intended, point it at a **different** object (a slice/field of another signal).
3. Check for a typo where the alias target name accidentally matches the alias name.
4. If you only needed a shorter name, alias a portion of a larger signal instead of the whole same signal.
