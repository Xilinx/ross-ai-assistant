# 8-264: Latch Enable Inference

**Message:** `[Synth 8-264] enable of latch inferred`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

Vivado infers a latch because a signal is not assigned in all branches of combinational logic.

---

## Common Patterns

### P1: Missing else branch in combinational logic

**Problematic Code:**
```diff
always @(*)
  if (en) q = d;  // WARNING: latch on q (no else branch)
```

**Recommended Fix:**
```diff
always @(*)
  if (en) q = d;
  else q = 1'b0;  // assign in all branches
```

---

## Fix Strategy

1. Assign the signal in **every** branch: add the missing `else`, or provide a default assignment at the top of the combinational block before the conditionals.
2. Ensure `case` statements are full or include a `default`; a partial case also infers a latch.
3. Use `always_comb` (SystemVerilog) so the tool actively checks for incomplete assignment and unintended latches.
4. If a latch is genuinely intended, document it explicitly; otherwise treat this warning as a bug and drive the signal in all paths.
