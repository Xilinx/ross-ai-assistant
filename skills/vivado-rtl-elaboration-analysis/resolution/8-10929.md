# 8-10929: literal value !%1! truncated to fit in !%2! bits

**Message:** `[Synth 8-10929] literal value !%1! truncated to fit in !%2! bits`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A literal is wider than the target and its high bits are dropped (truncated) to fit the declared width.

---

## Common Patterns

### P1: Literal value truncated to fit

**Problematic Code:**
```verilog
reg [3:0] r;
r = 8'hAB;   // truncated to 4 bits (0xB)
```

**Recommended Fix:**
```verilog
reg [7:0] r;
r = 8'hAB;   // widen the target, or use a value that fits
```

---

## Fix Strategy

1. Size the literal to fit the target width, or widen the target.
2. Confirm the intended value is not being silently truncated.
3. This is a warning; make the width relationship explicit.
