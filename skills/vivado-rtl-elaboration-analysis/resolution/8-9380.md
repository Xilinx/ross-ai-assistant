# 8-9380: Dynamic Range in Net Declaration

**Message:** `[Synth 8-9380] dynamic range is not allowed in net declaration`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A net declaration uses a non-constant range.

---

## Common Patterns

### P1: Non-constant net range

**Problematic Code:**
```diff
wire [n:0] data;  // ERROR: n is not constant
```

**Recommended Fix:**
```diff
parameter N = 7;
wire [N:0] data;  // constant range
```

---

## Fix Strategy

1. Net declaration ranges must be **constant** — use a `parameter`/`localparam` (`wire [N-1:0] data;`), not a runtime signal.
2. If the width depends on configuration, parameterize it so it is fixed at elaboration.
3. Do not size a net from a `reg`/runtime value; that value is data, not a width.
4. Verify the range bounds evaluate to constants at elaboration.
