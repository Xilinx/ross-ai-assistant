# 8-11558: Ref Port Cannot Be Net Type

**Message:** `[Synth 8-11558] ref port '!%1!' cannot be of net type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A SystemVerilog `ref` port is declared with a net type (`wire`), but `ref` requires a variable type.

---

## Common Patterns

### P1: Net type on a ref port

**Problematic Code:**
```diff
// Before: ref port as wire
module m(ref wire logic in1);  // ERROR: ref can't be net
```

**Recommended Fix:**
```diff
// After: use variable type for ref
module m(ref logic in1);  // remove wire
// Note: ref ports are not synthesizable
```

---

## Fix Strategy

1. `ref` ports require a **variable** type, not a net (`wire`) — and `ref` is not synthesizable anyway.
2. For synthesizable RTL, replace `ref` with `input`/`output`/`inout` ports of appropriate types.
3. Keep any genuine `ref` usage in verification code with variable-typed actuals.
4. Verify the connected object's type matches the port kind after the change.
