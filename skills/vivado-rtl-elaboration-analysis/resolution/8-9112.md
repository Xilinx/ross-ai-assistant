# 8-9112: actual for formal port '!%1!' is neither a static name nor a globally ...

**Message:** `[Synth 8-9112] actual for formal port '!%1!' is neither a static name nor a globally static expression`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A formal port's actual is neither a static name nor a globally static expression where one is required.

---

## Common Patterns

### P1: Port actual is not static

**Problematic Code:**
```vhdl
port map (a => sig(dyn_index));   -- non-static actual
```

**Recommended Fix:**
```vhdl
port map (a => sig(CONST_INDEX));  -- static name/expression
```

---

## Fix Strategy

1. Use a static name or globally static expression for the actual.
2. Avoid runtime-variable indices in port associations that require static actuals.
3. Precompute a static intermediate signal if needed.
