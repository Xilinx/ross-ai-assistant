# 8-7023: Connection Count Mismatch

**Message:** `[Synth 8-7023] instance of module has N connections declared but fewer used`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An instance declares more connections than are actually connected.

---

## Common Patterns

### P1: Declared ports left unconnected

**Problematic Code:**
```diff
// Before: 44 declared but some unused
my_mod inst(.clk(clk), ...);  // WARNING: unused connections
```

**Recommended Fix:**
```diff
// After: connect all declared ports or remove unused
-- Ensure all ports in instance are properly connected
```

---

## Fix Strategy

1. Connect all declared ports of the instance, or intentionally leave unused outputs open and tie unused inputs to constants — do not leave them implicitly unconnected.
2. Prefer named connections so it is obvious which ports are (in)tentionally unconnected.
3. If some declared ports are genuinely unused by design, document that; otherwise a missing connection is usually a bug.
4. Verify the instantiated module version matches the connection list you expect.
