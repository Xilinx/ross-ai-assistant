# 8-3917: Unconnected Top Port

**Message:** `[Synth 8-3917] design has port that is not connected`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A top-level port is declared but not connected to any internal logic.

---

## Common Patterns

### P1: Top port with no internal connection

**Problematic Code:**
```diff
-- Before: port with no internal connection
port (output1 : out std_logic);  -- WARNING: unconnected
```

**Recommended Fix:**
```diff
-- After: connect or remove
output1 <= internal_sig;  -- connect to logic
```

---

## Fix Strategy

1. Connect the top-level port to internal logic — drive an output from a real signal, or consume an input somewhere in the design.
2. If the port is genuinely unused, remove it from the entity/module interface to clear the warning.
3. For ports that must exist for interface compatibility but are intentionally unused, tie outputs to a defined constant and document why.
4. Check for a typo where the intended internal connection targets a different signal, leaving this port dangling.
