# 8-2254: instance name '!%1!' matches net/port name

**Message:** `[Synth 8-2254] instance name '!%1!' matches net/port name`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An instance name is the same as a net or port name in the same scope, creating a name clash.

---

## Common Patterns

### P1: Instance name matches a net/port name

**Problematic Code:**
```verilog
wire a;
sub a (...);   // instance 'a' clashes with wire 'a'
```

**Recommended Fix:**
```verilog
wire a;
sub u_a (...);   // unique instance name
```

---

## Fix Strategy

1. Give the instance a unique name distinct from nets/ports.
2. Adopt a naming convention (e.g. `u_` prefix) for instances.
3. Rename either the instance or the conflicting net.
