# 8-982: !%1! in always_comb/always_latch/always_ff is not allowed

**Message:** `[Synth 8-982] !%1! in always_comb/always_latch/always_ff is not allowed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A construct not permitted inside `always_comb`/`always_latch`/`always_ff` is used there.

---

## Common Patterns

### P1: Statement not allowed in always_comb/latch/ff

**Problematic Code:**
```systemverilog
always_ff @(posedge clk) #5 a<=b;   // delay illegal in always_ff
```

**Recommended Fix:**
```systemverilog
always_ff @(posedge clk) a <= b;
```

---

## Fix Strategy

1. Remove delays/illegal constructs from `always_*` blocks.
2. Match the block type to the intended logic (comb/latch/ff).
3. Model clocked logic in `always_ff` without delays.
