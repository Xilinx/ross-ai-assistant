# 8-3819: Generic Not in Instance

**Message:** `[Synth 8-3819] Generic not present in instantiated entity`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A generic map provides a value for a generic that doesn't exist in the instantiated entity.

---

## Common Patterns

### P1: Generic map targets a non-existent generic

**Problematic Code:**
```diff
-- Before: generic not in entity
generic map(c_s_axi4_supports_narrow_burst => 0);  -- WARNING
```

**Recommended Fix:**
```diff
-- After: remove non-existent generic from map
-- Or check that correct entity version is used
```

---

## Fix Strategy

1. Remove the generic association for the generic that does not exist on the instantiated entity — it is being ignored.
2. Fix a typo in the generic name so it matches the entity's declared generic exactly.
3. Verify you are instantiating the intended, current entity version; an older/newer entity without that generic is a common cause.
4. If the generic should exist, add it to the entity and connect it through the hierarchy.
