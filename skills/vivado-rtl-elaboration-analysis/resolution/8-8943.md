# 8-8943: '!%1!' is not compiled in library '!%2!'

**Message:** `[Synth 8-8943] '!%1!' is not compiled in library '!%2!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A referenced design unit (entity/package) is not compiled into the library it is looked up in.

---

## Common Patterns

### P1: Unit not compiled in the library

**Problematic Code:**
```vhdl
use lib1.mypack.all;   -- mypack not in lib1
```

**Recommended Fix:**
```vhdl
use work.mypack.all;   -- reference the library that actually holds it
```

---

## Fix Strategy

1. Reference the library where the unit is actually compiled (often `work`).
2. Add the unit's source to the correct library/file list.
3. Fix the library name in the `use`/`library` clause.
