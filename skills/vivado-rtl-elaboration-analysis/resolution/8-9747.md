# 8-9747: Modport Item Not in Interface

**Message:** `[Synth 8-9747] modport item must refer to an item in interface`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A modport member name doesn't exist in the enclosing interface.

---

## Common Patterns

### P1: Modport member not in interface

**Problematic Code:**
```diff
interface intf;
  int a, b;
  modport M(input c);  -- ERROR: 'c' not declared in intf
```

**Recommended Fix:**
```diff
interface intf;
  int a, b;
  modport M(input a);  -- 'a' exists
```

---

## Fix Strategy

1. List only signals that are actually declared in the interface as modport members.
2. Add the missing signal to the interface, or fix the typo so the modport member matches a declared signal.
3. Ensure modport directions (`input`/`output`) match how each signal is used by the connected modules.
4. Verify producer/consumer modports reference the same interface signals with complementary directions.
