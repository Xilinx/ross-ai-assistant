# 8-10491: Array Element Width Mismatch

**Message:** `[Synth 8-10491] array element widths do not match`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10491] array element widths do not match [/path/to/file:NN]
```

---

## Root Cause

Assignment between arrays where element widths differ (e.g., assigning `int[4]` to `bit[1:0][2:0][3]`).

---

## Common Patterns

### P1: Array element width mismatch

**Problematic Code:**
```diff
// Before: arrays with different element widths
bit [1:0][2:0] a [4][4];  // element = 6 bits
int b [4][4];              // element = 32 bits
b = a;                     // ERROR: widths 6 vs 32
```

**Recommended Fix:**
```diff
// After: match element widths or use explicit conversion
bit [31:0] a [4][4];       // match int width (32 bits)
int b [4][4];
b = a;
```

---

## Fix Strategy

1. Make both sides of the array assignment have matching element widths and shapes.
2. Resize or restructure one array's declaration so element widths agree, or assign element-by-element with explicit width adaptation.
3. Use streaming operators / explicit casts to reshape when converting between different packed/unpacked layouts.
4. Verify total bit counts match before a whole-array assignment.
