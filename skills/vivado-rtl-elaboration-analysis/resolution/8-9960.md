# 8-9960: Range Must Be Constant

**Message:** `[Synth 8-9960] range must be bounded by constant expressions`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A range uses non-constant expressions for its bounds.

---

## Common Patterns

### P1: Non-constant range bound

**Problematic Code:**
```diff
wire [n:0] data;  // ERROR: n is not constant
```

**Recommended Fix:**
```diff
parameter N = 7;
wire [N:0] data;  // constant bounds
```

---

## Fix Strategy

1. Bound ranges with **constant** expressions — `parameter`/`localparam` or literals (`wire [N-1:0] data;`).
2. Do not size a declaration from a runtime signal; parameterize the width instead.
3. Ensure any function used in a bound is a constant function evaluable at elaboration.
4. Verify both bounds fold to constants so the range is fixed at elaboration.
