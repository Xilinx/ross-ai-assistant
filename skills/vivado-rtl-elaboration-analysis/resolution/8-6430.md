# 8-6430: The Block RAM "gain_syn:/RAM_reg" may get

**Message:** `[Synth 8-6430] The Block RAM "gain_syn:/RAM_reg" may get memory collision error if read and write address collide. Use attribute (* rw_addr_collision= "yes" *) to avoid collision`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

An inferred Block RAM can have a **read/write address collision** (the same
address read and written in the same cycle). The read data during such a
collision is undefined unless the collision behavior is specified.

---

## Common Patterns

### P1: BRAM read/write address collision

**Problematic Code:**
```diff
-- The Block RAM "gain_syn:/RAM_reg" may get memory collision error if read and write address collide. Use attribute (* rw_addr_collision= "yes" *) to avoid collision
```

**Recommended Fix:**
```verilog
// Declare the collision behavior (or add an output register / avoid collisions)
(* rw_addr_collision = "yes" *) reg [DW-1:0] RAM [0:DEPTH-1];
```

Review the warning and apply the recommended coding practice from UG901.
