# 8-11117: Non-Static For-Generate Range

**Message:** `[Synth 8-11117] range of for-generate statement must be static`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-11117] range of for-generate statement must be static [/path/to/file:NN]
```

---

## Root Cause

A VHDL `for...generate` loop uses a non-static (runtime) range, such as a hierarchical external name reference.

---

## Common Patterns

### P1: Non-static for-generate range

**Problematic Code:**
```diff
-- Before: non-static range in for-generate
for4: for ilx in <<constant ^.block1.Inst1.cons1 : bit_vector>>'range generate
  -- ERROR: external name reference is not static
```

**Recommended Fix:**
```diff
-- After: use static range
for4: for ilx in 0 to 7 generate   -- explicit static range
  -- Or use a generic/constant for the range
```

---

## Fix Strategy

1. Make for-generate ranges **static** (compile-time deterministic) — use generics/constants, not signals or external names.
2. Replace external-name/signal-dependent bounds with parameters fixed at elaboration.
3. For runtime-variable behavior, use ordinary logic (loops in always/process, muxes), not a generate loop.
4. Ensure any function in the range is a constant function.
