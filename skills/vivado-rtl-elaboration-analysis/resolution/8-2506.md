# 8-2506: Mixed Ordered/Named Parameter Connections

**Message:** `[Synth 8-2506] parameter connections cannot be mixed ordered and named`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

Parameter connections in an instance mix positional and named styles.

---

## Common Patterns

### P1: Mixed positional/named parameter overrides

**Problematic Code:**
```diff
// Before: mixed parameter styles
my_mod #(8, .B(16)) inst(...);  // ERROR: can't mix
```

**Recommended Fix:**
```diff
// After: use one style consistently
my_mod #(.A(8), .B(16)) inst(...);  // all named
// Or: my_mod #(8, 16) inst(...);  // all positional
```

---

## Fix Strategy

1. Use one consistent style for parameter overrides — either all **named** (`#(.A(8), .B(16))`) or all **positional** (`#(8, 16)`), never a mix.
2. Prefer **named** overrides: they are order-independent, self-documenting, and robust against added/reordered parameters.
3. If mixing crept in from an edit, convert the positional entries to named form.
4. Verify each named parameter actually exists on the target module after converting.
