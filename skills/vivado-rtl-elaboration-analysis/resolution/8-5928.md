# 8-5928: Asymmetric RAM Attribute Conflict

**Message:** `[Synth 8-5928] Asymmetric Ram with incompatible attribute ram_style`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

RAM style attribute conflicts with asymmetric RAM implementation.

---

## Common Patterns

### P1: Distributed style on asymmetric RAM

**Problematic Code:**
```diff
-- WARNING: ram_style="distributed" incompatible with asymmetric RAM
```

**Recommended Fix:**
```diff
-- Use block RAM for asymmetric:
attribute ram_style of mem_reg : signal is "block";
```

---

## Fix Strategy

1. Use `ram_style = "block"` for asymmetric-width RAMs — distributed/LUTRAM cannot implement asymmetric read/write widths.
2. Remove the conflicting `ram_style = "distributed"`/`"registers"` attribute on the asymmetric memory.
3. Ensure the coding matches the UG901 asymmetric-RAM template (power-of-two width ratio, adjusted address widths, synchronous access).
4. If BRAM is not desired, redesign the memory to symmetric widths so distributed style becomes valid.
