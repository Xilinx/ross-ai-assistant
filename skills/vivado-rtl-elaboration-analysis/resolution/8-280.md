# 8-280: Expression Must Be Constant

**Message:** `[Synth 8-280] expression must be constant: !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-280] expression must be constant: sel [/path/to/file.v:42]
```

---

## Root Cause

A non-constant expression is used in a context requiring a compile-time constant. The specific expression is named in the error message.

---

## Contexts Requiring Constants

| Context | Example |
|---------|---------|
| Array dimensions | `reg [7:0] mem [0:SIZE-1]` |
| Parameter values | `parameter X = expr` |
| Generate bounds | `for (i=0; i<N; i++)` |
| Part-select bounds | `data[HIGH:LOW]` (fixed select) |
| Case labels | `case(x) CONST: ...` |

---

## Common Patterns

### P1: Array Size from Signal

```verilog
// Before - signal in array dimension
input [7:0] depth;
reg [7:0] memory [0:depth-1];  // ERROR: depth not constant

// After - use parameter
parameter DEPTH = 256;
reg [7:0] memory [0:DEPTH-1];
```

### P2: Part-Select with Variable

```verilog
// Before - variable indices in part-select
input [3:0] start;
wire [7:0] data;
wire [3:0] nibble;
assign nibble = data[start+3:start];  // ERROR

// After - use +: operator for variable part-select
assign nibble = data[start +: 4];  // 4-bit slice starting at 'start'
```

### P3: Case Label with Variable

```verilog
// Before - variable in case label
input [7:0] threshold;
case (value)
  threshold: out = 1;  // ERROR: threshold not constant
endcase

// After - use if-else for variable comparison
if (value == threshold)
  out = 1;
else
  out = 0;
```

### P4: VHDL Generic with Signal

```vhdl
-- Before
signal width : integer;
component my_comp
  generic (W : integer);
end component;

U0: my_comp generic map(W => width);  -- ERROR

-- After
constant WIDTH : integer := 8;
U0: my_comp generic map(W => WIDTH);
```

---

## Fix Strategy

1. Replace signals with parameters/constants
2. Use `+:` or `-:` for variable part-selects
3. Use if-else instead of case for variable comparisons
4. Move runtime decisions to multiplexer logic
