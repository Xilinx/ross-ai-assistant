# 8-6858: Multi-Driven Net

**Message:** `[Synth 8-6858] multi-driven net`
**Severity:** CRITICAL WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A net/signal has multiple drivers, which may cause contention.

---

## Common Patterns

### P1: Net driven by multiple sources

**Problematic Code:**
```diff
// Before: signal driven from multiple sources
assign out = a;
assign out = b;  // CRITICAL WARNING: multi-driven
```

**Recommended Fix:**
```diff
// After: use single driver with mux
assign out = sel ? a : b;  // single driver with select
```

---

## Fix Strategy

1. Merge the multiple drivers into a **single** driver — select between the sources with a mux (`assign out = sel ? a : b;`) instead of two `assign`s.
2. For registers, ensure only one process/always block drives the signal.
3. If the multi-drive was accidental (duplicate assignment/copy-paste), delete the extra driver.
4. Treat this CRITICAL WARNING as contention risk — real multi-driven nets can cause X/contention; verify a single resolved driver post-fix.
