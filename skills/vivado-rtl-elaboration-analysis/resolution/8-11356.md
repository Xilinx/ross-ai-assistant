# 8-11356: Protected Type in Signal Declaration

**Message:** `[Synth 8-11356] Protected type cannot be used to declare '!%1!'`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

VHDL protected types cannot be used to declare signals or variables outside their intended scope.

---

## Common Patterns

### P1: Protected type in a signal declaration

**Problematic Code:**
```diff
-- Before: protected type as shared variable (not synthesizable)
type prot_t is protected ... end protected;
shared variable s : prot_t;  -- ERROR or not synthesizable
```

**Recommended Fix:**
```diff
-- After: use synthesizable types
signal s : std_logic_vector(7 downto 0);  -- synthesizable type
```

---

## Fix Strategy

1. Protected types are not synthesizable — remove them and model shared state with `signal`s plus explicit synchronization.
2. Convert `shared variable`/protected-type access into ordinary signals driven by well-defined logic.
3. Keep any genuine protected-type modeling in simulation-only code.
4. Ensure no signal/variable is declared with a protected type in synthesizable scope.
