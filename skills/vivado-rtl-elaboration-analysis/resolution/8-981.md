# 8-981: !%1! in always_comb/always_latch is not allowed

**Message:** `[Synth 8-981] !%1! in always_comb/always_latch is not allowed`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A construct not permitted inside `always_comb`/`always_latch` (e.g. a blocking event/delay) is used there.

---

## Common Patterns

### P1: Statement not allowed in always_comb/always_latch

**Problematic Code:**
```systemverilog
always_comb begin @(posedge clk) a=b; end   // event control illegal
```

**Recommended Fix:**
```systemverilog
always_ff @(posedge clk) a <= b;   // use always_ff for clocked logic
```

---

## Fix Strategy

1. Use `always_ff` for clocked/event-driven logic, `always_comb` for combinational.
2. Remove delays/event controls from `always_comb`/`always_latch`.
3. Keep only combinational statements in `always_comb`.
