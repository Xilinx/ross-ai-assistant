# 8-10511: Attribute Spec Outside Declaration

**Message:** `[Synth 8-10511] attribute specification for design unit is outside the declaration of the design unit`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10511] attribute specification for design unit is outside the declaration of the design unit [/path/to/file:NN]
```

---

## Root Cause

A VHDL attribute specification for an entity is placed in the architecture instead of the entity declaration region.

---

## Common Patterns

### P1: Entity attribute spec in architecture

**Problematic Code:**
```diff
-- Before: entity attribute in architecture (wrong scope)
architecture syn of top is
  attribute BRAM_MAP: string;
  attribute BRAM_MAP of top : entity is "yes";  -- ERROR: outside entity decl
```

**Recommended Fix:**
```diff
-- After: move to entity declaration or use correct target
entity top is
  port (...);
  attribute BRAM_MAP: string;
  attribute BRAM_MAP of top : entity is "yes";  -- inside entity
end;
-- Or apply to architecture instead:
architecture syn of top is
  attribute BRAM_MAP: string;
  attribute BRAM_MAP of syn : architecture is "yes";
```

---

## Fix Strategy

1. Place an **entity** attribute specification inside the entity declaration region, not the architecture.
2. If the target is actually an architecture object, change the entity-class to `architecture`/`signal`/etc. accordingly.
3. Match the attribute's entity class to where the specification is written.
4. Ensure the attribute is declared before it is specified.
