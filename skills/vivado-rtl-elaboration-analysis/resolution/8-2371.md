# 8-2371: Multi-Statement Function Without Begin/End

**Message:** `[Synth 8-2371] multiple statement function/task without begin/end not supported in this mode of Verilog`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A Verilog function/task has multiple statements without `begin`/`end` enclosing them.

---

## Common Patterns

### P1: Multiple statements without begin/end

**Problematic Code:**
```diff
// Before: multiple statements without begin/end
function [7:0] calc;
  input [7:0] a;
  reg [7:0] tmp;
  tmp = a + 1;  // ERROR: needs begin/end
  calc = tmp;
endfunction
```

**Recommended Fix:**
```diff
// After: add begin/end
function [7:0] calc;
  input [7:0] a;
  reg [7:0] tmp;
  begin
    tmp = a + 1;
    calc = tmp;
  end
endfunction
```

---

## Fix Strategy

1. Wrap multiple statements inside a function/task body in a `begin ... end` block (Verilog-2001 functions do not implicitly group statements).
2. Ensure every declaration in the function appears before the `begin`, and all executable statements go between `begin` and `end`.
3. Consider migrating to SystemVerilog, where the function/task body implicitly forms a block and `begin`/`end` is optional.
4. Confirm the return variable (function name) is assigned within the block on all paths.
