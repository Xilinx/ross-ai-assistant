# 8-693: Zero Replication

**Message:** `[Synth 8-693] zero replication count - replication ignored`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A replication `{0{...}}` has count zero, producing nothing.

---

## Common Patterns

### P1: Zero replication count

**Problematic Code:**
```diff
// Before: zero replication
assign out = {0{data}};  // WARNING: produces nothing
```

**Recommended Fix:**
```diff
// After: use non-zero count or remove
assign out = {4{data}};  // replicate 4 times
// Or: assign out = 0;
```

---

## Fix Strategy

1. Use a positive replication count (`{N{data}}` with `N > 0`); a zero count produces an empty result and is almost always a mistake.
2. If the count is parameterized and can legitimately be zero, guard it with a `generate`/conditional so the zero case is handled explicitly (e.g., assign a constant instead).
3. Check the parameter/expression driving the count — an accidental 0 (uninitialized or mis-computed) is the usual root cause.
4. If replication is not actually needed, replace it with the direct value or a constant.
