# 8-8925: Not a Type

**Message:** `[Synth 8-8925] '!%1!' is not a type`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

An identifier used as a type is not actually a type.

---

## Common Patterns

### P1: Non-type name used as a type

**Problematic Code:**
```diff
-- Before: signal name used as type
signal bticks : bticks;  -- ERROR: 'bticks' is not a type
```

**Recommended Fix:**
```diff
-- After: use actual type
signal bticks : std_logic_vector(7 downto 0);
```

---

## Fix Strategy

1. Use an actual **type** name in a type position, not a signal/variable name (`signal s : std_logic_vector(7 downto 0)`).
2. Check for a name collision where an object and a type share a name; rename one.
3. Ensure the intended type is declared/visible (import its package if needed).
4. Fix typos so the type reference resolves to a real type.
