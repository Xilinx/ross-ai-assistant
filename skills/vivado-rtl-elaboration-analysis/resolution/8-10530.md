# 8-10530: Null Waveform on Non-Guarded Signal

**Message:** `[Synth 8-10530] cannot assign a null waveform to a non-guarded signal`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10530] cannot assign a null waveform to a non-guarded signal [/path/to/file:NN]
```

---

## Root Cause

VHDL `null` waveform assignment (`signal <= null;`) is only allowed on guarded signals (signals with disconnect specifications).

---

## Common Patterns

### P1: null waveform on a non-guarded signal

**Problematic Code:**
```diff
-- Before: null assigned to non-guarded signal
when others =>
  result <= null;  -- ERROR: result is not a guarded signal
```

**Recommended Fix:**
```diff
-- After: assign a default value instead
when others =>
  result <= (others => '0');  -- use actual default value
```

---

## Fix Strategy

1. Replace the `null` waveform with a real value — `null` is only valid on guarded (resolved, disconnectable) signals.
2. If you intended to disconnect a driver, use an enable/valid scheme instead of a null waveform.
3. For guarded-signal behavior, ensure the signal has a disconnect specification; otherwise drive a defined value.
4. Confirm the ignored assignment was not the only intended driver.
