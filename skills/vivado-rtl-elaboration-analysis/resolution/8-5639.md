# 8-5639: Null Variable Init

**Message:** `[Synth 8-5639] ignoring null variable initialization`
**Severity:** WARNING
**Source:** Oasys Synthesis

---

## Root Cause

A variable initialization with null value is ignored.

---

## Common Patterns

### P1: null/X variable initializer

**Problematic Code:**
```diff
// Before: null initialization
reg [7:0] data = 'bx;  -- WARNING: ignored
```

**Recommended Fix:**
```diff
// After: use valid initial value
reg [7:0] data = 8'h00;
```

---

## Fix Strategy

1. Initialize registers/variables with concrete values (`8'h00`), not `x`/`z`/null — unknown initial values are ignored for synthesis.
2. For power-on state, rely on an explicit reset in a clocked block rather than an initializer, which is more portable across flows.
3. If the initializer was meant to mark "don't care," ensure the signal is actually driven before use so no undefined value propagates.
4. Verify the intended reset/initial value is applied where the logic first reads the signal.
