# 8-9565: illegal argument of type !%1! in '!%2!()', expected !%3!

**Message:** `[Synth 8-9565] illegal argument of type !%1! in '!%2!()', expected !%3!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A system function call is given an argument of the wrong type.

---

## Common Patterns

### P1: `$clog2` given a non-integral argument

**Problematic Code:**
```systemverilog
n = $clog2("str");   // string arg -> illegal
```

**Recommended Fix:**
```systemverilog
n = $clog2(DEPTH);   // integral arg
```

### P2: `$bits` given a value where a type/expression is required

**Problematic Code:**
```systemverilog
w = $bits(3.14);     // real literal -> illegal argument type
```

**Recommended Fix — pass a type or a sized net/variable:**
```systemverilog
logic [7:0] data;
w = $bits(data);     // width of an integral object
w = $bits(logic [15:0]);  // or a packed type
```

### P3: `$signed`/`$unsigned` applied to a non-integral value

**Problematic Code:**
```systemverilog
x = $signed("abc");  // string -> illegal argument type
```

**Recommended Fix:**
```systemverilog
logic [7:0] v;
x = $signed(v);      // integral operand
```

### P4: `$size`/`$dimensions` on a scalar instead of an array

**Problematic Code:**
```systemverilog
logic scalar;
k = $size(scalar);   // scalar has no unpacked dimension
```

**Recommended Fix:**
```systemverilog
logic [7:0] arr [0:15];
k = $size(arr);      // array operand
```

---

## Fix Strategy

1. Pass the expected argument type shown in the message (`!%3!`).
2. Convert the argument to the required type first (e.g., a sized net/variable
   for `$bits`/`$signed`, an array for `$size`).
3. For `$bits`, pass a packed type or an integral object, never a real/string literal.
4. Check argument order and count for the system function.
