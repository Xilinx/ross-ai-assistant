# 8-10478: Integer Level Required

**Message:** `[Synth 8-10478] an integer level should be specified`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Vivado Message

```
ERROR: [Synth 8-10478] an integer level should be specified [/path/to/file:NN]
```

---

## Root Cause

The `` `line`` compiler directive requires a numeric line number, filename string, and integer level. Missing or malformed arguments cause this error.

---

## Common Patterns

### P1: Malformed `line directive

**Problematic Code:**
```diff
// Before: malformed `line directive
`line 27 "file.v"         // ERROR: missing level argument
`line "file.v"            // ERROR: missing line number
```

**Recommended Fix:**
```diff
// After: provide all three arguments
`line 27 "file.v" 0       // correct: line_number "filename" level
// Or remove `line directives (usually not needed for synthesis)
```

---

## Fix Strategy

1. Give the `` `line `` directive all three arguments: `` `line <number> "<filename>" <level> ``.
2. Ensure the line number and level are integers and the filename is a quoted string.
3. If the directive is auto-generated and not needed, remove it — it is not required for synthesis.
4. Check the tool/preprocessor that emitted the malformed directive.
