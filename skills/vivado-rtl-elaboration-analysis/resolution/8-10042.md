# 8-10042: subprogram '!%1!' does not conform with its declaration

**Message:** `[Synth 8-10042] subprogram '!%1!' does not conform with its declaration`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A subprogram's body (or a generic subprogram's actual) has a profile - parameter names, types, modes, or return type - that does not match its earlier declaration in the package spec or interface. VHDL requires the body to conform exactly to the declaration.

---

## Common Patterns

### P1: Subprogram body does not match its declaration

**Problematic Code:**
```vhdl
-- spec
function f(a : in bit_vector) return bit_vector;
-- body: profile differs (std_logic_vector vs bit_vector)
function f(a : in std_logic_vector) return std_logic_vector is begin ... end;
```

**Recommended Fix:**
```vhdl
-- body matches the spec exactly
function f(a : in bit_vector) return bit_vector is begin ... end;
```

---

## Fix Strategy

1. Make the body's parameter names, types, modes and return type identical to the declaration.
2. For a generic subprogram formal, ensure the actual subprogram's profile conforms to the declared interface.
3. Watch for subtype differences (e.g. bit_vector vs std_logic_vector) - they do not conform.
