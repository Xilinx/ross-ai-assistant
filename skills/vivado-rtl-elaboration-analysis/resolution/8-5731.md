# 8-5731: Unknown Identifier

**Message:** `[Synth 8-5731] Unknown identifier !%1!`
**Severity:** ERROR
**Source:** Oasys Synthesis

---

## Root Cause

A VHDL identifier (type, signal, function) is not found in any visible scope.

---

## Common Patterns

### P1: Identifier not visible in any scope

**Problematic Code:**
```diff
-- Before: 'unsigned' not recognized
signal s : unsigned(7 downto 0);  -- ERROR: 'unsigned' unknown
```

**Recommended Fix:**
```diff
-- After: import the package
use ieee.numeric_std.all;  -- defines 'unsigned'
signal s : unsigned(7 downto 0);
```

---

## Fix Strategy

1. Import the package that defines the identifier — e.g., `use ieee.numeric_std.all;` for `unsigned`/`signed`, `use ieee.std_logic_1164.all;` for `std_logic`.
2. Ensure any user package defining the type/signal/function is compiled before this file and referenced with the correct library.
3. Fix typos and confirm the identifier is visible in the current scope (not local to another unit).
4. Verify the correct library is declared (`library ieee;`) and mapped in the project.
