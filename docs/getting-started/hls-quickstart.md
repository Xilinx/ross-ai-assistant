# Vitis HLS AI Assistant

Vitis HLS skills work directly with your source code — no MCP server or live Vivado session needed. The agent reads your code and HLS project files to provide architecture guidance, code generation, and optimization recommendations.

## Prerequisites

- **Vitis HLS** installed and on your `PATH` (for running the HLS compilation flow). 2026.1 is the tested baseline; the HLS skills and examples also run on 2025.1+ — see each example's README for its minimum.
- HLS agent skills installed in your workspace — see [Install Agent Skills](install-skills.md). Use `--skill hls-optimize` for a single skill, or `--all` for everything.

For skill descriptions, example workflows, and the full skills reference, see the **Vitis HLS AI Assistant — Skills Reference** guide.
